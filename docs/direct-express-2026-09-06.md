# 顺丰、德邦官方月结自动下单

## 范围与费用

用户已有两家月结账号，选择官方直连，运费仍按已有月结合同结算。此方案不购买快递鸟/快递100等聚合下单套餐；未获得官方书面免费承诺，不能标为永久免费。真实调用、生产启用和寄件验收尚未完成。

快递鸟官方 [升级公告](https://v2.kdniao.com/news/42) 明确免费版不再支持电子面单下单；[试用页](https://www.kdniao.com/v2/activity/try.aspx) 列出电子面单 100 次试用，不能作为长期免费依据。

## 当前流程

1. 办公端「销售 → 基础资料 → 快递账号绑定」选择已有承运商，保存月结账号、常用服务和德邦送货方式；管理员准备平台连接及正式账号验收后，由有承运商编辑权限的人员显式启用。销售订单可覆盖产品。
2. PDA 按既有流程打包、箱贴闭合后确认整批打包完成。系统按当前任务已完成箱子自动取件数，不要求输入重量；两家下单接口重量均默认传 1（kg）。
3. 每 30 箱最多一批，自动生成各批独立 WB 号，并保存寄件仓库及销售单收件资料。多仓/分批出库不混单。
4. 后台校验资料后在事务中保存请求快照，提交事务后才向平台发请求。保存全部运单号，不能丢弃子单。德邦原单查询不保证母号优先，列表 `trackingNo` 仅是代表单号，`trackingNumbers` 才是完整集合。
5. 结果不明进入“下单待核实”，最多自动查询 5 次；人工核实按钮只恢复查询。德邦同渠道单号再次 create 可能追加子件，因此不做自动重发。

未向平台发送过的运单可补充地址/产品后重新提交；请求快照一旦保存就不再通过编辑改变原单。已发送的直连单目前通过快递官方取消，ERP 不允许仅修改本地状态假装取消；取消确认同步尚未实现，已提交箱子变更须先人工核实原单。未提交批次因缩批自动移除后可随后续重打包恢复，人工作废不自动恢复。面单由官方平台处理，此次不冒用本地箱贴作为快递面单；轨迹直连接口尚未接入。

## 开通资料

### 顺丰

[顺丰开放平台](https://open.sf-express.com/) 申请下订单和订单结果查询权限，绑定月结卡及所需产品，获取合作伙伴编码 partnerID 和校验码 checkword。测试与正式凭据分别配置，默认沙箱。

```dotenv
WAYBILL_SF_MAIN_APP_ID=
WAYBILL_SF_MAIN_APP_KEY=
WAYBILL_SF_MAIN_MODE=sandbox
WAYBILL_SF_MAIN_API_BASE=https://sfapi-sbox.sf-express.com/std/service
```

承运商凭据引用填 `sf_main`。正式环境使用 `MODE=production` 与 `https://sfapi.sf-express.com/std/service`，不得混用测试凭据/测试运单。普快或航空须选择合同实际开通的产品，不依据俗称自动认定空运。

官方接口依据：

- [丰桥新 API 接口规范](https://qiao.sf-express.com/doc/download/丰桥平台新API接口规范.pdf)：`EXP_RECE_CREATE_ORDER`、`EXP_RECE_SEARCH_ORDER_RESP`、`parcelQty`、母子运单结果。
- [官方 PHP SDK 指南 V2.1.1](https://qiao.sf-express.com/doc/download/SF-CSIM-EXPRESS-SDK-PHP指南-V2.1.1.pdf)：对 msgData+timestamp+checkword 做 form-urlencoded 编码，MD5 二进制再 Base64。

上述公开 PDF 较旧，正式开通时须核对该账号开放平台当前启用的接口版本；离线合同测试不能代替真实联调。

### 德邦

[德邦开放平台](https://dop.deppon.com/) 注册后绑定合同客户/月结编码，申请【新】下单服务、客户订单号查询权限及子母件权限。生产 URL 和查询权限需由德邦技术分别配置，不猜测 URL。

```dotenv
WAYBILL_DEPPON_MAIN_APP_ID=
WAYBILL_DEPPON_MAIN_APP_KEY=
WAYBILL_DEPPON_MAIN_MODE=sandbox
WAYBILL_DEPPON_MAIN_API_BASE=
WAYBILL_DEPPON_MAIN_QUERY_API_BASE=
WAYBILL_DEPPON_MAIN_ORDER_PREFIX=
```

承运商凭据引用填 `deppon_main`。`APP_ID` 为 companyCode；`ORDER_PREFIX` 为平台分配的 sign，含前缀的渠道号不能超过 32 字符。产品类型及送货上楼/不上楼须符合合同约定。

**下单重量默认值（用户最新约定）**：顺丰 `totalWeight=1`，德邦 `packageInfo.totalWeight=1`，单位均为 kg，不根据件数累乘。顺丰字段语义为本批总重量，德邦为单件/均重；这里均是下单默认值，最终实重由快递员称重确认，不写入实际重量或运费账单。操作员页面和寄件资料 API 不接受重量输入。旧 `DEFERRED_WEIGHT_MODE` 已不再读取，不能让旧 omit/zero 配置继续改变本次规则。已保存的历史下单请求快照不重写、不重发，仍只查询原单。

只允许官方 HTTPS 地址；若分配的测试地址仅支持 HTTP，请德邦提供安全入口。

官方动态文档（2026-09-06 实际读取）：

- [新下单服务](https://dop.deppon.com/#/apiDocs/apiDetail/CREATE_ORDER_NOTIFY)：orderType=2、大客户月结、产品类型、件数上限与重复提交追加子件规则。
- [客户订单号查询](https://dop.deppon.com/#/apiDocs/apiDetail/QUERY_ORIGINAL_ORDER)：custOrderNo 查询整批单号，单独申请权限。
- [SDK 签名](https://dop.deppon.com/#/apiDocs/accessGuide/apiSDKUsageInfo)：MD5(params+appkey+timestamp) 十六进制文本再 Base64。

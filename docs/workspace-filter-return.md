# 工作区列表筛选与详情返回

## 已应用条件与返回目标

工作区继续以现有 `tabs[].path` 和合并页 `viewPaths` 保存路径；不新增跨页面查询缓存。裸列表返回和顶部菜单经 `getWorkspaceListPath` 取该列表原路径，验证页面与工作区 key 一致。不存在原列表时仍打开指定列表；显式 query、明确清空及新建来源参数保持调用者的目标。合并页只读取指定子视图原 query，财务组菜单仍遵循原有权限与最后子页规则。

关闭详情/表单标签先规范化 pathname 再匹配 `listPath`，带 `focus`、`edit` 或来源参数时也能识别所属列表。只关闭当前详情；非活动标签关闭不改变当前页。原有脏稿确认、切换保留输入、新建来源隔离继续使用原工作区机制。

## 查询作用域

已挂载列表读自身 `TabPathContext`，避免隐藏页从其他标签 URL 读取默认日期或关键词。`useWorkspaceSearchParams` 提供稳定的自身参数与普通 Router setter；隐藏页禁止改其他标签 URL，没有标签上下文时沿用普通 Router。新接入采购、采购申请、调拨、两类退货、日志、批次和承运商账号页。现有销售、收货、库存、商品等自身路径实现复用。

采购/销售退货共用组件，但类型由自身路径决定。拣货批次已应用筛选随 URL 保存；打开 `waveId` 详情保留查询，关闭只移除详情上下文，明确清空仍清筛选。承运商手选账号同步原 `carrierId` 参数，保留原查询和搜索草稿；显式跳转另一账号、脏稿切换确认继续生效。

局部 state 筛选仍由 KeepAlive 组件实例保留；内联详情关闭不额外重置查询。独立 full-url 页（如条码打印查询）保留其原身份，新菜单入口不擅自合并不同来源查询。

本轮完整页矩阵、红绿日志、反向证明、最终静态检查及补丁哈希位于仓库外任务报告。GUI、Windows34项、PDA、实际打印仍未执行；不以 jsdom、类型检查或构建替代设备验收。

### 2026-10-13 标签容量与单页异常保护

30标签上限含固定首页。添加标签、直接路由及历史遍历统一只淘汰当前会话内最少访问、可关闭且无dirty登记的标签；无安全候选时保留原页并提示先保存/关闭。访问顺序不改变展示顺序、不跨刷新持久化；合并视图子路径的dirty保护整个标签。容量不允许的历史遍历在Router消费前恢复真实原idx/URL/state，保留前进历史；旧dirty确认、筛选/滚动及keepAlive实例继续保留。未登记的新深链不会临时挂载首页或第31页。

每个TabPanel内部独立错误边界；活动页或隐藏页渲染异常及该页重试不重挂其他页面。工作区外层故障只显示工作区故障，不承诺旁页完好。失败页自身内存仍随恢复重挂，刷新后草稿恢复未新增；云端组件测试已通过，浏览器GUI未验证。

### 2026-10-14 库存流水读取与未应用筛选

库存流水读取失败、加载、离线暂停时分别呈现当前状态，不把失败当作零条或继续展示旧计数；成功且完整读取后才显示真实空态。内部有界读取截断时明确说明数量未完整，不新增可见分页。重试沿原已应用 URL 条件，读取状态变化不覆盖查询弹窗中尚未应用的日期草稿。

实际库存页、原 useLogs/API/完整读取器的组件回归使用合成 transport 响应；已覆盖初始/后续批失败、截断、后台失败、离线暂停和草稿保留。它不等于真实数据库流水或浏览器 GUI 验收。

### 2026-10-16 未应用草稿与后台读取

十四类父页（销售、采购、拣货批次、商品、库位、货架、退款、授信特批、报废、退货共用页、运单、库龄、补货、库存总览）按全部已应用原始字段稳定传给查询弹窗的初值。退货共用页分别验采购/销售子路由；退款仍用其原局部state，已使用URL/TabPathContext的页面继续原作用域。后台GET、父重渲染、选择器晚到及隐藏返回不成为重新初始化草稿的理由；显式应用、重置和取消重开继续原默认日期和筛选合同。

连续列表不依赖可见页码保存位置，虚拟行、当前搜索输入、详情开关及列表滚动沿原KeepAlive实例保留。内部请求取消/错误不自动清查询或换请求意图；关闭/隐藏/卸载停止未完成续批，恢复从原已应用条件的首批开始。精确任务交接仍按原taskId/warehouseId核资格，不能通过自动收集扩大范围。

回归使用真实页面、QueryClient、QueryDialog及KeepAlive/原生浮层，网络边界为严格合成GET；几何与延迟响应受控，不等于真实API保存、服务器授权撤销、完整浏览器业务链或设备通过。

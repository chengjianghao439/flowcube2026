## 首轮问题与修正

首次正式入口于 `03:28:48 UTC` 启动，提交 `48ee3d406300a3f78bf4abbab773ec9e8cabb965`。Tests、安全及桌面 main 验证通过，PDA APK 已生成。镜像 ZIP 约 205 MB，按批次等所有分片完成后才启动下一批，少数慢分片拖住整体，超过旧 300 秒中转窗口仍未交付。

主动取消 Browser `35683308441`、PDA `35683308399`，未推 tag。取消后通过生产 Git SHA 核对仍为 v0.10.3 的 `846f146c89ebfe467138c5536d31636637567e63`，没有切换应用。

修正为固定 32 个 worker 持续补位，2 MiB 分片独立重试；签名 URL 最多缓存 30 秒，失败时跨线程去重刷新。生产中转等待 900 秒，远程接收上限 1100 秒，外层部署/job/PDA 等待预算同步覆盖。保留原 SHA、原字节、接收端独立摘要验证和全部部署门禁。

新增慢分片不阻塞后续工作的回归，旧实现已反向失败。接收窗口大于外层时限的反向测试也失败，避免只延长内层而仍被外层提前终止。

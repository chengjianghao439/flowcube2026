## 需要你操作：设置消息立即用于当前任务

电脑控制工具明确禁止操作 Codex 自身的界面，因此这一步需要你点击，不能由助手绕过限制设置。

1. 切回应用，按 **⌘ + ,（Command 加逗号）** 打开设置。
2. 点击设置左侧的 **常规**。注意本机中文版叫“常规”，不是“通用”。
3. 找到 **跟进处理方式**，打开对应选项。
4. 将 **加入队列** 改为 **调整方向**。

**调整方向**：任务还在运行时，你发来的补充要求会用于调整当前任务。例如正在改页面时发送“按钮文字也改成中文”，会作为当前工作的补充。**加入队列**：补充消息等当前这一轮结束后再处理。

依据：[官方设置说明](https://learn.chatgpt.com/docs/reference/settings#general)。原配置记录中的“运行时防止休眠”和上下文用量显示已开启；本次未重新核对其开关状态。

## 需要你操作：保存项目的本地环境

1. 按 **⌘ + ,** 打开设置，在左侧点击 **环境**。本机中文版导航名称是“环境”，页面内仍会出现“本地环境”。
2. 在 **选择项目** 中选择 `flowcube`，核对路径为 `/Users/chengjianghao/flowcube`。若列表没有它，点击 **添加项目**，选择该文件夹。
3. 已有本地环境时点击 **编辑**；尚未配置时点击 **创建本地环境**，名称可填“本地开发”。若先出现简化的“设置此项目”页面，展开 **高级选项**。
4. 找到 **设置脚本**，平台选 **默认** 或 **macOS**，填入下面的命令，再点击 **保存**：

```bash
npm run dev:setup
```

该命令用于新工作树依赖安装，不要为了试按钮在仍有开发服务运行的当前目录反复执行 npm ci。新工作树仍需单独配置开发数据库，不会自动带上被 Git 忽略的真实 `.env`。

本次在临时空目录测试时，前后端安装成功，桌面端的 Electron 安装阶段超过 240 秒测试时限，已停止该临时安装进程；尚未验证完整三端初始化成功。以后新工作树若卡在此处，保留终端报错供 Codex 排查，不能把依赖未完成视为可运行。现有开发目录的依赖未受这次测试影响。

然后在同一环境的 **操作** 区域点击 **添加操作**，逐条填写 **名称** 和 **操作脚本**，**平台** 选择 **macOS**（也可选择“所有平台”），每条填完点击 **保存**：

| 操作名称 | 命令 |
|---|---|
| 启动后端 | `npm run dev:backend` |
| 启动 ERP | `npm run dev:erp` |
| 启动 PDA | `npm run dev:pda` |
| 检查代码 | `npm run dev:check` |

保存后，这些操作会出现在应用顶部，运行输出在集成终端。默认后端 3000、ERP 5173、PDA 5174；前端地址以实际输出为准。已有服务运行时先复用，不要重复启动或关闭他人使用中的进程。

应用已保存 `.codex/environments/environment.toml`，包含设置脚本及四个快捷操作，并与开发命令一起纳入版本管理。新工作树应基于包含这些配置的提交创建；自动触发及完整 Electron 安装仍需实际验证。

依据：[官方本地环境中文说明](https://learn.chatgpt.com/zh-Hans/docs/environments/local-environment)。

注意：“设置项目”简化入口会立即运行设置脚本。当前开发服务运行时，不要用它试运行 `dev:setup`；这里只需要保存新工作树将使用的配置。

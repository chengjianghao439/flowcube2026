# 实际金额按分的现行规则

## 金额与价格分开

订单毛额、折后净额按精确十进制计算后四舍五入到分；实际退货冲账、退款、收付款及每笔核销分配均为整数分。单价、成本快照、换算率和中间计算保留原精度，数量继续按商品现行数量规则。金额显示两位不等于后端金额已经正确。

新资金输入超过分位明确拒绝，不借浮点容差把真实第三位小数吞掉。合法金额可保存在既有 DECIMAL 四位列中，例如 `12.3400` 仍是整数分。计算先用固定点整数，写库用十进制文本；返回 JSON 数字须可准确还原同一分值。保留原权限、期间、账户、核销、已付及请求回执约束。

## 对账实时投影与旧来源写入

对账单列表、详情与刷新按原 DECIMAL 四位事实做固定点求和、已付夹限和相减，最后才转 API 数字。`.30-.10` 的余额必须为 `.20`，不能把浮点运算尾数误认成历史不足一分。真实旧值 `.0067-.0033=.0034` 保留原值并继续触发实际现金的非分待核，不以两位展示或浮点容差消除它。草稿状态、原读取/行锁与各返回 DTO 类型保持。

新建供应商退款、新确认、新回款和新补录申请除了自身及原付款分币校验，还须核原 PR 合计、毛额，并复用采购退货确认/出库的原现金依据：新冻结报价保持八位原价，旧 NULL 来源仅沿原严格可证明的兼容规则。仅把退款请求写成 `.33`，不能使原退货 `.3333` 或不可执行的小数价旧依据变为合法新资金来源。该门放在原结果重放之后，不加在历史 GET、原 ACK 查询或非资金取消；旧 canonical 四位正文、快照及身份摘要均不改变。

## 普通销售与退货的预算

冻结原订单、逐行量价及仓库身份，原行毛额、整单毛额、折扣和净额使用分预算；行预算合计须与头额闭合。不强迫 `3×0.3333=0.9999` 与已经按分的行/头额 `1.00` 相等；该单折扣 `0.10` 后的新净额预算是 `0.90`。已发贡献按各原行分预算乘该行实际已发量/原量精确累计，中间不逐行舍入；零分行贡献恒零，不能因其原单价非零而从其它行分到钱。原高精度量价仍是来源证明。

已发累计净额按冻结净额预算乘上述实际已发贡献占整单预算比例，精确四舍五入到分。普通分批合格退货在预算内分配；当所有正分预算行的合格累计达到执行时各自实际已发终点时，取该终点净额减此前实际退货冲回，后续补发不能反向解释旧回执。金融终点比较精确原行贡献或正预算行向量，不能比较已经舍入的净额。零分行的实物仍受逐行可退量和任务完成约束，但不拖延正预算行的资金结尾，也永不承接现金尾分。申请金额与实际合格入仓冲回分开，零元净额允许合法实物流程继续。成本仍按原快照反转。

套单继续使用原组件、出库冻结毛额预算；实际净冲回应核此前真实已冲回金额，并按累计目标取差。不能只改小数位或把历史不足一分的冲回静默补成一分。

新政策的来源/退货 DTO 用明确 `moneyPrecision: 2` 及 `cashPolicy: 'cash-cents-v1'` 标记可按现行金额解释的事实。旧记录缺标记时不得仅靠页面格式器认作新政策；仍应保留原价精度及历史金额原文。

## 采购应付与供应商退款

新采购单冻结原 POI 身份、原数量、八位单价及已按分的行预算。已审核实际上架量在原订量内时，以原行分预算乘实际量/原量精确累计，再对整单目标舍入到分。采购结算凭证读取同一已审上架事实和原预算，不以已经扣除退货的应付缓存充当毛额；采购退货凭证单独冲回。

原收货流程允许合法超收，金额修复不改变数量合同。某行实际量超过原订量时，该行按原高精度单价乘累计实际量重算到分，其他行仍保持各自原分预算比例；不能把原分预算无界外推，也不能把已经舍入的原预算再加超量原值而重复舍入。例如原订一件、单价 `0.005`、原行额 `0.01`，实收两件的行额仍为 `0.01`；原行额为零、单价 `0.0049` 的行若实收一百件，则为 `0.49`。这种延伸须先证明原行预算等于原量价计算的分值；旧异常依据保留待核。

采购退货在创建时沿原 PO 排他锁与活动退货数量额度冻结商业金额。原三件合计 `1.00` 分三次建退货时可形成 `0.33/0.33/0.34`，后续出库顺序不重分，已收供应商退款也不使原报价改价。新报价以创建当时真实收货贡献按退量/实收量分配，非终点向下取分且不得超过“当前真实总预算减此前未取消冻结承诺”的可靠剩余额，终点取该剩余额；负剩余额明确待核，不能补零掩盖。取消仅释放该未执行退货的原数量与金额保留，不改其它退货或已收退款。当前真实贡献为零的行不承接尾分，原订量内原零分行仍恒零；合法超收后的新贡献按上述原价规则另行证明。

旧采购单的原依据为 NULL 时不回填升级。新退货仅在原单价为整数元、原逐行量价与分预算及头额闭合、旧活动退货和当前应付已付余额均可按原算法证明为分时，使用仅保存在新退货中的临时依据继续；它不改变旧 PO 标记或旧 AP 算法。其它无法证明的旧来源明确待核，不把所有旧单一律当作新分预算。

无应付记录时，原合法的未审收货退货仍可执行，实际信用金额留在原退货事实供以后审核抵扣，不伪造零应付。应付重算保留原 `max(0, 已审毛额－已执行退货实际金额)` 口径。已有应付后新执行退货仍须先通过原负总额和已付保护；不能先夹成零而放行。例如已有应付 `0.33`、已付零，新退货 `0.67` 仍拒绝，与“无应付时先退货，随后只审核部分收货”的合法时序不同。

新应付投影仅记录可重新证明的已审向量、原依据、已执行退货及待抵关系；普通付款和供应商退款只更新实际资金字段，不凭空构造收货向量。供应商退款始终使用原冻结退货金额和原范围、账期、已付、回执门。原流程允许已收退款的未执行退货取消时留财务核对标记，本轮不自动冲回那笔资金。

采购凭证继续由原应付记录驱动并使用原首次记账日期。因此“退货先执行、随后部分审核但尚未产生应付”的中间阶段，本轮不扩展毛额凭证入口或猜测日期；不能宣称该阶段已形成完整会计投影。

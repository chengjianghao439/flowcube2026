## 顺丰正式配置（2026-09-09）

- 先在生产服务器通过官方 `EXP_RECE_SEARCH_ORDER_RESP` 查询专用的不存在订单号，取得 HTTP 200、A1000、6150；无下单请求。
- 沿用已部署 v0.9.10 后端镜像，不编译、升级版本或部署本地其他改动。持有 `/tmp/flowcube-deploy.lock` 后，确认顺丰自动下单关闭且无运单，备份原私有 `.env`，原子写入 SF 六项配置。
- 生产基础 Compose 尚未包含快递映射，增加服务器配置文件 `/opt/flowcube/docker-compose.override.yml`，仅为 backend 引入 `WAYBILL_SF_MAIN_*` 六项；文件本身只有变量引用，不含密钥。标准 `docker compose` 自动合并此文件，既有部署脚本没有显式 `-f`，后续部署继续生效。基础映射发布后可在完整核对渲染配置一致的前提下移除此冗余覆盖文件，不能先删造成凭据丢失。
- 修改前后解析 Compose 完整配置，断言仅后端增加六项 SF 环境变量，其他服务/环境、镜像、挂载和网络不变。仅重建 backend，镜像摘要前后一致；没有构建、操作数据库业务记录或重建其他服务。
- 私有备份和不含凭据的回执位于服务器 `/root/.config/flowcube/backups/sf-config-20260908T162709Z/`，时间戳为 UTC；原配置和凭据文件权限 0600。回退需在部署锁内恢复该原始 `.env`、移除本任务覆盖文件，并使用相同镜像重建 backend 后验证 ready，不能覆盖后续其他任务的新配置。

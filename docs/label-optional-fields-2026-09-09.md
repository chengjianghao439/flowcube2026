# 条码标签可选信息（2026-09-09）

在「打印模板」选择对应标签，将左侧字段拖入画布，可调整位置、字号与大小；保存后后续打印使用该版式。现有模板及默认排版不自动增加字段，避免在小标签上挤入全部信息。

## 数据口径

- 真实数据预览与打印入队共用后端标签取值，模板保存字段与版式，不保存业务样例值。没有业务记录时沿用原有空白模板；真实记录缺少字段时留空，不补虚构信息。
- 商品编码、供应商型号、型号和颜色分别来自商品主档对应字段；`article_number` 表示供应商型号。
- 库存、塑料盒的单位优先容器单位，未记录时使用商品单位；数量沿用此次标签业务值（补打为当前剩余数量）。批次、生产日期、到期日期来自容器本身，不推算；未上架或未绑定库位时库位编码为空。
- 仓库名称/编码来自标签所属仓库；物流箱贴的销售单号来自仓库任务保存的关联销售单号，备注是箱子备注。多商品箱不显示某一个商品的型号或颜色，避免误认为整箱信息。
- 货架层数与每层位置数是货架配置；库位通道/货架号/层/位置来自库位本身。
- 收货和分箱入队使用调用方事务读取容器数据；新增字段查询不修改库存、单据或账款。预览继续校验来源业务权限和仓库范围。
- 无需数据库迁移；内置兜底 ZPL 和承运商电子面单版式不变。

## 本次包含的全部工作

### 小满正式接入

- 新增独立「小满」工作区；顶栏进入小满，仪表盘仍能打开原待办中心，原页面与权限继续保留。
- 支持库存查询、销售草稿、销售占库、补货建议与采购草稿、客户往来、收款核销、仓储卡点和经营简报；同时提供极序使用、流程、排错及产品设计交流。无关话题明确拒绝，不提供任意工具执行入口。
- 最多显示最近 30 条本人且当前有权查看的任务；支持候选选择、数量调整、新预览、刷新恢复和原单跳转。确认、结果不明与恢复继续使用原任务及原请求键。
- 收款登记与核销分步确认；权限、仓库范围、商品数量精度、会计期间与幂等仍由原 Flow API 校验。模型只做受校验的意图解析或极序交流，不替代业务事实源。
- 正式构建与 Electron 复用当前 ERP 服务器及登录会话，经原 `/api` 接入现有后端，无新增公开服务端口。后端镜像带运行源码，任务目录独立持久化；模型配置仅进入受保护的后端环境。
- 实测切换服务器/用户时丢弃迟到响应；断网后的确认只能查询原任务。发布整合另修正一处预览金额手写格式化，改用共享金额函数，分转元与业务计算不变。

### 六轮电脑端精修

- 品牌与基础材料：统一浅色品牌蓝、语义颜色、表面、圆角与阴影，字体本地随包并附许可证；清除旧色字面量与两份死样式文件，图表使用蓝阶和语义令牌。
- 页面族：采购列表/表单、入库创建/详情、库存总览/ABC、调拨、会计账簿/凭证、审批、财务看板、仓储运营与报表、条码打印等页面对齐共同材料和控件密度；全局搜索、菜单与其它浮层也纳入核对。
- 发票：进项/销项共享段控，增加按类型的状态页签、关键词/状态查询弹窗及 chips；去重复计数、使用「张」；按当前状态安排推进操作和菜单。已抵扣/已红冲且只剩删除的行保留原单一删除按钮；必填标记和金额带统一。
- 发票、补录、凭证去掉重复卡片；汇总回到表后标准位置。补货、账簿明细、采购详情、库存 ABC 表头归编，清理 ReportTable 上不会生效的背景类；塑料盒详情两张小表使用正式紧凑变体。
- 运费对账两表、波次绩效、审批流、会计期间、打印机、平均成本对账补齐真实列表计数；客户去双计数，成套配件补筛选卡，打印模板/部门及补货建议的汇总一并归编。
- 表单与浮层：共享红色必填星号，统一应用/表单/资金工作区页脚；审批流配置原生下拉换共享 Select；段控类名改为通用名。常用浮层补进出动画，按钮补按压反馈，尊重系统减动效设置。
- 销售与采购详情统一摘要带、视图页签、基础信息及明细行色，修正采购首行常驻悬停蓝并去页头重复数量；状态 chip 和人员短列避免挤压换行。操作日志清理按钮改为红框次级危险操作。
- 规则按普通/危险/幽灵、选中/禁用/悬停状态收窄；价格等级四色标签没有重新编码，可选状态页签滑移未引入测量逻辑。

### 会计修复

- 单体与账套汇总资产负债表正确扣减抵减资产：原值 100、累计折旧 10，净额为 90；合成集团对照从错误的 330 修正为 270。期间、子账套及红冲对照通过，查询前后凭证与资金流水摘要不变。
- 利润表、资产负债表、现金流及账套汇总读取失败时明确报错并提供所属区域重试；保留期间/账套，独立恢复正常区域，不再持续加载或将失败伪装为零值/不平。

### 发布前主动订正

首次候选暴露旧编译器基线与已批准设计未区分，也暴露通用规则对暗色控件的越界。保留不可变旧基线，单列 96 项浅色材料差异，恢复暗色与 PDA 基础令牌并限定精修 scope；PDA 游客登录也按既有 DOM 标记隔离，未修改 PDA TSX。

真实浏览器核对 4140 个多状态计算点，另验四种上下文的 16 个行按钮值；移除 scope 会触发失败，旧值漂移也会被拒绝。`.dark` 原声明块逐字不变。详见 [原因、文件与实测值](desktop-release-style-boundary-2026-10-26.md)。

# v0.4.27

本版给销售单加上「分仓发货」和「分批发货」两个能力，一张订单不用再拆成多张单处理。

## 新功能

- **分仓发货**：一张销售单里的不同商品可以从不同仓库发。新建/修改订单时勾选「分仓发货」，就能给每个商品单独指定发货仓库（不勾选则和以前一样，全部从同一个仓库发）。发货时系统按仓库分别生成出库任务，各仓独立拣货出库；订单详情能看到每个仓库任务的进度。
- **分批发货**：一张订单可以分多次发货。点「发起出库」时可以勾选本次要发的商品——只发一部分，其余留着，之后在订单详情点「继续发货」再发剩下的。有货的先发、缺货的等来货再发，不用整单等齐。
- **发货进度看得见**：销售单列表和详情会显示「已发/应发」进度（如「履约中 2/5」）；分仓订单详情逐个仓库列出发货状态。
- **取消剩余结案**：已经发了一部分的订单，如果剩余不想再发了，「取消订单」会取消未发部分、释放其占用的库存，已发部分和对应应收保留，订单以实发金额结案。

## 说明

- 应收账款按实际发出的商品金额累计，分批发货每次出库后自动更新。
- 已经开始发货的订单不再支持「修改订单」，只能继续发剩余或取消剩余。
- 桌面端本版无功能变更，仅随系统同步版本号。

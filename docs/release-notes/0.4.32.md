# v0.4.32

## 新功能

- **供应商与客户新增「结算方式」**：分为现结与月结两种。月结可选 30 / 60 / 90 天账期，现结无账期。
- **到期日自动按结算方式计算**：现结在下单当天到期，月结从收货完成 / 出库完成当天起算账期。到期未付会进通知提醒。
- **「应付/应收」拆成两个独立菜单**：应付账款、应收账款。两页都支持按单号或往来方名称查询。
- **「对账基础版」拆成「供应商对账」与「客户对账」**，并且可以直接在对账页登记付款 / 收款、确认结算。
- **账款按结算方式分流**：现结往来方的账款在应付 / 应收账款页处理，月结往来方的在对账页处理。

## 改进

- **全站状态显示统一**：单据状态、任务状态、启用停用、打印结果等一律使用同一套徽章样式，颜色按含义区分——进行中为蓝、已完成为绿、待确认为橙、已取消为红、草稿为灰。
- **账款状态文案区分应付应收**：应付显示「未付 / 部分付 / 已付清」，应收显示「未收 / 部分收 / 已收清」。
- 顶栏下拉菜单支持二级分段，财务菜单下按「往来账款」「对账」分组显示。

## 修复

- 修复绿色状态徽章的边框显示为灰色的问题。
- **修复改动客户 / 供应商的结算方式后，其历史账款会整批切换页面的问题**。结算方式现在于账款生成时固定下来，此后修改往来方档案只影响新产生的账款，不再改写已有账款。

## 说明

- 本版含数据库结构变更（迁移 135–138），部署后需执行数据库迁移。
- 升级后，历史账款会按往来方当前的结算方式归类一次，之后不再变动。

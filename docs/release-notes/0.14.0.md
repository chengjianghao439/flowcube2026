# v0.14.0

## 新功能
- 新增「小满」工作区。已支持查库存、销售草稿和占库、补货和采购草稿、往来台账、分两步收款、仓库作业卡点、经营简报；业务结果仍以系统接口为准。
- 小满支持最近任务恢复、预览数量调整；收款登记与核销分别确认，继续遵守原有权限、期间与幂等规则。空白页写明能做和不能做。最近记录只留下走过业务图的任务，招呼、本地短回和闲聊不进列表。
- 口语「做个订单」「开单」「下一单」进入销售草稿。缺客户或商品时追问，不回一整份能力清单。取消、改价、审批、付款和发货仍不做，回复里给出对应菜单。模糊品名在权限和仓库范围内列出候选让人选，一条近似也不自动替换；无权仓库的商品不出现。
- 小满不做开放讨论，不再进入用法闲聊。在吗、名字这类招呼只在本地短回。退货完整汇总暂不支持。卡点只覆盖仓库执行，本轮不扩到商务。大额量级提示本轮暂无。

## 电脑端优化
- 统一品牌蓝、浅色表面、本地随包字体及常用控件，减少外部字体加载依赖。
- 精修采购、入库、库存、调拨、会计、审批、财务与仓库报表、条码打印等页面的表头、间距、圆角和数值呈现。
- 销售与采购详情统一摘要、页签和基础信息；状态标签与人员短列避免被挤压换行。
- 发票管理补齐进销项状态筛选、查询弹窗和筛选条件清除，统一行操作、计数、必填标记与金额带。
- 统一表后汇总、筛选卡、红色必填标记及弹窗页脚，补齐常用浮层动效和按钮按压反馈，并尊重系统减动效设置。
- 保留选中行、禁用态和危险操作的区分，日志清理改为红框次级按钮。
- 收窄浅色精修范围，保留暗色与PDA控件的原有色彩、圆角和密度。

## 会计修复
- 修正单体与账套汇总资产负债表的抵减资产方向：原值100、累计折旧10时，净额正确显示为90。
- 报表读取失败时显示明确错误与重试，保留期间和账套；汇总各区域独立恢复，不再把失败显示成零值或“不平”。

## 说明
- 小满通过正式业务接口工作；需要人工确认的操作不会因文字回复直接执行。需要调用模型时，模型名只取环境变量 `AGENT_MODEL_NAME`。
- 小满目前的证据以合成库和局部浏览器为主。月结、跨期、多仓多供应商、生产并发和真机，不能当作已经成熟的证明。
- 本版同步桌面、服务端与PDA版本；Windows安装与更新提示、PDA真机和实际出纸仍需现场验收。

# v0.9.17

## 修复

- **PDA 收货：多商品收货单收到一半被卡住**
  一张收货单里有多个商品时，收完第一项后页面会跳到"收货已完成"，剩下没收到货的商品再也找不到入口（生产上已有一张单因此卡了三天）。现在收完一项会正常切到下一项，全部收满才进入上架。

- **上架规则改为服务端强制：未收满不能上架**
  以前只有 PDA 页面在拦，接口层仍可提交。现在服务端会拒绝未了结的收货单并明确提示——**继续收货，或由 ERP「短装结案」**。供应商少发货时走短装结案，即可正常上架已收到的部分。

- **「待上架」待办与超时提醒恢复工作**
  这两处的容器状态判断此前写错（用了不存在的状态值），导致"待上架"卡片永远是空的、"打印后未上架超时"提醒从不出现——收了货没人上架不会被发现。

- **单据列表的默认时间范围**
  销售、采购、收货三个列表的"最近一周"统一为 7 天（此前采购与收货实际是 8 天）；打开「查询」即可看到当前生效的日期范围。此前从菜单进入列表时是否套用默认范围并不稳定，且首屏会先闪出全部数据再跳成筛选结果，现已一致。清空日期即可查看全部。

- **销售列表显示**
  折后金额不再折行（`¥44610.70` 曾被拆成两行显示）、销售单号显示完整。

- **全局搜索框不再被自动填充污染**
  此前进入系统就能看到搜索框里是登录账号名，并弹出一个"未找到"的面板挡住右上角的「导出」「新建」等按钮。

- **Excel 导出**
  日期列统一为 `yyyy-mm-dd`（此前是英文习惯的 `mm-dd-yy`），并保留日期格式，可在 Excel 中正常排序与筛选。

- 无折扣时不再显示 `-¥0.00`。

## 说明

- 桌面端与 PDA 随本次同步更新版本号，功能与上一版一致。
- 生产上那张卡住的收货单（IN20260914001）在本次更新后即可继续收货。

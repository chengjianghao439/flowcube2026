# v0.9.6

## 页面优化
- 统一 PC 页面、查询弹窗、表格、分页和操作按钮的显示风格，优化登录、采购、销售、库存、仓储、财务和报表页面。
- 仪表盘支持展示全部有权限的卡片，并按业务分区排版，保留个人布局。
- 销售订单采用清爽的独立列布局，标题下增加快捷状态分类，查询入口统一放在顶部。
- 商品信息按编码、供应商型号、型号、名称、颜色分别展开，订单录入、收货、占库、库存和相关报表不再将多个字段挤在一起。

## 商品查找
- 统一商品选择弹窗，支持按编码、名称、条码、供应商型号、型号和颜色搜索。
- 优化分类筛选、分页、键盘选择与回填；按业务场景显示供应商、参考售价和仓库库存。
- 修复带仓库查询商品时的关联别名冲突，稳定分页结果。

## 说明
- 桌面端与 PDA 同步系统版本；库存、账款与单据审批规则保持原有口径。

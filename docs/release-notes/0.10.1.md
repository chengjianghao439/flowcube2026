# v0.10.1

修复 v0.10.0 的一个设计问题，并补齐上一次没有发出去的浏览器端与 PDA。

## 修复

- **「数量小数」开关不再限制小数位数**：v0.10.0 把「允许小数」实现成了「最多两位」，但系统本身的最小库存精度是 `0.0001`——按重量、长度计量的商品会用到位数更多的数量，这样会把 `0.0001` 这类合法数量误拦（调拨场景已经出现）。现在开关只决定「整数 / 可以小数」这一件事：不允许小数的商品填小数仍会被拦下并说明原因，允许小数的商品不再限制位数。
- **商品档案里的提示文案同步**：从「可以带小数，最多两位」改为「可以带小数」，不再承诺一个后端并不执行的限制。

## 说明

- v0.10.0 只发出了桌面端——浏览器端与 PDA 因测试失败没有部署成功，本版一并补齐。浏览器端与 PDA 的内容与 v0.10.0 相同（商品数量小数开关、金额与数量显示统一、打印单据金额格式、提示里的内部术语清理），另含上述修复。
- 本版不含数据库变更。

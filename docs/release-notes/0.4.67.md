# v0.4.67

## 新功能
- **经营 KPI 仪表盘**：新增「经营 KPI」报表页，一屏看 GMV、毛利、订单数、回款、平均客单五大指标，并与上月环比
- **临期库存预警**：保质期商品（批次管理）到期前 30 天自动提醒，提示尽快消化或处理（出库已按效期优先 FEFO）

## 运维加固
- **密钥轮换机制**：支持新旧双密钥过渡期——更换 JWT 密钥时老用户不会被迫重新登录（含操作手册）
- **MySQL 慢查询日志**：自动记录超过 2 秒的查询和未走索引的查询，监控脚本会告警慢查询堆积
- **容器非 root**：后端容器以非 root 用户运行，降低被攻破后的影响范围
- **日志可对接集中检索**：配置后可把告警/错误日志推送到 Grafana Loki，错误可上报 Sentry

## 预留
- 会计科目/凭证/期间表加了「账套」字段预留，为将来多账套做准备（当前单账套不受影响）
- 前端销售单编辑页（1489 行）拆分为多个文件，维护更清晰

## 说明
- 本版为运营与监控增强；桌面端/PDA 端与上版一致，仅随系统同步版本号

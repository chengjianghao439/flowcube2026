# v0.14.9

## 新功能

- 销售开单与采购开单明细表新增「历史价」独立列（位于单价列前）：分别展示该客户或供应商对该商品的最近一次真实成交价，点击直接填入单价，鼠标悬停查看上次单号、成交日期与数量。
- 财务菜单新增「工资管理」页面，支持员工档案维护、按月新建工资单、录入应发工资、核算个税社保与确认发放。

## 界面与导航优化

- 取消页内合并 Tab 切换条，原合并视图全部改为独立菜单入口与独立工作区标签，菜单名、标签名与页面标题保持一致。
- 精简顶栏导航：移除「会计」一级菜单与系统内重型总账入口，保留「发票管理」与「跨期补录审批」并归入「财务」菜单。
- 仪表盘待办卡片跳转收口至「审批中心」，减少重复待办入口。

## 修复与加固

- 统一补齐核心业务与运单接口的编号参数校验，非法编号直接返回明确错误提示，避免误触发系统异常。

## 升级说明

- 本版无新增数据库结构迁移，网页、桌面端与 Android PDA 同步升级至 v0.14.9。

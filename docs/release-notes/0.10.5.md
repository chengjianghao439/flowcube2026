# v0.10.5

改进权限与账务一致性，优化 ERP/PDA 长文本显示，并补齐收货扫码上架的操作反馈。

## 仓库作业与显示
- PDA 拣货商品改为单列，编码优先完整展示；总览商品名称可省略，进入详情后显示全名。
- ERP 业务字段、备注和选择结果支持换行，避免长信息被省略；图表长标签也可完整查看。
- 收货扫码上架显示库存条码校验失败原因、接口错误、推荐库位及成功提示。

## 权限与账务
- 加固打印动作、用户角色与仓库范围校验，修复 PDA 设备换仓、重置和会话失效的一致性问题。
- 授信申请没有匹配审批流程时明确提示，避免绕过审批。
- 销售收入与成本按实际分批出库期间归属，改进跨期凭证、历史来源检查和金额精度。
- 用户维护支持分配有权授予的自定义角色，PDA 待办按用户权限和仓库范围展示。

## 稳定性
- 修复未保存页面前进/后退时的地址恢复，以及分页汇总重叠数据未被识别的问题。
- 隐藏仪表盘停止不必要的轮询，补齐静态资源安全响应头，并更新测试依赖。

## 说明
- 本版修复了上架页面反馈缺失；现场扫码枪完全不触发识别的情况仍需真机验证。

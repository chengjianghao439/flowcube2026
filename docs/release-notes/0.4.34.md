# v0.4.34

## 修复
- 销售退货后再次发货时，应收不再被算回全额（退货冲减不再被吞掉，客户不会被多计应收）
- 库存并发操作（占库/出库/盘点/撤回收货/调拨）在个别情况下互相死锁导致的偶发报错
- PDA 打包（建箱/装箱/完成箱）无法操作的问题
- 库存总览、库存流水两个页面未按仓库权限过滤，可能看到其他仓库数据
- 调拨扫码出库未校验可用量，可能把已被销售占用的货调走
- 拣货扫码可累计超出容器实际库存
- 收紧退货、报销等接口的参数与权限校验

## 变更（会改变现有操作习惯，请留意）
- 销售退货：应收按实际质检**合格**入库数量冲减，质检不合格部分不再退给客户
- 退货冲减账款后，需财务**重新确认**才能再次付款/核销
- 打包出库：装箱数量必须与复核数量**一致**，装不齐不能进入待出库

## 说明
- 本版为质量与内控加固版本，补充了大量自动化回归测试守护上述改动

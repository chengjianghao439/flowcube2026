# v0.4.19

## 新功能
- 收货订单详情页新增单价、小计、已上架金额合计，方便核对本次收货的实际金额，不用再跳回采购单查单价。
- 采购单、销售单、调拨单、采购退货单、销售退货单的"商品明细"录入表格统一改版：编码、货号、型号、商品名称、颜色分列显示，不再挤在一个按钮里；数量和单价输入框收窄，短数字右对齐后不再留一大截空白。

## 修复
- 修复取消采购单时，混合收货单（一张收货单合并多个采购单）场景下漏判、误放行的边界问题；进一步加固了并发提交收货订单时的库存超发校验。
- 修复采购单详情页"关联收货入库单"显示"已完成"，但点进收货单详情实际是"异常中"（打印超时/上架超期等）的状态不一致问题，现在两处状态展示口径完全一致。
- 修复收货订单列表页"已收数量/未收数量"在部分场景下恒为 0 的统计错误。
- 修复 PDA 收货、上架页在断网重试后未正确核对服务端真实进度的问题，减少重复提交风险；修复数量输入框中千分位逗号导致的解析错误。
- 修复收货订单详情页货号/型号/颜色列在无数据时被误隐藏的问题，统一显示为"—"。

## 说明
- 桌面端本版无独立功能变化，仅随系统同步版本号。

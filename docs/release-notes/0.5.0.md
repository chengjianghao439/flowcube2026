# v0.5.0

## 新功能

- **钉钉经营预警**：库存低于补货点、客户/供应商账款逾期、商品临期、呆滞库存——系统自动推送到钉钉，管理层不用进系统就能看到经营风险（需在服务器配置钉钉机器人，联系管理员开启）
- **审批待办提醒**：通知铃和首页工作台新增「待我审批」卡片，请购、报销、放行、处置、改价等审批一眼可见，不再担心漏批
- **价格体系升级**：客户绑定价格表后，销售下单自动取价格表价格（未覆盖的商品自动回退等级价）；商品改价自动记录变更历史（改前/改后/操作人），支持配置「改价需审批」流程
- **客户/供应商门户**：客户可在系统内查看自己的对账单，供应商可查询采购单到货进度
- **批量操作**：销售单列表可勾选多张草稿单一键确认；客户资料、价格表支持 Excel 批量导入
- **PDA 库存查询**：仓库现场扫码枪扫条码即可查看商品在哪个库位、什么批次、哪天到期、剩多少
- **角色复制**：新建角色时可复制现有角色权限，不用从零勾选
- **库位标签打印**：库位条码标签支持打印（与货架标签一致）
- **报表增强**：库存周转报表新增周转率/周转天数；采购报表新增商品采购价格趋势图
- **单据编号自定义**：可在系统设置中修改各类单据的编号前缀（如销售单 SO → SO1）

## 修复

- **跨仓库权限漏洞**：修复退款单、盘点单、处置单未校验仓库权限的问题，限仓用户不能再操作其他仓库的单据；报销单详情与导出强制「只能看自己的」；调拨扫码强制校验 PDA 设备绑定仓库
- **货物效期计算错误**：修复收货时按生产日期推算效期在时区下回退一天的问题（涉及批次管理的商品）
- **性能优化**：权限查询加缓存、销售单列表翻页提速、补 6 组数据库索引、10+ 个列表页改为真分页、导出大文件自动限行防止卡死
- **安全加固**：升级前端依赖修复已知漏洞；监控新增公网探测与证书到期提醒；部署失败时自动回滚前后端并推送钉钉通知

## 说明

- 本版新增了数据库结构与设置项，部署时会自动迁移，无需人工操作
- PDA 版本同步更新（v0.5.0），请在手机上检查更新
- 钉钉预警、单号前缀等新设置项默认关闭/与原值一致，不会改变现有使用习惯

# v0.13.0

本版新增供应商退款、库存处理衔接和作业异常提醒，完善开单、资料录入与权限安全。

## 新功能

- **供应商退款**：采购退货可登记供应商退款，按原付款分配核对可退金额；确认、收到款和凭证状态分别显示，已结账日期的收到款走特权补录审批。
- **库存处理衔接**：记录待处理货品的意图，衔接退货、销售或报废；按实际执行数量核对进度，避免把处理意图当成库存变化。
- **作业异常提醒**：提醒当前箱贴失败、排队超时和长期无作业的批次；主机告警与数据备份摘要更清楚。
- **资料与查询**：支持更完整的客户、供应商名称和地址；客户导入模板新增选填地址，旧六列模板仍可用。优化商品查找、预占说明和跨单据查询。

## 改善与修复

- 普通重复开单、容器拆分和退款在网络中断后可核对原结果，保持原请求身份，减少重复执行。
- 费用跨期付款经过审批，业务日期与凭证所属期间分别保留；撤回收货拒绝已经调拨或在途异常了结的货品。
- 登录退出、仓库范围、PDA 绑定仓库和打印工作站鉴权更严格；导入、打印和访问频率限制更完善。
- 桌面端与 PDA 的构建、签名、发布和产物校验分别受发布门禁保护。

## 升级说明

- 浏览器、桌面端和 PDA 同步升级。升级后需要重新登录一次；打印工作站需由管理员重新注册后恢复消费打印队列。
- Windows 更新弹窗、PDA 硬件扫码、实际出纸及员工现场试用仍需现场验收。

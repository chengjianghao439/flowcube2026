# v0.4.48

## 新功能
- **来料质检新增「让步接收」处置，合格率报表区分严格 / 宽口径**：质检时可把不良但协商后接收入库的数量单独记为「让步接收」（PDA 质检页由「合格 / 拒收」两栏改为「正常合格 / 让步接收 / 拒收」三栏）。来料质检合格率报表相应新增「让步接收量」与「严格合格率（扣除让步）」两列，供应商质量分析可同时看到含让步的宽口径合格率与不含让步的严格合格率。

## 说明
- 让步接收量仍与正常合格一样上架、计入应付（结算口径一字不改），只是额外单列统计，不影响任何库存 / 账款数量。
- 历史质检数据（让步量为 0）行为完全不变：严格合格率等于原合格率。

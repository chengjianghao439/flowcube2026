# v0.4.81

## 新功能
- **全局搜索增强**：支持按仓库过滤（限仓用户只看到自己仓库的单据），新增时间范围筛选（默认当天，可切近 7 天/近 30 天/全部）
- **查询弹窗默认当天**：采购/销售/收货/退货等全部查询弹窗打开即默认筛选当天数据，可按需修改
- **PDA 设备会话心跳续期**：活跃使用期间自动续期，票据有效期从 30 天收紧到 7 天，设备丢失后冒用窗口大幅缩短
- **PDA 更新包安全校验**：下载 APK 前校验 sha256 签名，杜绝更新包被替换

## 修复
- **权限安全加固**：仓库任务/波次管理补全仓库数据权限——限仓用户无法再跨仓查看或操作他人仓库的任务；PDA 设备绑定仓库与任务仓库不一致时禁止作业
- **财务安全**：手工建账款接入幂等保护（连点两次不再重复生成）；多账套数据彻底隔离；退款/退货自动刷新对账单；开票量并发校验加锁
- **登录安全升级**：访问令牌有效期缩短至 2 小时 + 独立刷新令牌自动续期，改密码/禁用账号后旧会话立即失效，登录更安全且不用频繁重登
- **PDA 凭据加密存储**：设备绑定凭据改用系统级加密存储（Android Keystore），不再明文保存
- **全局搜索修复**：修复限仓用户搜索结果越权问题
- **稳定性**：工作区标签页上限控制（避免长时间使用后卡顿）、模板编辑器切换模板不再残留上一模板内容、登出后彻底清理缓存

## 说明
- 桌面端与 PDA 端均需更新到本版本以获得完整修复（PDA 安装包已内置新安全特性）
- 更新后首次打开查询页会默认筛选当天数据，如需查看历史数据请调整日期范围

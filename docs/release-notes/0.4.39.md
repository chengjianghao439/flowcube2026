# v0.4.39

## 新功能
- **序列号（个体制）管理·PDA 现场收尾**：为需要逐台管理的贵重/质保商品补齐现场作业——收货时逐台扫序列号登记、出库时逐台扫序列号核销；配套「序列号台账」查每台的当前状态与归属、「序列号追溯」看一台货从采购入库 → 上架 → 出库的完整时间线、「一致性对账」守护「容器数量 == 在库序列号数」不变量。功能默认关闭，可在商品资料按需对新品 / 零库存商品开启。

## 修复
- 修复序列号商品 PDA 收货时逐台扫码面板无法弹出的问题。
- 补齐序列号上架留痕，使追溯时间线完整呈现「收货登记 → 上架 → 出库核销」。

## 说明
- 序列号为灰度上线（默认关闭）；未开启序列号的商品，收发货流程与上一版完全一致。
- 桌面端与上版功能一致，随系统同步版本号。

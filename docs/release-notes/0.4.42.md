# v0.4.42

## 新功能
- **会计总账（二期）**：在「会计」菜单下补齐总账、报表与发票，形成完整的会计核算闭环。
  - **总账 / 试算平衡**：按会计期间查看每个科目的期初、本期发生、期末余额；借贷发生额与期末余额各自平衡一目了然，点科目可下钻查看**明细账**（逐笔 + 逐笔余额）。
  - **会计报表**：利润表、资产负债表、现金流量表（简版）。资产负债表实时校验「资产 = 负债 + 所有者权益」会计等式；现金流量表按收付款/报销自动归集。
  - **发票管理**：进项/销项发票池与认证、抵扣、红冲台账。录入按税率自动拆分不含税/税额/价税合计。
  - **价税分离**：生成凭证时，若采购/销售关联了发票，自动把税额拆分为「应交税费—进项/销项税额」（应付、应收金额口径不变）；无发票不拆税，后补发票重新生成凭证即自动带上。

## 说明
- 会计相关功能默认仅对**财务角色**开放；报表与总账均由已生成的记账凭证实时汇总得出，**不影响任何现有单据、库存与账款流程**。

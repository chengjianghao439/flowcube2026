# v0.4.36

## 新功能
- 仪表盘全面改版为「可自定义小组件」：进入编辑模式可拖拽排序、调整卡片宽度、隐藏或从组件库添加小组件；布局自动保存到你的账号，桌面端与网页端同步。
- 新增近 30 个业务小组件，涵盖关键指标（在库 SKU、库存数量 / 价值、待处理采购销售、今日出库 / 扫码、应收应付敞口、账户余额）、图表分析（出入库趋势、库存价值 Top、各仓分布、月度销售 / 采购、应收应付账龄、月度现金流、账户余额分布）、列表看板（低库存预警、到货看板、PDA 作业、催收 / 催付 Top、我的工作台、Top 客户 / 供应商、异常扫码），均按你的角色权限自动显隐。
- 新增一批趣味小组件：电子木鱼（连击特效）、下班倒计时（到点撒花）、可自定义假期日历倒计时、番茄钟、每日一言、摸鱼倒计时、今日运势、喝水提醒、待办便签、年度进度。

## 修复
- 采购：修复多张收货单对应同一采购单、并发上架时应付金额可能少算的问题。
- 销售：修复执行期改单时的库存预占泄漏与减量误拒；统一出库加锁顺序，消除并发死锁风险。
- 退货：修复整单质检全部不合格时退货单卡在「已确认」无法推进；修复上架加锁顺序；出库前对负库存提前拦截。
- 财务：「按单登记」的收款 / 付款现会正确进入资金账户流水；费用报销可见范围按权限收紧；对账单改为实时汇总口径；收付款、报销付款在金额超支时增加二次确认。
- 多处列表接入仓库数据范围，避免越权看到其他仓库的数据。

## 说明
- 本版含数据库结构更新，随部署自动执行，无需手动操作。

# v0.4.29

本版专项整改条码打印，修掉了一批会导致「标签重复出纸」「纸从别的机器出来」「绑定了打印机却不生效」的问题。仓库日常打标签的体验会明显更稳。

## 修复

- **同一张标签被打印两次**：以前点打印时，页面自己打一次、后台打印客户端又领走打一次，两边撞上就会重复出纸，还常伴随一个「打印失败」的红色提示（其实纸已经印出来了）。现在打印统一由打印客户端执行，页面只负责提交任务，不会再重复。
- **打印机绑定整体失效**：只要在「打印机管理」里删除过一台打印机，它的用途绑定会残留成无效记录，导致后续所有标签都跑到同一台打印机上，各仓库配好的绑定形同虚设。现在删除打印机会一并清理绑定，已有的无效记录也会在升级时自动清除。
- **多仓库打印商品标签会跑到别的仓库**：商品不属于任何仓库，系统此前只能按负载随便挑一台打印机，上海仓的人点打印、纸可能从北京仓出来。现在改为**从你这台电脑连接的打印机出纸**，不需要做任何选择。
- **「从本机添加打印机」报错添加不上**：老库上这个功能会直接失败，现已修复。
- **连续点击打印会印出多张**：网络卡顿时用户容易连点，以前每次点击都会真的生成一个打印任务。现在短时间内的重复点击会自动合并为一次，商品标签打印按钮在处理期间也会禁用。
- **打印客户端断网后任务卡住**：客户端断网或崩溃时，它领走的任务会一直卡在「打印中」，要等满 30 分钟才释放。现在几分钟内就会自动回收并标记出来。
- **标签打印成功却提示失败**：打印已经完成、只是回传结果时网络抖了一下，以前会被记成「打印失败」，容易让人再打一次造成重复出纸。现在会区分这两种情况，并自动重试回传。
- **PDA 打包打印箱贴总弹红色错误**：箱贴其实已经正常进入打印队列，提示是误报，现已去掉。

## 说明

- 多台打印机绑定同一用途时（例如各仓库各有一台标签机），默认不再随机切换打印机，避免在 A 工位点打印却从 B 工位出纸；只有当某台打印机频繁出错时，系统才会自动把任务分流到其它机器。
- 「A4 / 文档打印机」不再作为可选设备类型：标签打印统一使用 ZPL 指令，该类设备无法处理，选了也打不出来。已登记的设备不受影响，仍会正常显示。
- 本版包含数据库结构调整，服务器部署时会自动执行，无需手工操作。

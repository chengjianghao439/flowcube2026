# v0.4.37

## 新功能
- 销售单新增「客户常用地址簿」：在新建 / 编辑销售单的收货信息处点「地址簿」，可按客户存好常发的几个收货地址，**双击一行即填入订单**，不用每次重敲。
- 地址簿支持「粘贴自动识别」：把一整段「张三 13800138000 北京市朝阳区…」粘进去，自动拆成收货人 / 电话 / 地址，核对后一键保存或直接填入订单。
- 常用地址可设默认（自动置顶）、编辑、删除；地址按客户保存在服务端，换电脑、换人打开同一客户都能看到同一批地址。

## 说明
- 本版含数据库结构更新，随部署自动执行，无需手动操作。
- 维护常用地址需要「客户编辑」权限；仅有查看权限的账号可以选用地址，但不能新增或修改。

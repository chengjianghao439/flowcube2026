# v0.4.43

## 新功能
- **来料质检拒收处置**：采购收货质检判定的不合格品，现在可在「收货订单详情」里一键处置——退供应商或报废。收货详情新增质检进度展示（待质检 / 合格 / 拒收）与拒收品容器清单。拒收品从收货起就不计入库存、不产生应付，处置只作废这些拒收容器并留痕，不影响库存与账款。
- **序列号历史导入**：已有存量库存的商品现在也能开启序列号管理了。新增「序列号 · 历史导入」页，为在库货逐容器补齐序列号后原子开启；补齐后序列号对账自动一致、可正常逐台出库核销。有存量库存的商品在商品档案里直接勾选序列号会被拦截，引导改走历史导入。

## 说明
- 两项均为对现有流程的增量增强：未开启「来料质检」「序列号管理」开关的商品，行为完全不变。

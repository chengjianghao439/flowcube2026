# v0.7.1

## 新功能

- **打印模板表格「名称后附加信息」**：A4 单据模板（销售/采购/出库/仓库任务单）的表格中，可以把**颜色/型号/单位/货号**拼接在商品名称后（如「商品A [黑色] [500g/件] [件]」），不再单独占列——打印模板编辑器 → 选中表格 → 属性面板「名称后附加信息」勾选即可

## 修复

- **打印模板「规格」改为「型号」**：之前打印模板里出现的是「规格」，但商品资料里这个字段实际叫「型号」（商品资料页、销售/采购等单据都是「型号」）——已统一为「型号」，历史保存过的模板也会自动订正
- **设置页精简**：「品牌标识」卡片删除了「系统品牌（极序 Flow）」的只读说明区块，只保留公司 Logo 上传

- 上一版（v0.7.0）的 PDA 相机扫码、未绑定受限模式、专业名词简化请见上一版更新内容

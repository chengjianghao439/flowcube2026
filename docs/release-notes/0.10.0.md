# v0.10.0

本版加入**商品级「数量小数」开关**，并系统性地统一了金额与数量的显示口径、清理了提示里一直没被注意到的内部术语。

## 新功能

- **商品可以设置「是否允许小数点」**：在商品档案里勾选「数量小数」——勾上的商品数量可以带两位小数（如 1.25 公斤），取消勾选的商品只能按整数出入库（如 3 个、2 台）。这个开关对该商品的下单、请购、收货、退货、调拨、盘点、库存调整与出库**全部生效**，不只是在页面上提醒：填错数量会被拦下并说明原因。新增商品默认允许小数，**存量商品的行为完全不变**。
- 商品列表与商品选择器会把「只能整数」的商品标出来，不用点进档案才知道。

## 修复

- **打印出来的单据金额终于好读了**：此前打印的销售单、采购单上金额不带千分位（`¥1234567.89`），而界面里是 `¥1,234,567.89`——同一笔钱两个样子。现在打印、模板预览与界面完全一致。
- **金额显示全面统一**：修掉台账、发票、会计报表、退款、处置等页面漏网的 10 处旧写法（没有千分位、空值显示成 `¥0.00`）。现在金额统一保留两位小数并带千分位，没有数据的显示 `—`，不再把「没有这笔金额」和「金额为零」混为一谈。
- **数量不再显示成 `1.20` 这种写法**：数量与金额的规则不同——`1.2 公斤` 是对的，`1.20 公斤` 是错的。此前有 8 处各自实现，有的固定两位小数、有的连千分位都没有。
- **提示里不再出现内部术语**：后端的报错会直接弹给你看，但此前它们一直在说「容器不存在」「波次已完成」「设备会话已过期」这类内部叫法。现在统一说「库存条码」「批次」「设备登录」，也不再显示 `ACTIVE`、`status=4` 这样的技术词。

## 改进

- **页面名称、菜单与标签栏三者对齐**：进入「商品分类」页，标题、菜单与顶部标签现在都叫同一个名字。
- **读屏与纯键盘操作可用**：删除分录、删除凭证、删除明细行、模板编辑器的加粗与对齐等只有图标的按钮补上了名称，不再是一排念不出来的按钮。

## 说明

- 本版含一处数据库变更（商品档案新增「数量小数」字段，默认允许小数）。升级后存量商品行为不变，无需人工处理。
- 桌面端与 PDA 随系统同步版本号；PDA 界面同上版。

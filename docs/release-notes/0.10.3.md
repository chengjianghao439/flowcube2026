# v0.10.3

数量最多保留两位小数，修复商品数量设置、仓库作业与版本更新中的多处问题。

## 数量与仓库作业
- 数量输入超过两位有效小数时直接提示修改，不再自动舍入后保存；金额、单价和单位换算率保持原有精度。
- 修复商品“允许小数”设置无法保存、保存后部分页面未及时更新的问题。
- 收货、退货、盘点按每箱分别检查数量，不能用多箱合计绕过整数要求。
- 修复拆分、装箱、释放占库等操作的数量校验遗漏，防止数量前后不一致。
- 修复合法小数被误判超量、库存已扣空但状态未更新，以及整箱归还被误拆的问题。

## 界面与更新
- 修复详情标签偶尔缺少单号、旧列表标签名称未更新，以及禁用选择器仍可清除的问题。
- 统一数量显示口径，修复采购数量使用科学计数法时被截断的问题。
- 改进更新包传输、发布顺序和安装包完整性检查，提高网络波动时的更新可靠性。

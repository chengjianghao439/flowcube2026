# v0.4.61

## 新功能
- **会计期间与期末结转（本系统为正式账）**：新增「会计期间」页，按月管理结账
  - 一键生成**损益结转凭证**：收入、费用科目期末清零，差额计入「本年利润」；12 月自动生成年度利润结转（本年利润 → 利润分配）
  - **结账/反结账**：期间结账后，该期间的凭证一律锁定（不可新建、删除、红冲、重算），要改须先反结账——账面一旦认可，不会被后续操作悄悄改写
  - 结账前系统自动校验：本期损益必须已结转、且结转凭证内容与业务一致（结转后又来了新业务会提示「结转需更新」），防止「结完又来一笔」导致账表不符
- **多级科目汇总**：试算平衡 / 科目余额表新增父级汇总行（如「应交税费」自动等于进项税 + 销项税合计），明细账也支持按汇总科目查看（含全部下级分录）——会计对表不用再自己加

## 修复
- 结转凭证重算不再把自己算进损益发生额（此前会导致结转后永远显示「需更新」，无法结账）

## 说明
- 历史期间默认为开放状态，可自行结账；结转科目「本年利润 / 利润分配」已自动预置
- 桌面端功能与上版一致，仅随系统同步版本号

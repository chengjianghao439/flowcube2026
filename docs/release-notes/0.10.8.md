# v0.10.8

PDA 扫码作业统一为直接扫码、按需手动输入；拣货信息更完整，操作反馈和设备操作更顺手。

## PDA 扫码与作业
- 上架、拣货、分拣、拣货退回、改单确认、盘点和库存查询统一使用扫码条。打开页面即可按设备扫码键；只有点“手动输入”才弹出键盘。移除库存查询中的扫码方式开关和扫码区上方的箭头提示卡片。
- 拣货列表补充商品规格、颜色、供应商型号、订单数与剩余数量；同一商品涉及多个任务时可以先选具体任务。
- 作业成功或失败统一显示一条悬浮提示，避免右侧提示与悬浮提示重复出现。

## 设备体验
- 修正 PDA 页面内容不足一屏时仍能上下滑动一点的问题。
- PDA 实体返回键可返回上一页；在工作台或登录页按返回键会退到后台。屏幕按设备系统设置正常息屏。

## 说明
- 浏览器与桌面端随系统同步版本。PDA 的扫码、返回键和息屏行为仍需安装本版后在 i6310pro 真机确认。

# v0.12.0

本版新增成套配件销售与边收货边上架，改善销售、仓库和财务之间的工作衔接。

## 新功能

- **成套配件**：维护套件及组件，销售按套开单，仓库按实际组件作业；缺件时只发完整套。分批发货记录原批次的组件金额，退货按该批次原分摊金额处理。
- **边收货边上架**：已收到的货可以先上架并供销售使用，不必等整张收货任务结束；任务结束且已收货全部上架后，按实际收货结算。
- **工作衔接**：销售进度可以进入对应的分拣分配；仓库完成作业后提供后续入口，首页与待办按员工权限显示常用工作。
- **开单解释**：显示销售价格来源与录入单位换算依据，方便核对成交价格和数量。
- **财务查账**：核销与对账详情可查看来源单据，收款详情可进入已有往来明细，返回时保留原查询条件。

## 改善与修复

- 塑料盒还原整件、套件开单和退货遇到网络中断时，可核对原操作结果，减少重复提交和误切单据。
- 运单与打印记录说明更清楚，区分业务状态、客户端打印回报和需要现场确认的出纸结果。
- 修复同一客户并发占库时的额度判断与改仓锁等待问题，保留原授信、仓库权限和库存规则。

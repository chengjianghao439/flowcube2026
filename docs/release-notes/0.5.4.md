# v0.5.4

## 新功能

- **桌面端本地日志**：桌面端新增本地运行日志（故障时可取证排查，文件保留在安装目录，便于技术支持定位问题）

## 优化

- **官网宣传页焕新**：
  - 新增「一条货的旅程」轨道时间线——从采购下单到对账结算的六步流程以可视化轨道呈现（电脑端水平交错、手机端竖向顺列），滚动时逐站点亮
  - 配色收敛为统一的系统蓝，界面更清爽稳重
  - 全站卡片样式统一（白底圆角 + 蓝色图标 + 悬停上浮），下载区改为三端平铺卡片（网页端 / 桌面端 / PDA），下载更直观
- **登录动线优化**：从官网点击任一功能卡片进入，登录后自动回到目标页面，不再被甩到首页

## 修复

- **官网页脚精简**：移除页脚重复的「进入系统」按钮，入口统一收敛至顶部导航与主按钮

## 说明

- 本版无数据库结构变更
- PDA 版本同步更新（v0.5.4），请在手机上检查更新

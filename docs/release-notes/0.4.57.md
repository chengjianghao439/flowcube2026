# v0.4.57

## 新功能
- 库存页「查看条码」面板升级：单件条码（一件一码，收货时每箱 1 件生成）带「单件」徽标，可一键「仅看单件」；点击任一条码可展开**流转时间线**，看到它从入库到出库的每一次移动（时间、动作、数量、经手人、关联单号）
- 塑料盒在面板中有独立徽标，与库存条码一眼区分

## 改进
- 单件库存条码不可拆分、不可并入塑料盒：该条码就是这件货的唯一身份，并入盒中身份即丢失。系统现在会直接拦截并提示「整件扫本条码操作」
- 界面用词统一：库存页的「容器」改称为「条码」（库存条码 / 塑料盒）

## 说明
- 本次为「条码与序列号融合」的第二阶段（个体判定与约束），现有作业流程无变化

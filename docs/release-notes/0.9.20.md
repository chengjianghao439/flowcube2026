# v0.9.20

本版集中修复现场反馈的「拦截原因看不见、单据收不了尾、列表数据不刷新」三类问题，覆盖 PDA 打包/调拨/上架/盘点/拣货退回/退货收货，以及 ERP 的操作日志、表格与图表呈现。

## 修复

- **错误提示不再被通用文案覆盖**：打包时箱贴没打印成功、调拨数量超过剩余可调量这类拦截，现在直接显示真实原因（例如「箱贴仍待确认：箱号 L000493 尚未打印完成，请先收口打印任务」），不再一律变成「状态已变化，请刷新后重试」让现场反复无效刷新。
- **PDA 打包页显示箱贴打印状态**：每个箱子标出「箱贴：待派发 / 已打印 / 打印失败（原因）」；箱子都完成但箱贴未打印成功时，页面常驻提示待处理箱和三条出路（重新入队打印、ERP「条码打印查询 → 出库条码」重打、启动已绑定打印机的桌面端）。规则不变：箱贴未打印成功不能进入待出库，放开的是「看不见原因」。
- **PDA 调出页显示「剩余可调」**：整容器调拨要求容器数量不超过剩余计划量，页面现在把每个商品的剩余可调量摆出来，避免拿大箱去凑小计划。
- **库位扫码不再卡格式**：上架与调拨调入的库位改按「编码或条码」解析，`SH-A01` 这类历史库位编码也能扫得进；同时回填历史库位缺失的条码。库位归属仓、状态与数据范围仍由服务端校验。
- **盘点单不再产生空单**：该仓库没有在库商品时直接拒绝创建盘点单；历史遗留的空单在 PDA 待盘点列表也会出现，并提示「无盘点明细，请在 ERP 取消后重建」，不再 ERP 有单、PDA 无入口。
- **纯 PDA 扫码完成的盘点单可以在 ERP 提交**：此前只弹「请至少填写一行实盘数量」，单据永远停在「进行中」，库存无法按实盘调整。
- **拣货退回能收尾**：没有原库位（导入/历史容器）的容器允许放回本仓任意启用库位，并把该库位记回容器；此前一律拒绝，订单取消卡在最后一步、任务与容器锁一直挂着。
- **PDA 退货收货支持扫商品编码**：现场标签印的是商品编码，此前只认商品条码，扫了没有任何反应；现在商品编码、商品条码、纯数字 ID 都能匹配，匹配不到时给出明确提示而不是静默忽略。
- **PDA 列表进入即取最新数据**：收货、打包、复核、调拨、盘点、退货列表重进立即刷新；拣货页的「刷新」同时刷新订单列表与商品汇总，不再出现「订单列表已空、商品列表还显示待拣 0/2」。
- **PDA 登录错误提示看得清**：改为浅色主题配色并加图标（此前是给深色背景准备的配色，白底上几乎看不见）。
- **绑定成功后密钥不再留在屏幕上**：绑定成功即清空并收起手动输入区。
- **重复提示不再堆叠**：5 秒内同类型同文案的错误条只保留一条，不再被并发请求刷出一叠红条。
- **上架偏离推荐库位的提示常驻**：需要再扫一次确认的状态一直显示到确认或改扫推荐库位，不再一闪而过。
- **控制台不再被无意义日志刷屏**：空集合的 JSON 解析不再打印警告，真实告警不再被淹没。

## 改进

- **表格操作列固定在右侧**：宽表横向滚动时操作按钮仍然可见，不再被挤出屏幕只露一个「详」字。
- **操作日志「操作内容」显示模块与动作**：例如「调拨单 · 扫码出库」「仓库任务 · 完成打包」「盘点单 · 扫码盘点」，未映射的显示方法 + 路径；此前整列都是「系统接口访问」，只能逐条点开详情。
- **分布类图表自动收敛**：各仓库存价值分布、账户余额分布按数值取 Top 8 + 「其他 N 个」，不再把上百个仓库/账户全画成系列。
- **隐藏标签页里的图表不再报错**：图表只在其所在标签可见时渲染，避免尺寸为 0 时的警告与空图。
- **条码前缀识别不出类型时直接回显扫描原文**：不再显示「已识别：未知条码」这类让人以为扫错的措辞。

## 说明

- PDA 作业页统一为默认「扫码模式」：进入页面、点击页面、扫码结束都不会自动弹出软键盘，需要手输时点「手动输入」。键盘是否弹出属 Android 行为，建议在真机上再确认一次。
- 本版含一条数据库迁移（回填历史库位条码），随部署执行，只补 `barcode` 为空的库位，不覆盖已有条码。
- 桌面端界面与上一版一致，仅随系统同步版本号。

# v0.9.18

## 修复

- **操作日志能正常打开了**
  此前打开操作日志页要几十秒才出结果，看起来像"查不到数据"——日志表只增不减，页面每次都要把全部记录拉完才显示。现在限制单次加载 5000 条，超出时会明确提示"仅加载最近 5000 条，请缩小时间范围或加筛选条件"，加载请求次数从 90 多次降到 20 多次。

## 改进

- **查询的日期范围一眼可见**
  查询弹窗现在会显示**当前实际生效**的日期范围（以前是空的，看不出列表其实已经按某个时间段筛过了）；点「清空」即表示查看全部。这个口径在销售、采购、收货、库存流水、操作日志等页面已经统一。

- **打开更快**
  操作日志、库存流水这类只增不减的数据表补上了默认时间窗口，不再一打开就加载全表。

## 说明

- 桌面端与 PDA 随本次同步更新版本号，功能与上一版一致。

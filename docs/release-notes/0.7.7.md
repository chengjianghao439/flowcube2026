# v0.7.7

## 新功能
- 供应商管理：新增**批量导入**，支持下载模板、按模板批量建档，编码/结算方式与手工创建一致。
- 新增**批次追溯**查询（库存 → 批次追溯）：按库存条码或塑料盒条码，追踪单个容器从入库到出库的全部流水。
- 商品资料：「货号」改为「供应商型号」——系统型号可能与供应商给的不同，现在可以单独记录供应商的型号，不再自动生成随机的货号。

## 修复
- 修复 PDA 首页「收货订单」显示有待办、点进去却没有任务的矛盾：计数口径与列表一致，未提交到 PDA 的收货单不再计入待办。
- 修复多账套下发票/报税重复计税、勾稽对账不平：发票按账套归属，报税口径统一。
- PDA 首页作业入口按「入库 → 出库 → 辅助」链路重新排序，找任务更顺手。

## 说明
- 桌面端与上版一致，仅随系统同步版本号。
- 商品资料的历史「货号」数据保留（列名不变），只是界面改显示「供应商型号」。

# v0.5.3

## 优化

- **盘点提速**：盘点提交的库存校验与调整改为批量处理（此前每件商品单独查询，全仓盘点需要几分钟，现在大幅缩短）
- **运营/API 日志一致性**：所有库存流水写入统一入口——不同单据（收货上架/出库/调拨/盘点/退货/处置）的库存变动记录口径完全一致，对账与追溯更可靠
- **PDA 下载稳定性**：APK 下载的断点续传请求参数校验更严格，异常请求不再产生错误响应

## 修复

- **个人资料修改收编**：修改姓名/资料走规范的服务层（含校验与统一日志），不再绕过分层
- **退货作业事务一致性**：退货收货/质检/上架的 3 个 PDA 接口统一事务边界管理
- **官网宣传页**：宣传数据更新为最新（60 个功能模块、5+ 内置角色、负库存零容忍），补齐 robots.txt 与站点地图（搜索引擎可收录官网）

## 说明

- 本版无数据库结构变更（仅 1 个索引优化）
- PDA 版本同步更新（v0.5.3），请在手机上检查更新

# v0.4.53

## 优化
- **序列号商品的执行期改单更灵活**：序列号管控的商品现在可以在拣货前做执行期改单（加量、未拣货前减量）——此前序列号商品的改单被整体拦截。已拣货后的减量因涉及物理归还、需逐台核对，仍会明确提示改走「取消后重新下单」，不再一刀切。
- **序列号商品盘点差异防错**：序列号商品的盘点盈亏差异不再自动盘盈/盘亏（旧行为会让容器数量与在库序列号台数不一致、静默破坏账实一致），改为明确提示「需逐台核对」，防止数据悄悄错乱。完整的序列号级盘点作为后续专项。

## 说明
- 非序列号商品的改单与盘点行为完全不变。
- 序列号管控为灰度功能、默认关闭；未开启序列号的商品不受影响。

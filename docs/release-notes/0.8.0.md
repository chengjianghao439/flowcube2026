# v0.8.0

## 新功能
- 新增「资金流水」页（财务 → 资金）：跨账户查看所有收付款、报销、余额调整、退货退款的明细，支持按账户、业务类型、收支方向、日期、单号搜索，并一键导出。账户余额由流水实时汇总，一目了然。
- 用户管理新增「允许自行审批」开关（仅超级管理员可设置）：开启后，该账号可以审批自己提交的费用报销、采购单、采购申请、授信放行与审批流单据。适合单人或小团队记账，默认关闭、由管理员逐人授予。
- 销售占库支持「在途预计量」：采购单提交后，其商品也能被销售单占用（占库弹窗会标出「在途 +N」）。当某张采购单被取消或短装时，系统会先拦截并提示「先去解除占用了它的销售单」，避免订单压着永远到不了货的库存。

## 修复
- 资金账户流水查询此前分页无上限，可能一次拉取超大结果集；现已按上限收敛，避免超量加载。
- 账户流水业务类型此前遗漏「退货退款」，现补齐，列表与导出均可正确显示。

## 说明
- 桌面端与上版一致，仅随系统同步版本号。
- 「在途占用」是「现货 + 预计到货」的估算口径：实货未到前，仓库任务/拣货会提示实物不足，到货后按库存现状补发。采购单取消/短装时会先拦截并引导解除被占用的销售单，不自动改动销售单。

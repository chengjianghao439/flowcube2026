# v0.14.1

## 小满
- 小满不再闲聊：新消息不进入开放讨论，页面设计、排错闲聊和使用讨论会直接拒绝。
- 空白页用白话写清能做和不能做：能查库存、开销售或采购草稿、看账款、仓库卡点和简报；不能取消、改价、审批、付款或发货。
- 遇到做不到的操作时，拒答会指出对应菜单，页面上可以直接点开。
- 口语说「做个订单」「开单」「下一单」会进入销售草稿；缺客户或商品时追问，补全后仍走原来的试算和确认。
- 品名对不齐时，只在当前有权限的仓库里列出近似商品候选；只有一条近似也不会自动替换。编码或名称完全一致且只剩一条时，仍直接使用。

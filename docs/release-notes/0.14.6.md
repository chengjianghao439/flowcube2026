# v0.14.6

## 小满

- 更好地识别客户全名、分店、语音转写、错别字、口语简称和粘贴的单号。信息不足时只询问关键项，转发的客户原话要由经办人另行确认。
- 支持按条件和顺序处理多项要求。中途改口、切换客户或单据、刷新页面或重新登录后，可找到原任务继续。需要办理时重新核对权限、单据状态和确认内容。
- 销售、客服、财务和仓库可围绕同一张销售单交接，查看已办事项、缺货或审批等卡点，以及下一步经办岗位。沿原单可核对分批发货、部分退货和分笔收款。
- 月结、核销和退款会说明逐单已核销金额、欠款、预收余款、应收冲减、已退与待退金额。跨月退货和已结账期间补录会说明原账所属期间及处理路径。多批占库释放或核销冲回后，可按原批次和办理记录核对已补、未补及待核项目。
- 确认前显示原单、数量或金额、账户与关键日期。另增对话复盘工具，可查看每次对话、确认和续办结果，便于排查重复追问及办理受阻的原因。

## 销售履约、仓库与财务

- 拣货推进与销售改单、取消同时发生时，重新核对原单和作业状态。集包、拣货等操作遇到重复提交或应答中断时，可查看原办理结果。
- 完善预占补办、分次核销和客户退款的提交前复核。原批办理记录或账款在预览后发生变化时，会提示重新核对，减少串批、重复占库、重复核销和重复退款。
- 优化首页经营指标和履约待办的查询。履约刷新遇到通知遗漏或服务重启时，后台会补扫未处理事项。
- 清理历史代码与旧资源，为开发权限和操作日志展示补齐自动检查。

## Windows 桌面更新

- 客户端发现新版后在后台下载。右下角提示条可查看进度、收起、重新打开，也可从仪表盘检查更新。下载可取消，失败可重试。
- 下载完成后由用户点击「重启升级」。如果有未保存的单据或表单，会先征求确认。安装前重新核对发布信息和安装包完整性。
- 已安装的旧版会沿用自身的更新方式完成首次升级。安装本版后，后续更新开始使用新的流程。

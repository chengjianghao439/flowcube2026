# v0.4.17

## 新功能
- **退货单、调拨单、收货订单列表页新增「查询」功能**：支持按经办人、产品、仓库、供应商/客户、日期范围等条件筛选，界面与采购单、销售单保持一致；筛选条件会保留在网址上，刷新页面不丢失，也可以逐项移除或一键清空。
- **导出 Excel 与当前筛选条件保持一致**：退货单、调拨单、收货订单点击「导出 Excel」时，会按列表当前的筛选条件导出，不再是每次都导出全部数据。
- **调拨单「源仓库/目标仓库」改名为「调出仓库/调入仓库」**：表述更直观，列表、表单、PDA 扫码页面统一更新。

## 修复
- 修复调拨单导出 Excel 时状态显示错误的问题：已完成的调拨单会被错误导出成「已取消」。
- 修复商品列表页缺少「分类」列的问题，现在可以直接在列表里看到每个商品所属的分类路径。
- 修复仓库运营看板缺少快捷跳转按钮的问题，现在可以直接点击跳到「波次效率」「PDA 异常分析」两个相关报表。
- 修复 PDA 打包作业页面「自动选中已开箱的箱子」功能失效的问题。

## 说明
- 桌面端与网页端同步升级，桌面端本版无独立功能变化，仅随系统同步版本号。

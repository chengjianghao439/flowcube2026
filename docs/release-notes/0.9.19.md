# v0.9.19

本版以修复为主，集中在权限拦截、盘点安全、PDA 显示与库存口径准确性上。

## 修复

- **只读账号不再能看到、也不能打开新建/编辑界面**：新增销售单、采购单、商品、客户、仓库、收货单、调拨单、盘点等入口都会按权限隐藏；直接输入网址访问新建页会提示无访问权限（此前会渲染出完整表单和"保存"按钮）。
- **盘点：未填写的行不再被当作"实盘 0"**：此前在"填写实盘"里只填了少量商品，保存时会把整单其余行都存成实盘 0（差异显示为 -账面量），一旦提交就会把整仓库存按盘亏清零。现在只有你真正填过的行才会保存，一行都没填时会提示"请至少填写一行实盘数量后再保存"。
- **PDA 收货列表的商品种类数显示错误**：此前无论单据里有多少商品，列表都显示"0 种商品"；现在显示真实数量。
- **取消销售单后明细的"已占/已派发"数量会正确归零**：此前取消后单据仍显示已占用，与已释放的库存预占不一致。
- **PDA 设备绑定页显示仓库名称**：此前显示为"所属仓库 #1"，现在显示"所属仓库 北京主仓"。
- **角色名称显示与角色设置一致**：修正了部分账号在界面显示旧角色名的问题（例如管理员显示成"管理员"而非"系统管理员"）。
- **系统设置里的单号前缀说明与实际一致**：销售单前缀示例改为 SL、采购改为 PC、收货订单改为 IN、调拨改为 TF（此前示例与系统实际生成的单号不一致）；同时清理了页面上不再生效的旧前缀项。

## 稳定性

- **请求体格式错误会返回明确的 400 提示**（此前返回"服务器内部错误 500"，且会污染错误日志）。
- **库存重算现在同时修复"已占"数量**：此前一键重算只修实物数量，一旦"已占"缓存与预占记录不一致，可用量会被算成 0，占库/发货会被静默挡住且提示"库存不足"，无法自行恢复。
- **一致性审计新增两类检查**：库存容器指向已不存在商品、以及已完结任务仍占用库存容器锁，便于提前发现脏数据。

## 说明

- 桌面端界面与上一版一致，仅随系统同步版本号。
- 盘点"未填写行"的防护是本版最重要的改动，建议仓库同事在正式盘点前先熟悉新的提示文案。

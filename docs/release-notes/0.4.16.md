# v0.4.16

## 新功能
- **退货单改为独立页面**：采购退货、销售退货不再是弹窗，新建、查看都在单独页面完成，可以直接看到货号、型号、颜色，绑定原采购单/原销售单时也能看到完整信息。
- **退货单详情页新增实时进度展示**：确认后可以直接在详情页看到出库或入库的实时进度，不用再去别的页面另外查。
- **收货订单明细支持货号/型号/颜色**：建单候选列表、收货订单详情页统一展示货号、型号、颜色，跟采购单、调拨单体验一致。

## 修复
- 修复采购退货、销售退货确认后仓库端偶发无法正常完成收发货的问题。
- 优化退货出入库流程，确认后统一由仓库人员扫码完成出入库，避免库存记录出错。

## 说明
- 桌面端与网页端同步升级，桌面端本版无独立功能变化，仅随系统同步版本号。

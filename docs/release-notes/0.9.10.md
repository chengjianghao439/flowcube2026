# v0.9.10

## 财务与采购
- 新增客户、供应商往来明细，可查看期初余额、逐笔变化及期末余额，客户多付款项可在往来净额中查看。
- 财务入口明确区分现结客户/供应商账款与月结客户/供应商对账。
- 按单登记默认显示全部日期的未结清单据，部分收付款保留待处理；查询与导出条件一致。
- 加强收付款单位归属与采购收货来源校验，避免同名单位混核和来源缺失造成应付重算错误。

## 操作体验
- 页内标签切换保留筛选、草稿、选择和滚动，关闭整个功能页后重置。
- 待办中心移除已取消的巡检功能，处理入口按实际页面及权限校验。
- 移除表格上方的恢复默认列宽按钮，保留拖动、双击和键盘调整列宽。
- 修复首页卡片排序保存后被重新分组的问题，系统版本等卡片可移到最上方并保持顺序。

## 说明
- 往来明细以启用时净余额作为历史结转，启用后逐笔记账，不倒推生成旧流水。
- 网页、桌面端与 PDA 同步版本。历史应收及采购定向修复已经单独完成，本次升级不重复执行。

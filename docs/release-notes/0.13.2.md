# v0.13.2

## 销售开单与查询

- 统一销售单的新建、编辑和详情。列表点击编辑直接进入编辑状态，普通商品与套装使用同一入口，编辑时也可添加套装。
- 套装按主商品和配件行展示，保留完整商品信息；主行显示数量和单价，配件行显示数量，单价用横线表示，成组关系更易辨认。
- 明细支持行备注和拖动列宽，内容上下居中，单一单位不显示下拉箭头；数量汇总在左，折扣与订单金额在右。
- 客户、商品和成套配件选择器改善行高、分类筛选和键盘操作；保留双击选择、虚拟滚动和完整范围查询。
- 删除重复说明、价格来源、成交依据及读取最新订单等冗余呈现；备注仅在实际截断时显示展开入口。

## 稳定性修复

- 销售列表超过现有加载上限时明确提示，读取失败或尚未加载时不再显示误导性的零条结果。
- 列表操作与详情权限保持一致，长收货地址自动适应高度，选择器关闭后返回原输入位置。
- 订单打印保留单价精度，显示折扣和折后订单金额；仅兼容系统原始默认销售模板，自定义模板保持原设置。
- 保存结果待核实时可查询原操作回执，确认原单后由用户主动进入查看，保留尚未保存的输入。
- 整理前端组件导出，消除 Fast Refresh lint 警告，保持原有路由与业务行为。

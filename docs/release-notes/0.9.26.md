# v0.9.26

本版以**修复与稳定性**为主：修掉资金看板一处图表可读性问题，并把发布与运维链路上几处「偶发失败、且失败时看不出原因」的环节加固。界面与业务功能与上一版一致。

## 修复

- **资金看板「账户余额分布」在账户较多时挤成一团**：该图此前把**全部启用账户**都画成扇区，而配色只有 8 种——账户超过 8 个之后颜色开始重复，账户多时扇区与图例已无法分辨。现改为只显示**余额最高的 8 个账户**，其余合并为「其他 N 个账户」（悬停仍显示各自的金额与占比）；「其他」使用中性色，不再与某个真实账户撞色。

## 加固

- **部署前的磁盘检查失败时会说明原因**：此前服务器可用空间不足时，检查只返回失败、不打印任何信息，与「连不上服务器」看起来一模一样，只能靠人工推断。现在会打印各挂载点的实际可用空间，并区分「空间不足 / 连不上服务器 / 取不到数据」三种情况。
- **发布产物不再在服务器上堆积**：桌面安装包的中转目录此前每个版本都会留下约 108 MB 且从不清理，把服务器磁盘一步步吃到不足、导致连续多轮部署被拒。现在发布完成或失败后都会立即清理。
- **服务器连接抖动不再中断发布**：与服务器建立指纹信息时此前只尝试一次，服务器短暂繁忙就会让整条发布失败。现在最多重试 5 次，并在失败时打印原因。
- **备份恢复演练不再残留临时数据卷**：演练用的临时数据库在异常中断（被强制终止或机器重启）时会留下完整副本目录并长期累积。现在改用固定名称，并在每次演练前先清理，异常中断也能自愈。

## 说明

- 本版不含业务逻辑变更；桌面端与 PDA 界面同上版，仅随系统同步版本号。

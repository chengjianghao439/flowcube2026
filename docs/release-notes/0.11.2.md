# v0.11.2

本版完善退货返货、跨期补录和应付入账流程，修复采购收货撤回及仓库权限问题。

## 退货与仓库

- 销售退货已有货品入库时，取消申请会生成独立的返货出库单；仓库完成返货出库后，退货单才正式取消。退货详情可查看返货进度和条码。
- PDA 待出库列表可处理返货出库，并改进拣货推荐批次和分页加载。
- 已登记付款的采购收货不再允许撤回；未形成应付的记录不会误显示为已付清。

## 财务

- 已结账期间的收付款及退款补录改为先申请、后审批，在当前未结账期间生成调整凭证，并保留审批与生成结果。
- 运费应付按销售费用－运费入账；手工应付录入时由财务选择借方科目。尚未分类的历史记录保留为待处理差异。

## 权限与操作可靠性

- 公司级打印机绑定仅允许超级管理员维护，仓库级绑定按可管理仓库范围控制。
- 手动出库和退款执行补齐重复提交保护，减少网络重试导致的重复操作。

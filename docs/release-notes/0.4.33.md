# v0.4.33

## 新功能

### 资金账户
- 新增「财务 → 资金 → 账户管理」：管理银行、现金、支付宝、微信等收付款账户。
- 每笔收付款都要指定账户，账户余额由流水自动汇总，可随时查看每个账户的收支明细。
- 账实不符时可做「余额调整」，系统按差额补一笔流水，调整过程完整留痕。

### 收款核销
- 应付账款、应收账款、供应商对账、客户对账四个页面都新增「收款/付款核销」。
- **一笔汇款可以冲抵多张订单**：录入汇款金额后勾选订单分配，或点「自动分配」按到期日从早到晚依次填满。
- 客户多汇的钱会留在汇款单上，下次可以继续核销（即预收款）。

### 汇总对账单
- 「供应商对账 / 客户对账」新增「汇总对账」：把一段时间内的多笔月结账款汇总成一张对账单。
- 确认后可**导出正式对账单**（带抬头、明细、合计与签章栏），直接发给对方核对签字。
- 对方汇款后在核销页冲抵这张对账单，系统自动分摊到下属各笔订单。

### 日常费用报销
- 新增「财务 → 费用 → 费用报销」：登记房租、水电、差旅、办公等经营费用。
- 流程为：填单 → 提交 → 审批 → 从指定账户付款，付款后自动记入账户流水。
- 支持撤回、驳回（需填原因）。**不能审批自己提交的报销单。**
- 费用类别可在「费用类别」页自行增删，已预置办公费、差旅费、交通费等 7 个常用类别。

### 资金看板
- 新增「财务 → 资金 → 资金看板」：账户余额分布、月度收支趋势、费用构成、报销待办一屏看全。

## 改进

- 六个账款类列表的查询统一收进查询弹窗，生效条件以标签显示在列表上方，可逐个移除。
- 查询的「单号」与「供应商/客户」拆成两个独立条件，不再混在一个关键字里。
- 现结页只筛创建日期；月结页可分别筛创建日期与到期日。
- 账款列表、收付款单、对账单均可导出 Excel，导出内容与当前筛选一致。

## 修复

- 修复导出 Excel 中日期显示为英文格式（如 `Wed Jul 01`）的问题。
- 修复新建费用类别时排序与备注未能保存的问题。

## 说明

- 本版含数据库结构变更（迁移 139–143），部署后需执行数据库迁移。
- 「账户管理」需要先建好账户，之后登记收付款时才能选择。历史收付款记录不会归入任何账户，不影响新账户的余额。
- 「余额调整」与「报销审批 / 付款」权限默认未分配给任何角色，请在「系统 → 权限管理」中按岗位开放。

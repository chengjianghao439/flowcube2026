# v0.9.16

仓储 PDA 收货修复，打印记录（补打）口径调整。

## 修复
- 仓储 PDA：修复收货时提示「此操作仅允许 PDA 扫码完成」、导致无法完成收货的问题。
- 收货录入：去掉没有用处的扫码框；点选商品即可收货，点一次「打印并登记」即提交，
  一个商品收完后会自动切到下一个未收完的商品。
- 打印记录：只保留有唯一编码的标签（库存条码、拆分出的散货、出库箱贴、物流面单）；
  塑料盒自身的固定编码不再出现在这里。
- 打印记录：没有可用标签打印机时也会留下打印记录，装好打印机后可在打印记录页补打
  （以前这类标签会彻底打不出来）。
- 出库条码按打印状态筛选不再报错。
- 数据安全：修复备份恢复演练的误报，现在能正确导入，不再提示「备份可能损坏」。

## 调整
- 补打只保留「打印记录」一个入口；收货订单只显示任务进度，销售订单不再显示条码打印。
- 塑料盒页面新增「打印条码」，可随时重复打印塑料盒标签。
- 收货/退货收货遇到没有可用打印机时，提示改为「已记录并留有打印记录，请配置打印机后到
  『打印记录』页补打」。

## 说明
- PDA 端需要更新到本版本后，上面的收货相关修复才会生效；请在 PDA 内更新安装包。
- 本次不改动既有业务数据；备份恢复修复仅影响恢复演练脚本与迁移执行方式。

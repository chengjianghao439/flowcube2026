# v0.4.56

## 修复
- 塑料盒新建此前一直失败（后端误拦），现在可正常创建空盒并绑定产品
- 塑料盒「详情」按钮此前无反应，现在可查看该盒的完整流转流水（拆入/拆出时间、数量、操作人）
- 拆分/并货继承效期时日期会错乱提前一天的问题已修复

## 改进
- 拆分与并货现在会在库存流水留痕：源容器记「拆出 N 到 xxx」、目标盒记「自 xxx 拆入 N」，货物流转全程可追溯
- 并货入塑料盒新增批次守卫：盒内有货且批次不一致时拒绝并入，避免混批导致效期管理出错；并入空盒时自动继承批次与效期
- 容器被拣货任务锁定后不可拆分：PDA 拆分页扫码即提示，并说明正确操作顺序（先拆分建盒、再拣货）

## 说明
- 本次为仓库作业链路加固，无操作习惯变化；桌面端功能与上版一致，仅随系统同步版本号

# v0.10.2

把系统的最小数量精度统一为两位小数。

## 改进

- **数量精度统一为两位小数**：此前系统内部按四位小数记数量（0.0001），界面上根本读不出「0.0001 件」这种数字。现在所有数量统一到两位（0.01）——下单、收货、退货、调拨、盘点、库存调整都按这个精度计算与显示。**金额与单价不受影响**：它们仍是四位小数（例如单价 8.3333 元/个），改两位会直接影响金额计算。
- **存量数据无需处理**：升级前已核对生产库，没有任何数量用到三位以上小数，因此这次调整不会改变任何历史数据。
- 「数量小数」开关（v0.10.0 引入）不受影响：不允许小数的商品仍然只能填整数，会在提交时被拦下并说明原因。

## 说明

- 本版含一处数据库结构变更：数量列的精度由 4 位调整为 2 位（共 69 列），迁移可重复执行，升级后无需人工处理。

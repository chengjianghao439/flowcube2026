# v0.4.28

本版重做了销售单的「占用库存」和「取消发货剩余」两个环节，并把订单状态名理顺，去掉了容易混淆的几种叫法。

## 新功能

- **占用库存改成选仓库弹窗**：以前「分仓发货」要在新建订单时勾选，实际上从没真正按行分过仓库。现在改到点「占用库存」时弹出选仓库的弹窗，逐个商品选发货仓库，弹窗里实时显示各仓可用库存量，不同商品可以选不同仓库发货。
- **回款信息单独一列**：销售单列表和详情页新增独立的「回款」信息（未付/部分付/已付清），逾期会标红提示，不再跟订单状态混在一起显示。
- **补全操作入口**：打印订单按钮现在所有状态下都能点（以前只有「已出库」能打印）；列表页拣货中状态补上了「继续发货」入口（以前只有详情页有，列表页找不到）。

## 修复

- 修复「修改订单」（执行期改单）会把已经派发到仓库任务的商品行误判为「未派发」的问题，避免误触发「继续发货」重复建仓库任务，并回填修复了历史数据。
- 分批发货的订单，发了一部分后主动关闭剩余，现在会把没发的商品从明细里删掉、发了一部分的商品数量改成实际发货量，订单直接显示「已出库」，不再单独区分「部分发货已结案」这种特殊状态。

## 说明

- 状态名做了精简：不再区分「履约中」和「部分发货结案」，统一叫「部分发货」；「缺货待处理」删除，连带 PDA 现场拣货上报缺货、ERP 处理缺货上报的整套功能一并下线。
- 桌面端本版无功能变更，仅随系统同步版本号。

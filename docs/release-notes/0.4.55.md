# v0.4.55

## 新功能
- **序列号商品支持逐台扫码盘点**：序列号管控的商品盘点时不再手工填写实盘数量，改由 PDA 新增的「序列号盘点」逐台扫描在架的每一台，系统自动比对账面得出结果——账面有但没扫到的，标记为盘亏丢失（精确扣减该台所在的那只容器）；扫到但账面没有的，登记为盘盈入库。此前序列号商品的盘点差异会被拦下、提示需人工核对（v0.4.53）。
  - 盘亏的序列号保留记录可追溯（标记为「盘亏丢失」），不会凭空消失。
  - 即使盘盈盘亏台数相同、总数看不出变化（丢了一台又发现一台），台账同样会逐台更正。
  - ERP 盘点单里，序列号商品行会直接显示「盘亏 N 台 / 盘盈 M 台」，提交前看得清清楚楚。

## 说明
- 非序列号商品的盘点方式完全不变，仍然直接填写实盘数量。
- 序列号管控为灰度功能、默认关闭；未开启序列号的商品不受影响。
- 至此序列号管理的收货、上架、出库、退货、拆分、改单、盘点全链路已完整闭环。

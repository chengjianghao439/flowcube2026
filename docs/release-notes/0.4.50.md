# v0.4.50

## 新功能
- **拒收品处置增加 PDA 物理扫出确认**：来料质检拒收品处置（退供应商 / 报废）从「ERP 一键作废」升级为两阶段——ERP 决定处置去向后生成处置单（待扫出），由仓库在 PDA「拒收处置」逐个扫描拒收容器条码、物理确认出场后才最终作废，全部扫完处置单自动完成。收货详情可看到每张处置单的扫出进度。

## 说明
- 处置去向（退供应商 / 报废 / 处置哪些商品）仍由 ERP 决策，PDA 只扫系统列出的容器、不自选，符合「仓库端只执行不决策」。
- 拒收品从收货起就不计库存、不进应付，本流程不影响库存与账款、不生成凭证。
- 历史处置记录（旧一键流程）不受影响。

# v0.4.73

## 新功能
- **固定资产管理**：会计模块新增固定资产卡片、按月计提折旧（直线法）、处置/报废，折旧与处置凭证自动生成并进入总账
- **多账套与合并报表**：支持建立多个会计账套（新账套自动复制科目），可切换账套查看各自账簿；集团账套可查看合并资产负债表与利润表（Σ子账套）
- **工资社保个税**：员工档案、月度工资单、社保公积金比例；个税按累计预扣法自动计算（含跨档），工资核算后一键发放并生成计提/代扣/发放凭证
- **报税数据**：会计模块新增增值税（销项/进项/应纳税额）与所得税（利润总额/应纳税所得额/应纳所得税额）申报要素，支持税会差异调整项
- **错误追踪（Sentry）**：配置后可把前端渲染错误上报到 Sentry 集中查看（聚合/版本对照）；未配置时保持原有日志上报

## 修复
- 期末结转凭证可追溯：结转来源科目明细落快照表，可查看"本张结转凭证由哪些科目汇总而来"

## 说明
- 固定资产/工资/报税均在会计菜单下新增入口
- 多账套默认保持主账套（现有数据不变）；账套切换在「合并报表 / 账套」页
- 个税、社保比例等按年度配置；未配置时按 0 处理
- PDA 端与上版一致，仅随系统同步版本号

# v0.4.74

## 新功能
- **全局搜索大幅增强**：搜索范围从商品/供应商/客户/采购/销售 5 类，扩展到采购请购、调拨、采购/销售退货、收货订单、费用报销、呆滞处置、退款单、超额放行申请、盘点单、发票等 **16 类**业务单据；搜索命中后点一下即可直接跳到对应单据详情。搜索框支持按 Enter 直接进入第一个结果
- **用户菜单**：新增「我的信息」——查看自己的账号、角色、部门与仓库数据权限；菜单整体图标化、布局更清晰
- **通知中心**：通知按严重程度排序（逾期/库存/待办），按语义色分类显示；空状态更友好

## 修复
- 全局搜索的快捷键提示改为按平台显示（macOS 显示 ⌘K，Windows/Linux 显示 Ctrl+K）
- 修复点击搜索结果时下拉可能被提前收起的问题

## 说明
- PDA 端与上版一致，仅随系统同步版本号

# v0.9.25

本版是**安全与稳定性更新**：三端依赖整体升级到当前安全版本（桌面端运行时同步到 Electron 44），并修掉一处会让发布流程长期卡住的结构问题。界面与业务功能与上一版一致。

## 安全与维护

- **桌面端运行时升级到 Electron 44**：内置 Chromium 同步到新的安全版本，办公端建议更新到本版。
- **三端依赖整体更新**：后端、前端与桌面端依赖升级到当前安全版本，依赖漏洞扫描无高危与严重项。其中包含若干主版本升级（接口限流、代码检查工具、图表库、错误上报 SDK），均已逐项核对行为差异，未发现功能变化。

## 加固

- **发布流程不再自己等自己**：此前「PDA 构建」与「浏览器部署」共用一个部署排队组，而 PDA 构建里有一步要等浏览器部署先成功——两边于是互相等待，表现为浏览器部署长时间停在等待状态且不报错，只能人工取消才能让路。现把构建、等待、发布拆成三段：构建不占用部署排队组，等待段只等待不占组，只有真正的发布段持锁。这种互相等待从结构上不会再出现。
- **新增两条自动检查**：一条要求每处代码检查禁用都必须写明原因（防止为过门禁而屏蔽问题）；一条要求项目说明里最要紧的约束必须落在实际会生效的范围内（此前的失败方式是「约束写了、却根本没进上下文」，全链路不报错）。

## 说明

- 桌面端与 PDA 界面、功能与上一版一致，仅随系统同步版本号。

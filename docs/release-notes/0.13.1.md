# v0.13.1

## 修复与界面改善

- 销售订单统一为一个“新建销售”入口，同一张订单可混合普通商品和成套配件；纯普通订单仍沿用原有开单方式。
- 成套配件资料可维护分类、供应商、单位、型号、颜色、进价与 A/B/C/D 售价，新增或重新取价按客户价格等级处理，已保存订单保留原成交依据。
- 按使用习惯统一列表、详情、选择器与弹窗的层级、间距和操作位置，改善长名称、备注、窄窗口与浅深主题下的可读性。
- 读取失败时明确提示并提供重试，保留未保存输入；改进键盘选择、弹窗返回焦点和防重复提交反馈。
- 供应商退款显示原退货单、采购单与往来对象，修复客户退款限仓查询异常。
- PDA 改善触控区域、浮层操作与扫码焦点，普通输入不再被扫码控件抢走。
- 删除仪表盘“常用工作”区块。
- 修复旧数据结构导致长备注、收货人、联系电话和详细地址保存失败的问题，原有资料完整保留。

## 说明

- 浏览器、桌面端和 PDA 同步更新。库存、预占、单据状态、核销审批、业务精度与原操作结果恢复规则保持原有含义。
- 本版保留分项验收记录和未覆盖状态；浏览器模拟 PDA 检查不等同于真机扫码，Windows 安装更新、硬件扫码与实际出纸需现场验收。

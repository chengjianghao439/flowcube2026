# v0.5.2

## 新功能

- **商品列表「申请改价」入口**：商品列表行操作新增「申请改价」，点击自动跳转改价申请页并预填商品，操作更顺畅

## 修复

- **PDA 扫码输入优化**：收货页的批次号/生产日期/效期输入框不再被扫码枪误填（此前扫码枪落在这些框会把条码字符打进去，造成脏码/错日期）
- **页面切换省电**：PDA 切到后台、ERP 隐藏标签页时暂停数据轮询（30s/60s 定时刷新），回到页面自动恢复——减少电量与流量消耗
- **性能优化**：
  - 首页仪表盘图表按需加载（首屏不再下载图表库，打开更快，PDA 低端设备尤其明显）
  - 销售占库、波次列表、盘点提交等高频操作改为批量查询，翻页与大批量操作更流畅
  - 报表/列表的日期筛选改为走索引，单据多了以后筛选依然快
- **可访问性**：表格表头补全无障碍语义（屏幕阅读器可正确读出排序状态与选中状态）

## 说明

- 本版为优化补丁版，无功能变更、无数据库结构变更
- PDA 版本同步更新（v0.5.2），请在手机上检查更新

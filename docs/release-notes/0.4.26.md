# v0.4.26

本版是一次企业级审计后的集中加固，覆盖采购收货、销售出库、库存、财务、PDA 作业多个环节，主要是把「会算错账、会丢货、缺环节」的地方补齐。

## 新功能

- **拣货缺货能上报了**：仓库现场拣货时发现库位没货，可以在 PDA 上直接上报缺口数量，订单会自动挂起并提醒 ERP 端。ERP 端一键就能「按实际能拣的数量改单」或「补货后驳回继续拣」，不用再靠微信口头沟通。
- **收货防止拿错货**：收货时扫一下商品条码核对，扫错商品会被拦下；没扫码的会先提示、二次确认才放行。
- **上架告诉你放哪儿**：扫容器后系统会推荐库位（优先放到同商品已有的库位，其次给空库位），放到别处会记录下来，为后续制定上架规则积累依据。
- **保质期管理**：商品可开启「批次管理」，开启后收货必须录批次和效期，出库自动优先发快到期的货（先到期先出）。
- **应付账款多一道财务确认**：采购收货自动结算的应付，需要财务核对明细确认后才能登记付款；金额若因补收货/退货变动会自动打回重新确认。
- **成本算得更准**：改用移动加权平均成本，卖出时固化当时成本，之后改进价不会再让历史订单的利润跟着变。
- **仓库数据权限**：可以给用户设置「只能看某几个仓库」的数据范围，多仓多团队时数据不再互相看串。
- **首页到货看板**：能看到「今天/本周该到的货」和「已逾期未到的货」，采购单列表也能一键筛逾期未到。
- **账期可配置**：供应商、客户可分别设置账期天数，应付应收到期日按各自账期生成。
- **占库存不足给明细**：整单占库时若有商品不够，会一次性列出所有不足的商品和可用量，并可一键按可用量调整订单。
- **收货订单支持按供应商筛选**；详情/表单标签页关闭后会回到所属列表页。

## 修复与加固

- 盘点提交前会核对账面，若盘点期间发生过出入库会拦下并要求刷新重盘，避免把正常业务变动误算成盘盈盘亏。
- 库存预占的异常收敛不再静默处理，触发时会留下告警痕迹便于排查。
- 短装/异常结案的单据可与正常完成区分。

## 说明

- 桌面端本版无功能变更，仅随系统同步版本号。

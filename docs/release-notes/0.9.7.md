# v0.9.7

修复调拨分批收发、财务核销与权限边界，提升账号切换和 PDA 作业的可靠性。

## 业务修复
- 调拨按实际计划量完成，支持同商品多行和整箱跨行分配；首批出库后仍可继续剩余批次，断网重试不会串单或重复记账。
- 修复资金账户并发余额、核销与资产处置相关问题，完善财务导出的数据范围与错误提示。
- 修复工资累计扣除与跨月核算顺序保护，防止后续已核算或已发放月份被上游改动影响。
- 完善仓库范围、客户门户关联和管理权限校验，避免越权访问或同名客户数据混淆。

## 客户端优化
- 修复退出后登录其他账号时，旧请求错误重放或干扰新会话的问题。
- 创建账套期间防止重复提交和切换误报，完成后自动刷新列表。
- 优化 PDA 加载体积，修复开发模式设备绑定和设备票据续期边界。
- 加强桌面更新与下载校验，清理已确认不再使用的页面辅助代码。

## 运行稳定性
- 增加数据库繁忙时的等待上限和服务就绪检查，完善部署、备份恢复的超时及资源保护。
- 更新依赖并扩充自动化回归，覆盖库存、财务、权限、客户端与运维链路。

## 说明
- 浏览器、Windows 桌面端与 Android PDA 同步升级。
- 修复不会自动改写历史业务单据；需要处理的历史异常仍须核实实际业务事实。

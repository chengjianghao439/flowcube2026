# v0.4.41

## 新功能
- **会计总账（一期）**：顶栏新增「会计」菜单，面向财务岗，把业务事实转成标准会计数据。
  - **会计科目表**：内置企业会计准则常用科目（库存现金/银行存款/应收应付/库存商品/主营收入成本/管理销售费用/应交税费等），支持按需自定义增改、树形层级、启停用；预置科目受保护不可误删。
  - **记账凭证**：一键「生成本期凭证」，自动从采购入库结算、销售出库收入与成本、收付款核销、费用报销、采购/销售退货、盘点盈亏等业务事实生成借贷平衡的记账凭证；支持手工凭证录入与红字冲销。凭证由业务事实全量重算得出，可反复生成、幂等不重复。
  - **凭证导出**：可导出「通用记账凭证 Excel」与「金蝶 KIS」格式，直接对接专业财务软件，省去会计照着系统手工敲凭证。
  - **勾稽对账**：凭证与资金流水、应付余额、应收余额自动核对，差异一眼可见。

## 说明
- 会计功能默认仅对**财务角色**开放（其他角色看不到该菜单）。
- 凭证是业务的「投影」：只读取业务数据生成凭证，**不影响任何现有单据、库存与账款流程**。

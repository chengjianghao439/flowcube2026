# v0.13.3

## 安装验收说明

- 本版仅供安装验收。仓库范围受限账号查看部分异常历史关联记录的权限问题仍未完成验证与修复；验收期间只使用合成测试数据，不用于真实业务。
- Windows 安装与更新、PDA 安装与扫码、打印机实际出纸由用户安装本版后验收；发布包和服务器检查通过不代表现场验收通过。

## 采购与收货

- 统一采购与收货录入、商品身份、数量汇总和查询条件，改善长名称、紧凑布局与详情返回后的列表位置。
- 符合资格的收货草稿可编辑，保存结果不明时按原提交核对；记录运输付款方式与金额，运输记录不生成费用、应付或库存成本。

## 操作记录与仓库交接

- 销售和价格修改保留实际差异及原因，仓库交接显示原申请与确认事实；上述已知历史关联记录权限问题仍列为未完成项。
- 改善取消与返货操作的原结果核对、只读交接和 PDA 信息呈现。

## 打印与界面

- 打印记录区分初次打印、补打和最近任务，保留原补打意图，结果未知时先核对原任务与现场纸张；确需增加一份时明确选择另补。
- 三端同步为 0.13.3，PDA versionCode 为 154。补打请使用本版前端与本版服务端；旧桌面补打不兼容本版请求规则，新前端对旧服务端补打可能出现结果无法确认。
- 改善表格虚拟滚动、查询往返、键盘与菜单焦点；保留原库存、账款及自定义打印模板。

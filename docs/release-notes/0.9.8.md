# v0.9.8

## 快递与发货
- 新增顺丰、德邦月结直连和快递账号管理页，可在同一页面新增、修改、暂停、解绑账号，并保护已有业务记录不被删除。
- 打包完成后按实际箱数准备快递订单；重量默认 1 kg，最终由快递员称重确认。结果不明确时查询原单，防止重复下单。
- 支持补充寄件资料、查看一批包裹的全部母子单号。正式自动发货仍需完成接口配置及账号验收后手动启用。

## 订单与采购
- 统一订单操作记录和作业进度，方便追踪销售、采购、收货、调拨及退货处理情况。
- 增加履约异常跟进、预计发货日期和采购需求说明，可查看缺货、在途采购及跨仓可调数量。
- 采购建议考虑包装量和起订量，并显示建议数量的计算依据；调拨和转采购仍需人工确认。

## 页面体验
- 业务列表完整加载记录，减少分页操作；全局搜索可查询历史单据。
- 整合相关业务页面和待办入口，优化表格列宽调整与长表展示。
- 完善列表排序、异步加载、会话刷新和并发修改保护。

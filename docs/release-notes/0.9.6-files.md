# v0.9.6 提交范围

本次发布包含同一任务连续完成的 PC 界面调整与商品查找修复。

- frontend/src：页面、共享组件、类型与相关测试。
- backend/src/modules/products/products.service.js：商品搜索条件、分页与关联别名修复。
- scripts/pc-ui-inventory.cjs、tests/product-finder.test.js：页面清单工具与查找回归。
- AGENTS.md 与 docs：现行规范、任务记录及发布说明。
- 三端 package/lock、Android 与 APK 清单：同步 v0.9.6 / 114。

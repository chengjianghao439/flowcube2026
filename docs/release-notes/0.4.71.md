# v0.4.71

## 新功能
- **超额放行申请**：客户授信不足时，销售员可发起「超额放行申请」走审批流（如主管/财务审批）；审批通过后，该销售单占库时自动放行，无需再单独开通放行权限。原来的紧急一次性放行仍保留
- **补货建议一键转请购**：补货建议页可勾选待补货商品，一键生成采购请购单（进入审批流程），让「系统算的建议」先过审批再成为采购承诺

## 修复
- 收紧迁移文件编号校验：新增迁移与已有编号撞号时 CI 直接失败，防止部署期才暴露问题（历史遗留编号不受影响）

## 说明
- 「超额放行申请」发起与查看权限已授予销售角色，审批走审批流配置（需在「系统 → 审批流配置」中为「超额放行申请」配置审批人）
- 补货建议生成请购单需有「采购请购」权限
- PDA 端与上版一致，仅随系统同步版本号

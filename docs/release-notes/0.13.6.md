# v0.13.6

## 安装验收说明

- 本版继续仅供使用合成数据的安装验收。异常历史关联记录的仓库权限缺口仍未完成，不据此用于真实业务验收。
- Windows 安装与更新、PDA 真机扫码和实际出纸仍待现场验证；离线测试不替代现场验收。

## 查询与列表

- 多个业务列表连续读取匹配结果，保留查询条件、详情返回位置和未提交的筛选内容；加载未完成或失败时不使用旧结果继续操作。
- 修正库存周转期初数量的计算方向和循环盘覆盖统计中的重复计数。历史时点库存与可靠历史窗口仍需进一步核对。
- 账套明细、凭证与发票日期查询按当前页面口径恢复，操作记录和处理来源按当前范围读取。

## 金额与运行保障

- 供应商退款的正向收款计入经营活动现金流入，按分汇总；保留原交易业务日期及现有账户查询范围，不重写资金或历史凭证。
- 数量继续遵守商品策略：新商品默认整数，允许小数的商品最多两位。最终订单、实际退款和资金金额按分，单价与成本保留各自精度。
- 完善应用停止时的任务、请求及回执清理等待，并增加迁移前本次备份核对。

## 升级说明

- 三端同步至0.13.6，PDA versionCode为157；请同时更新前端和服务端。
- 本版不新增SQL迁移文件，保留现有数量、退货和资金写入兼容要求。历史库存重建与旧运行期建表问题未纳入本版。

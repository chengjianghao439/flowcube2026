# v0.9.23

本版以「把口径钉死」为主：统一全站业务日期的北京时间基准、收紧数据库访问的表名与列名校验，并补齐官网上长期缺失的版本更新记录。

## 修复

- **日期筛选窗口与会计期间统一按北京时间计算**。此前部分页面的「今天」「近 N 天」「本月」和会计期间取的是**运行设备的本地时区**，在非北京时间环境（系统重装、出差改时区、UTC 容器）下会偏一天，会计期间甚至会取到相邻月份。本次统一为北京时间，覆盖销售/采购/退货等列表的查询默认窗口、账款与对账弹窗、报销单默认发生日期、运费对账当前年月，以及财务的凭证 / 账簿 / 报表 / 税务 / 合并五个页面。
- **结账相关页面的期间默认值不再错月**：会计期间对时区最敏感——月初与月末在错误时区下会落到相邻月份，直接影响关账期间的选择。

## 改进

- **官网「版本更新」补齐**：此前官网只更新到 0.9.15，0.9.16 起的内容一直没有同步（页面上看不到近七个版本的变化）。现已补齐到本版，并加了自动检查避免以后再漏。

## 加固

- **数据库访问的表名与列名统一白名单校验**。动态查询里的表名、列名、列清单与别名此前各处自行处理，现统一经白名单校验；本次同时收口了 7 个文件、12 个插值点（含 3 处「同类校验有、新增入口漏一个参数」）。

## 说明

- 桌面端界面与上一版一致，仅随系统同步版本号。

# v0.4.77

## 新功能
- **PDA 工作台全新改版**：常用作业（收货、上架、拣货、分拣、复核、打包、出库等 14 项）以大图标卡片直接展示，点一下即进入；「塑料盒拆分」等自主操作收进「更多功能」折叠区，界面更简洁
- **PDA 图标全面升级**：所有页面弃用 emoji 表情符号，统一换成规范的线性图标，视觉更专业、显示更稳定

## 移除
- **下线「来料质检」与「拒收处置」两个 PDA 作业**：采购收货后所有商品直接进入待上架，不再需要质检环节。供应商与商品的「来料质检策略」开关一并移除（已配置的历史质检容器已自动转为待上架，无数据残留）
- 数据库已相应清理质检相关的表与字段（部署时自动执行迁移）

## 修复
- 修复 PDA 在部分网络环境下误报「网络中断」的问题，登录后网络状态显示更稳定
- 修复 PDA 个别页面在宽屏下内容占满全宽的问题，所有页面统一为手机宽度布局

- PDA 端随本版更新

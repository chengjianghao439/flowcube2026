# v0.9.5

仪表盘与销售订单全面升级，优化待办处理、订单预览和风险查看，修复占库、分批发货与执行期改单的一致性问题。

## 界面与效率
- 仪表盘改为紧凑经营摘要、优先待办、风险提醒、销售趋势和应收到期分布，保留组件自定义布局。
- 待办优先展示待归还、待审批和创建较早的销售订单，可直接预览；低库存和授信风险支持完整计数及分页查看。
- 销售趋势可切换订单金额、已出库订单金额和订单数，明确单位与统计口径。
- 销售列表增加状态计数、数量进度与密度切换；右侧预览支持连续浏览和当前订单高亮。
- 新建、编辑和详情页收紧表头，增加商品明细展示空间；占库、发货及相关弹窗统一优化，完整显示商品型号、颜色和仓库信息。

## 修复与改进
- 未形成应收的订单显示“未生成应收”，避免与未付款或逾期混淆。
- 修复分批占库、发货时授信重复计算，按折后未收金额核对额度。
- 加强执行期改单和取消保护，保留多任务、部分出库及待实物归还的数量事实。
- 加强占库、释放、发货的请求重试与数量校验，支持合法小数并避免浮点误差。
- 收货联系人和电话支持更完整的信息，详细地址长度扩展为 200 字符。

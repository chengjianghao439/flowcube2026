# v0.4.72

## 新功能
- **客户授信预警**：仪表盘新增「授信预警」卡片，显示超限/接近额度的客户；销售单占库时若将超授信，会提前提示并引导发起超额放行申请
- **循环盘点自动排程**：系统每日自动重算商品 ABC 分类，并按各类盘点周期自动生成到期的抽盘单（仓库现场按单执行即可）
- **盘点覆盖率看板**：ABC 分类页新增「盘点覆盖率」，按仓库×ABC 类展示应盘、到期未盘与覆盖率
- **呆滞库存告警**：90 天未动销的库存会出现在站内通知中，提醒确认处置
- **自动建议补货点**：补货建议页按「日均销量 × 采购提前期 + 安全库存」给出建议补货点，可一键采纳（也可继续手工维护）
- **采购计划加权预测**：生成采购计划时可选「加权移动平均（WMA）」，对近期销量趋势更敏感

## 修复
- **成本对账**：新增报表页，检查「库存缓存数量」与「实际库存容器」是否一致，有差异时提示执行缓存修复
- 系统会自检数据库表结构与迁移声明的漂移（部署时校验），早发现异常

## 说明
- 呆滞天数阈值、授信预警等均有系统环境变量可调
- 本次含数据库迁移（新增需求预测明细表），部署时自动执行
- PDA 端与上版一致，仅随系统同步版本号

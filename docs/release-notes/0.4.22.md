# v0.4.22

## 新功能
- 销售退货质检支持登记"不合格数量"：不合格品会自动与合格品分开，隔离成待报废容器，不再和正常库存混在一起，退货单详情页可以看到待报废容器清单
- 打包环节支持移出装错的商品、作废整箱重新装箱，不用再联系管理员处理
- 分拣格支持设置容量阈值，分拣数量超过阈值时 PDA 端会提醒（不会阻断正常作业）
- 采购单支持「撤回确认」，收货订单支持「撤回收货」：允许把已收货（含已上架、已自动结算）的收货订单整单打回待收货，反冲库存与应付，方便现场重新收货

## 修复
- 采购结算流程简化：收货订单全部上架完成后自动结算应付、采购单自动完成，去掉了人工审核这道环节
- 撤回收货新增安全校验：已被其它出库任务锁定、或已经卖出出库的库存条码，现在会被正确拦截而不能撤回
- 修复销售退货存在不合格品时任务卡在"待上架"、永远无法推进完成的问题
- 修复已作废的打包箱可以被重新"完成打包"、导致重复打印箱贴的问题
- 修复销售单详情页、PDA 出库页把已作废的箱子错误统计为"未完成"的问题
- 修复 PDA 端收货、上架、拣货、分拣、复核、打包、出库、调拨扫码、退货等核心操作可能被设备会话校验误拦截、提交失败的问题

## 说明
- 桌面端与上版一致，仅随系统同步版本号

# v0.7.2

## 新功能

- **PDA 相机扫码修复**：绑定页「相机扫码」现在能正常调用系统摄像头了。此前该功能要求设备装有 Google 服务（GMS）扫码模块，而仓库 PDA 大多没有——已改为设备本地解码方案，扫码框一开即可连续扫描，扫到绑定密钥即自动填入

## 修复

- **系统时间统一为北京时间**：此前数据库、后端、前端各自按服务器/设备时区取「今天」，设备时区不对（出差改时区、PDA 时间被改）会导致日期显示错一天、单号日期、报表「今天」、账款到期日等口径混乱。现已全链强制北京时间——数据库默认值、后端「今天」计算、前端所有时间显示、PDA 首页问候语都按北京时间走，不再受任何环节时区影响
- **PDA 首页问候语**：改为按北京时间分时段（「早上好/下午好/晚上好」），不再受 PDA 设备时区影响

## 说明

- 本版涉及数据库时区配置与后端重启（mysql 容器需重建一次，数据卷不动、无停机）
- PDA 端无功能变化，APK 可不更新（后续随版本号同步）

# v0.4.70

## 新功能
- **部门管理**：可在系统设置中维护组织部门树与部门负责人，用户可归属到部门
- **多级审批流**：采购请购单支持配置「按金额分级、多级顺序审批」的审批流——例如小额一审、大额部门负责人+总经理逐级审批。审批进度在单据详情中逐级展示，审批人按角色/部门负责人/指定用户三种方式配置
- **待我审批**：新增待办中心，集中显示当前流转到你名下的待审批单据，点击直达审批

## 修复
- 请购单详情页审批时间显示格式修正

## 说明
- 部门管理与审批流配置权限由管理员在角色权限中手动授予（默认不开放）；审批待办对全部用户可见
- 未配置审批流的请购单维持原有单级审批，行为不变
- PDA 端与上版一致，仅随系统同步版本号

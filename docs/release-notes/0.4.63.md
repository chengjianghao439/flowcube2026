# v0.4.63

## 修复
- **安全加固**：
  - 仓库数据权限补全：销售单详情/改单/占库/出库/取消、导出、报表、看板、通知现在都会按操作人的仓库范围过滤——配置了仓库权限的用户再也看不到、也改不了其他仓库的单据
  - PDA 设备密钥、会话令牌等敏感字段不再明文写入操作日志
  - 打包相关接口要求 PDA 设备会话（此前只校验可伪造的请求头）
  - 非超级管理员不能再把账号角色提升为超级管理员
- **稳定性**：操作日志、扫码流水、库存流水、历史打印记录自动清理，数据库不再无限增长
- 系统初始化不再在数据库迁移里写死管理员密码哈希（管理员账号统一由初始化脚本创建）

## 说明
- 本版为安全与稳定性修复，桌面端/PDA 端与上版一致，仅随系统同步版本号

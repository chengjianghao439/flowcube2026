# v0.5.1

## 新功能

- **商品改价申请（走审批）**：改价不再直接生效——发起申请 → 审批通过后价格自动更新并留下变更历史（改前/改后/操作人）。可在「库存 → 商品资料 → 商品改价申请」使用；审批流程在「系统设置 → 审批流程」中配置（业务类型：商品改价申请）

## 修复

- **安全加固**：
  - 系统设置保存增加白名单校验，防止越权篡改审批阈值等关键参数
  - 角色权限调整与角色复制仅限管理员操作
  - 审计日志清理仅限管理员
  - Excel 导入错误提示不再暴露数据库内部细节
- **稳定性**：
  - 盘点提交、退款执行增加防重复提交保护（连点/断网重试不会重复入账）
  - 商品改价、审批、状态流转的内部错误统一归类，便于排查
  - 服务器日志降噪与分批清理优化
- **后台优化**：PDA 设备会话自动清理、定时任务日志可追溯、生产环境配置校验增强

## 说明

- 商品改价申请功能依赖「审批流程」配置：未配置该业务类型的审批流时，提交申请会被驳回，请在系统设置中先配置
- 本版为补丁版，其余功能与 v0.5.0 一致

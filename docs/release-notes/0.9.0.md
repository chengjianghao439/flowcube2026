# v0.9.0

## 新功能
- **角色管理增强**：可新增、删除自定义角色（系统内置角色不可删），复制角色一键带入权限。
- **权限配置页全新改版**：左侧角色列表 + 右侧权限分组，按业务域清晰组织；新增「资金与报销」「期初导入」分组，权限项改为更清爽的选中态。
- **部门 / 用户管理页升级**：标准表格、清晰的每行操作（编辑 / 删除 / 重置密码 / 仓库范围），按钮按权限显示。
- **未保存退出提示覆盖更多页面**：采购申请单、分批盘点规则、系统设置、仪表盘布局编辑后关闭标签会弹确认，不再误丢草稿。

## 修复
- 补齐了 50 个此前无法在权限配置页勾选的权限（各主数据的新建/编辑/删除、仓库作业、财务等）。
- 清理已废弃的无功能权限；隐藏运维类权限（任务调试、打印客户端回执、清理操作日志）不再出现在配置页。

## 说明
- 权限配置页仅管理员可修改；角色权限调整后需重新登录生效。

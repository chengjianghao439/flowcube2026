# v0.13.5

## 安装验收说明

- 本版继续仅供使用合成数据的安装验收。异常历史关联记录的仓库权限缺口仍未完成修复；不得据本版用于真实业务验收。
- Windows 安装与更新、PDA 真机扫码和实际出纸仍待现场验证。此前两项被平台拦截的验证未运行，不以其他自动化通过代替。

## 数量、收货与退货

- 商品数量按当前“允许小数数量”规则检查；新商品默认仅整数，数量最多两位小数，历史单位与报价保留。
- 修复收货来源成本、短装任务与剩余采购说明，保留原单需求和各批实际收货记录。
- 普通采购退货可按准确原行选择部分数量；商品、单位及原价只读，不退的行可填零或移除，仍由服务端核对剩余预算。
- 分批履约显示原需求、当前目标、实际发出与执行中数量，明确单位；PDA完成仅指当前仓库任务。

## 金额与查询

- 新订单、实际收付款、退款和核销按分校验；单价和成本保留各自精度。历史不足一分的金额保留原值并提示核对，不自动改账。
- 修复对账余额的计算尾差，供应商退款新增操作核对原采购退货的可执行金额依据，原结果查询与取消路径保留。
- 修复科目详情查询的账套参数，供应商退款在往来账显示正确名称。
- 改善工作区异常隔离、数量录入与未知操作结果的核对，保留原来源和请求身份。

## 升级说明

- 三端同步至0.13.5，PDA versionCode为156；请同时更新前端和服务端。
- 本版新增迁移288–292，新增数量与执行证明字段，历史数据不自动回填或重算。迁移不支持DDL降级；0.13.4后端不具备新写入契约，进入迁移窗口后若发布失败将保持停写，须核实迁移并向前恢复兼容后端。不能将恢复旧镜像当作数据库恢复。

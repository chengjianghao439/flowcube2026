# v0.11.1

本版修复深度验收中发现的业务串联问题，并完善用户、部门、操作记录与 PDA 作业体验。

## 业务与仓库

- 修复采购收货后的应付月结确认与对账单创建；导入客户、供应商资料时，结算方式填写错误会明确提示，避免静默保存错误值。
- 修复部分仓库任务占库数量显示和受限仓库库存可见范围；主管可处理未分配成功的分拣格任务。
- 区分未分配打印机与打印任务卡住的状态，便于工作人员定位处理。

## 用户与操作记录

- 超级管理员可以修改登录账号，修改后使用新账号登录；开发账号默认不在用户列表显示，可按需查看。
- 部门层级支持一键展开、收起，新增子部门入口更清楚；操作记录增加分页，并标识待确认的操作。
- 改进登录、退出与业务操作记录的身份和状态追踪。

## PDA 与主数据

- 修复 PDA 切换页面后任务信息可能未及时更新的问题，完善扫码任务的异常提示。
- 新建客户、供应商时可由系统生成编码；保存失败只显示一次错误提示。

## 说明

- 浏览器、桌面端与 PDA 同步更新。PDA 扫码及桌面自动更新弹窗仍需在实际设备上验收。

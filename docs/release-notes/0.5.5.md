# v0.5.5

## 新功能

- **经营 KPI 仪表盘升级**：新增「近 12 个月经营趋势」图表（GMV / 毛利折线 + 回款柱状）与「当月分仓表现」明细表，选月份后趋势、指标卡、分仓数据同步联动
- **库存缓存一键修复**：成本对账页新增「修复缓存」按钮——发现缓存漂移后可当场一键校准，附二次确认
- **库存缓存自动巡检**：系统每 30 分钟自动核对库存缓存与容器账，发现异常即刻推送钉钉告警（含明细与恢复指引），问题在变成事故前就能被发现
- **商品信息全量显示**：库存、报表、库龄、补货、盘点、处置、波次、请购等所有商品展示位置，统一补充「货号 / 型号 / 颜色」三列，同名商品不再难区分

## 优化

- **财务 / 会计 / 报表三大类页面精简**：
  - 退货退款单移入「财务 → 往来账款」（此前误放在会计）
  - 报表中心只保留经营总览，其余报表入口统一走顶部菜单，一个功能一个页面
  - 利润率表与报税口径对齐（含「其他损益」行），结账后数字不再互相矛盾
- **销售单列表**：取消批量勾选，逐单「占库」按钮改为描边样式，与已占库状态一眼区分
- **会计凭证生成修复**：多账套下「生成本期凭证」不再误写入主账套；未认证的进项发票不再计入可抵扣税额

## 修复

- **PDA 直连服务器证书问题（重要）**：Android 直连 IP 时按规范不发 SNI，服务器对这类连接曾回退临时证书导致「无法连接服务器」——已在服务器网关彻底修复，PDA 无需重装即可连接
- 全系统商品显示补「货号 / 型号 / 颜色」时，空值统一显示「—」，不影响现有数据

## 说明

- 本版包含会计后端多处口径修复，上线后会计数据以最新生成凭证为准
- 巡检默认 30 分钟一次，未配置钉钉则静默运行

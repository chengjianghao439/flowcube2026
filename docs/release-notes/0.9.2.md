# v0.9.2

修复库存占用、销售退货和财务凭证问题，完善桌面自动更新与 PDA 更新流程，提升系统稳定性与权限保护。

## 库存与仓库作业

- 修复采购到货后预计库存重复计入、出库影响其他订单占用的问题，保持可用量与占用明细一致。
- 采购撤回、取消、减量和短装结案时检查关联销售占用，避免在途供应中断后订单仍保留无效占用。
- 销售退货支持部分质检后的数量正确拆分、标签补打和继续处理；上架扫码正确识别完整条码，防止误操作其他任务的容器。

## 财务与权限

- 修复试算平衡表、资产负债表的取数问题。
- 采购结算金额变化时保留原凭证、红字和后续修订记录，避免历史凭证被覆盖；导出同步保留完整抵消关系。
- 加强超级管理员账号保护；改价审批缺少配置时给出明确提示。

## 客户端与更新

- 修复登录续期时服务器地址、并发请求及会话切换的处理问题。
- 修复桌面端更新通知漏显示，加强下载清单、证书与安装包校验。
- PDA 安装包上传完成后才公布新版本，保留旧版本下载地址，避免更新提示与实际安装包不一致。
- 发布前自动校验测试与安全扫描结果，部署失败时恢复上一版应用。

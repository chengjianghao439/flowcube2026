# v0.4.75

## 新功能
- **16 个页面统一升级为「专用查询弹窗」**：采购请购、物流运单、波次拣货、退货退款单、库存管理、商品管理、呆滞库存处置、补货建议、库龄与呆滞、货架、分拣格、超额放行申请、操作日志、记账凭证、条码打印查询、库位管理——点「查询」弹出统一的多条件筛选窗口，选好条件后一次应用；已生效条件以标签形式展示，可逐项移除或一键清空
- **查询条件大幅增强**：各页面按业务补充了日期范围、供应商/客户、状态、仓库、区域、金额区间等筛选维度（如物流运单新增按承运商和创建日期筛选、商品管理新增按状态和供应商筛选）
- **菜单重组**：仓库/库位/货架/分拣格四个页面合并为「仓库结构」一个入口，进入后顶部标签切换；「审批中心」升级为独立一级菜单；打印相关页面并入「系统」组统一管理
- **修复异常工作台跳转**：报表中「库存异常」条目的跳转入口修复，不再指向失效页面

## 修复
- PDA 端「订单分拣」入口权限判断修正：有分拣执行权限的操作员现在能正常看到并进入分拣作业
- 查询弹窗的筛选条件会保留在网址中，刷新或分享链接后筛选不丢失

## 说明
- PDA 端与上版一致，仅随系统同步版本号

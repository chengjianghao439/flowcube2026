# v0.4.35

## 新功能
- 财务新增「应收 / 应付账龄分析」：资金看板一屏看清应收、应付的总敞口与逾期分布（未到期 / 逾期各区间），并给出「催收 / 催付 Top」名单，谁欠得多、拖得久一眼可见
- 资金看板重构：月度收支、账户余额分布、账龄分布改用图表展示，比原来的文字条更直观

## 修复
- 分次付款的尾款（例如先付一半、再付剩下一半）不再被误判为「超出余额」而无法结清
- 「登记付款 / 收款」接入防重复：连点两次或断网重试，不再重复登记同一笔款
- 修复并发下对账单「已核销金额」可能算错，以及直接付款与核销核账互相卡住导致的偶发报错
- 对账单核销金额精度对齐，含分、厘的账款不再出现核不平、结不清
- 费用报销：只有本人（或管理员）能编辑 / 提交自己的报销单

## 优化
- 财务各页面（应付 / 应收账款、收付款核销、对账单、资金账户、费用报销）的查询统一收进右上角「查询」弹窗，页面更清爽；已选条件以可逐个移除的小标签显示
- 查询弹窗里的「供应商 / 客户」改为从档案中选择（与销售单一致），避免同名或输错字导致筛不到
- 供应商 / 客户对账：去掉重复的单号列与默认时间限制，逾期账款状态更清晰，操作按钮位置与列表页统一

## 说明
- 本版聚焦财务模块：新增账龄分析与看板重构，并加固了账款计算的正确性与防重复，配套自动化回归测试守护

# v0.6.0

## 新功能

- **公司 Logo 上传（品牌自定）**：系统设置页新增「品牌标识」——上传一张 Logo 图片（PNG/JPEG/WebP/SVG，≤2MB），ERP 顶栏、登录页、PDA 登录页与首页立即全端生效；不传则保持默认样式
- **单据打印模板支持公司 Logo**：销售单 / 采购单 / 出库单 / 仓库任务单打印模板新增「公司 Logo」可拖拽元素，上传过的 Logo 会自动出现在打印单据上
- **打印表格序号列可显隐**：属性面板一键开/关「显示序号列」
- **打印表格列顺序可编辑**：表格列按打印顺序排列，点选调整先后；未用到的列点「+」添加
- **打印表格列宽可拖拽**：选中表格元素后，拖动表头列分隔线直接调列宽（属性面板数字同步）
- **打印模板编辑器自动适应画布**：窗口变窄时整张纸自动缩小到完整可见（可手动缩放，点「适应」一键恢复）

## 修复

- **序号列 / 自动换行开关"点不动"**：快速连点时状态卡住——已改为函数式更新，每次点击必生效
- **打印模板"预览看到的 ≠ 打印出来的"三处偏差**：
  - 文本字段打印时多出「标签：」前缀，预览里看不到——现在预览与打印完全一致
  - 叠在表格框内的元素打印时"消失"——不再丢失，统一归入表格下方
  - 表格「高」只影响预览、打印随行数自适应——属性面板已明示
- **编辑器属性面板数字可输入非法值**：位置/尺寸/字号/边距全部限制在合理范围，不再出现"元素飞出纸面再也点不到"
- **未保存离开保护**：编辑模板后直接切走/刷新会提示保存，不再无声丢失半天工作
- **暗色主题变量修复**：修复了 CSS 编译导致暗色主题样式变量丢失的问题（当前无暗色切换入口，未来启用即生效）
- **编辑器可达性**：Tab 键可选中画布元素、方向键微调、图标按钮全部支持读屏

## 优化

- 编辑器新增：元素图层面板（重叠元素置顶/置底不再只能删了重做）、画布框选多选、坐标实时读数
- 吸附参考线与打印安全区颜色区分（此前都是粉色，拖元素时分不清）
- 工具栏新增「适应」缩放按钮；属性面板「添加列」与「打印顺序」分离，顺序一目了然

## 说明

- 上传 Logo 后，ERP 顶栏只显示 Logo 图；未上传时显示默认「极序 Flow」文字
- 打印模板块改动较大：老模板无需任何操作保持原样（序号列默认显示、各列默认顺序不变）

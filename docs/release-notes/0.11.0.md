# v0.11.0

新增常用岗位角色，完善用户与部门管理；优化 PDA 作业，并修复库存、账款和权限相关问题。

## 组织与权限

- 新增仓库作业员、库存专员、采购主管、销售主管、财务专员、会计、客服专员七个岗位角色，按岗位提供初始权限；现有账号和角色保持原有分配。
- 用户新增与编辑页面更清楚地展示账号、角色、部门和仓库范围；部门负责人、部门选择与组织结构变更可及时同步。
- 用户、角色和操作记录页面不再展示开发验收信息；操作记录减少重复的打印客户端轮询记录。

## PDA 作业

- 修复上架偏离建议库位时，快速再次扫描同一库位条码可能没有响应的问题。
- 工作台入口与实际权限保持一致；任务读取失败会说明原因并提供重试，不再误显示为“暂无任务”。
- 岗位名称显示准确，登录与作业按钮更易使用，页面支持放大；网络待确认提示更清晰。
- 改进相机扫码关闭后的资源清理，以及待确认操作在页面切换后的提醒与防重复提交。

## 业务修复

- 盘点提交会保护已占用库存，避免盘亏处理影响尚未调整的销售订单；库存出库重试和仓库范围校验更可靠。
- 修正部分发货结案金额及收付款核销精度；销售草稿重复保存不会重复写入明细。
- 采购建议翻页保持同一次预览结果，结果失效时提示刷新，避免不同批次数据混用。

## 说明

- 浏览器、桌面与 PDA 同步更新。PDA 扫码和相机行为仍需在实际设备上验收。

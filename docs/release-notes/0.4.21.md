# v0.4.21

## 修复
- 销售统计报表（月度趋势、客户/商品排行）数字修正
- 应收账款记录的单号显示修正，财务按销售单号对账现在能搜到
- 采购单取消与收货并发操作的稳定性修复
- 混单收货场景下的重复建单问题修复
- PDA 取消任务报错修复
- 容器条码生成并发稳定性提升，减少高并发收货下的失败重试
- 销售单详情"操作时间线"排序修正

## 新功能 / 体验优化
- 收货审核退回后可以重新扫码收货修正，不再卡死
- 收货允许登记超收，超收部分在收货单和审核弹窗里会标红提示
- 销售单详情页补齐发货、取消占库、取消订单、删除、打印等操作入口
- 销售单编辑体验优化，编辑已有订单时货号/型号/颜色不再丢失
- 收货单、采购单详情页现在会自动刷新最新进度，不用手动刷新页面
- PDA 扫码增加防重复保护，主要操作按钮加大了触控区域，更适合戴手套操作
- 打印机管理、拣货波次、报表等页面的查询性能优化

## 安全加固
- PDA 设备与仓库绑定的校验补齐，防止跨仓库误操作

## 说明
- 桌面端与上版一致，仅随系统同步版本号

# v0.9.1

## 新功能
- **系统设置页全新改版**：品牌标识、基础参数分区更清晰；单号前缀配置时会即时预览「生成单号的样子」；保存按钮统一到右上角；有未保存更改时顶部提示、关闭标签前提醒。
- **PDA 设备管理页对齐全站风格**：补上页面标题、行操作改为菜单（编辑 / 停用·启用 / 重置密钥）、分页统一。

## 变更
- **各类单据与编号前缀统一为两位英文**：销售 `SL`、采购 `PC`、仓库任务 `WT`、收货 `IN`、调拨 `TF`、盘点 `SC`、退货 `RT`、退款 `RF` 等，客户/供应商/商品编号前缀也统一为 `CU`、`SU`、`PR`。*只影响新生成的单号/编号，历史单据不变；可在系统设置页重新自定义。*

## 说明
- 前缀是系统默认值，如需调整到你自己习惯的写法，可在「系统设置」页修改后保存。

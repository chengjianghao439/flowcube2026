# v0.11.4

本版新增**塑料盒作业**（放货、取货、分拣复核到装箱），并修复「提交结果查询」与打包重复提交相关的几处问题。

## 新功能

**塑料盒作业**

- **每盒一种商品，同商品不同批次可混放**：每只塑料盒只装一种商品；同一种商品的不同批次可以混放在同一只盒里。
- **整件放入指定盒**：整件商品可直接放入指定的塑料盒。
- **按销售数量扫盒取货**：按当前销售单所需数量扫盒取货，系统为本次取货生成**独立的取货标签**。
- **散件还原整件**：散件可按人工填写的每箱数量还原成整件，**允许保留余量**。
- **取货标签继续走下游**：取货标签可继续用于分拣、复核与装箱。

## 修复

- **同一次提交的网络重试不会重复生效**：打包完成、装箱移出、作废箱子在提交后遇到网络中断、再次提交时，会取回第一次的结果，不再重复处理。
- **箱贴补打**：同一次补打的网络重试取回原结果，不会重复入队；补打请求也不会误拿到别的箱子的打印任务。
- **后台成功但没收到响应时，恢复入口不会再消失**：换到另一个任务的页面，仍能看到「上次那一箱 / 那一单」的待确认提示并完成确认；任务已经进入待出库时，也不会被整页提示「当前任务不能打包」挡住。
- **打包页不再把「没查到」显示成「0 箱 0 件」**：任务进入待出库后，页面仍会显示这只箱装了什么。
- **手工应付**：查询成功时不再把**输入框里改动过的单号**显示成「已创建」的单号；提示只说明已创建成功，实际单号以列表为准。
- **收付款登记、继续核销已有收付款单、退款执行**：查询结果时按**本次实际提交的那一张单据**核对，多张单据并存时不会互相认错。
- 换到另一笔单据后再查上一笔：成功后**不关闭当前正在填写或查看的弹窗**，已填内容保留。
- 提交结果未确定期间又发起过一次提交：**晚返回的旧查询不会清掉后一次提交的「未确认」提示**。

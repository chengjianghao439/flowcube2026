# v0.11.3

本版集中修复一批影响数据准确性与可恢复性的问题：导出与报表口径、作废条码打印、商品与发票的并发编辑、查找与取价、销售改单，以及转采购单在响应异常时的结果确认。

## 导出与报表

- 对账单、收付款单的导出会完整带上页面上的筛选条件，不再导出与筛选不符的数据。
- 报表不再把售价当作成本，并在明细里标明成本来源：优先采用出库时记录的成本，缺该项时按当前进价估算，确实没有成本时记 0 并给出提示。
- 修正多工作表导出时的顶部汇总与表头错位问题。

## 库存与打印

- 撤回收货后，作废的库存条码不能再补打；已排队但未领取的打印任务一并结束。

## 商品与发票编辑

- 商品价格与发票编辑增加并发保护：当同一商品/发票在你编辑期间被他人修改，保存会明确提示“内容已被他人修改”，并**保留你已填写的内容**；商品价格也不会再被旧页面回退。
- 缺少编辑版本信息的旧客户端会收到明确指引：先复制需要保留的内容，再刷新或更新后重新编辑（避免先刷新而丢草稿）。

## 查找与取价

- 客户、供应商查找窗口的选中状态更一致：列表刷新或对象被删除后，不会误确认已失效的条目。
- 商品查找每次打开都会取到最新的可售与价格信息。

## 销售与采购

- 销售改单只修改商品明细：订单客户、出库仓库与收货信息在改单页显示为只读，不会再出现“改了却未保存”的误解。
- 转采购单在结果未确认（网络中断/超时）时，可按提示先查询上次结果；在**当前页面内**用同一内容原样重试会复用上次的提交标识（含关闭弹窗后重开），**不会重复生成采购单**。**请在刷新或关闭页面前先查询结果**；若已经刷新，提交标识不再保留、也没有原查询入口，请先**核对已转数量与采购单记录**，再决定是否重新转单。

## 说明

- 本版为修复版本，网页端、桌面端与 PDA 同步更新版本号；Windows 安装包与 PDA 安装包由发布流程单独构建，不在本机产出。

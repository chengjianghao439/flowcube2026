# v0.14.3

## 订单与查询

- 销售、采购、收货、库存和报销列表更容易查看单号、状态、金额和常用操作。宽表支持键盘横向滚动，打开原单后返回可继续使用原筛选。
- 查询会显示实际使用的日期范围，倒置的日期或金额区间会在字段旁提示。没有匹配结果和读取失败分别显示。
- 退货和调拨取消选品时保留原明细。关闭改过的草稿时可以继续编辑或放弃本次修改。
- 修复采购草稿仅修改单价时偶发的保存失败，预计到货日按业务日期回填。

## 仓库与打印

- PDA 上架明确区分库存条码、库位条码和设备绑定入口。拣货完成后去分拣时带上当前任务，方便核对同商品的多张订单。
- 打印查询区分打印进度和单据状态。打印模板一次坐标输入可以一次撤销，关闭有改动的新模板前会提示。

## 财务与统计

- 发票管理按票据状态和岗位权限显示可用动作，重复进项发票会明确提示。
- 优化对账供应商选择、收款核销说明和流水日期显示。修正无源销售退货的应收凭证、利润表结转取数和运费汇总口径。

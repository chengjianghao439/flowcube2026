# v0.14.8

## 订单与仓库

- 销售占库、释占与改单联动收紧：拒绝重复明细行，完整记录分批释占依据；改单挂起期间拦截误派发、误出库，并阻止跨仓及在途货品误上架或误扣预占。
- 优化销售发货与分批出库流程：按实际核销扣减预占，收紧短发结案、换仓校验与价格核对；补齐采购、收货、退货及拣货批次的商品名与规格字段宽度，避免长文本截断。
- 加强 PDA 断网与弱网防重保护：补齐退货上架、改单拆箱/归还、塑料盒拆分与装袋的请求隔离与结果核对，统一提示文案并与账号、设备、仓库范围严格绑定。

## 财务与报表

- 修正负债与权益类科目方向、结转红冲排除、增值税净额及发货成本金额精度，确保财务凭证、期间结账与对账口径一致。
- 统一财务导出日期按北京时间输出，校准库存与角色工作台待上架统计，排除调拨在途与跨仓数据干扰。
- 加固账户、对账单与收付款并发处理顺序，降低高并发登记与核销时的锁冲突风险。

## 电脑端界面与交互

- 统一订单、仓库、财务与日志等业务列表的查询弹窗、已选筛选标签与页面视图切换，查询与返回操作更连贯。
- 统一各类业务表单弹窗为单层滚动，修正部分弹窗无障碍提示；优化日期选择、商品选择、下单单位选择、表格操作菜单、权限保存状态同步及暗色模式对比度。

## 小满与三端安全

- 加强小满跨岗位续办权限复核、转发消息引文边界识别与大商品库定向查询，优化失权后会话解绑，消除极端输入下的匹配卡顿。
- 桌面端强化渲染窗口导航与更新包启动前校验，同时保留受信任主窗口的剪贴板写入与低库存通知能力；优化 Android PDA 更新安装包目录隔离与校验流程。

## 升级说明

- 本版包含数据库结构升级（货架活跃唯一键与商品/规格字段扩宽），部署时自动执行。
- 网页、桌面端与 Android PDA 同步升级至 v0.14.8。

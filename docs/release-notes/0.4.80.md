# v0.4.80

## 新功能
- **官网宣传页上线**：访问 `jixuflow.com` 即可看到产品介绍页，支持桌面端 / PDA 安装包一键下载，网页端「进入系统」直达登录
- **域名正式启用**：系统全面切换至 `https://jixuflow.com`（HTTPS 正式证书），桌面端与 PDA 后续版本将内置域名地址

## 改进
- **打印模板编辑器增强**：
  - 标签字段面板补齐「行数/件数摘要」（物流标签）、「单位 / 售价」（产品标签）等字段
  - 新增多选操作：按住 Shift 点选多个元素，支持整组拖动、对齐画布、垂直/水平等距分布、整组复制删除
  - 表格支持自定义列：可添加自定义列名（如批次号），打印与预览同步生效
  - 标签画布预览与真机打印走同一套排版引擎，所见即所得
- **部署链路修复**：修复发布门禁烟雾检查连不上前端的问题（容器端口调整后同步更新）

## 说明
- 网页端打开 `https://jixuflow.com` 即用；老用户从登录页或书签进入不受影响
- 已安装的桌面端 / PDA 仍可正常使用，下个版本安装包起内置域名地址

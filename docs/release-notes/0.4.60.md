# v0.4.60

## 新功能
- **PDA 扫码盘点**：盘点可以在 PDA 上扫库存条码完成——
  - 单件条码（一件一码）：扫到即计 1 件，没扫到的自动判盘亏
  - 数量条码（库存条码/塑料盒）：扫码后预填账面数，实物少了直接改成实际数
  - 提交按**条码逐只精确对账**：盘亏精确扣到「没扫到/少了的那几只」，不再按先进先出摊扣；库存流水里每只条码少了多少一目了然
  - 支持断点续扫（整行覆盖提交，断网重扫不重复计）；扫错商品/别仓/失效条码当场拦截
- ERP 盘点详情页可看到哪些行来自 PDA 扫码（这些行的实盘数以扫码为准，不能手填）

## 说明
- 本次补齐「条码与序列号融合」的最后一块：盘点从「手填数量」升级为「扫条码核对」，原 ERP 手填流程保留（未扫码的行照常手填）

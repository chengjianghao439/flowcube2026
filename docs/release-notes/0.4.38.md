# v0.4.38

## 新功能
- **安全库存与补货建议**：商品可按仓库设置安全库存 / 补货点，低于阈值自动进入补货提醒；新增「补货建议」报表，一眼看清哪些货该补、补多少。
- **采购请购与审批流**：新增请购单，支持提交审批、他人审批、一键转采购单，从请购到采购全程留痕。
- **客户信用额度**：可为客户设置授信额度，占库 / 下单时自动核对未清应收与在途敞口，超额即拦截；有权限的人可一次性授权放行并留痕。
- **电子面单与物流对接**：新增运单管理与承运商平台配置，支持在线取号、自建轨迹时间线跟踪，以及运费对账。
- **循环盘点与 ABC 分类**：盘点新增「循环抽盘」方式，可按 ABC 分类 / 库区 / 手选范围抽盘，并可一键重算本仓 ABC 分类。
- **库龄与呆滞报表**：新增库存账龄分桶（0-30 / 30-60 / 60-90 / 90+ 天）与呆滞判定报表，含效期视图与估值。
- **采购计划报表**：基于历史出库与安全库存，测算各商品的毛需求 / 净需求，辅助制定采购计划。

## 说明
- 本版为多项管理功能的集中上线，均为新增能力，不改变既有收货 / 出库 / 结算流程。

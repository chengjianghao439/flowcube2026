# v0.9.13

## 打印与标签
- 打印模板默认使用可查看的真实单据和标签数据辅助排版，没有数据时保留空白模板。
- 六类条码标签增加商品型号、颜色、单位、仓库、库位、批次及日期等可选信息，可按需拖入模板。
- 修复打印回执、过期任务领取、打印机选择和多份打印问题，完善标签纸高与特殊字符处理。

## 页面与操作体验
- 操作列可与其他列一起滚动、拖动和调整宽度，避免覆盖相邻内容。
- 减少大商品列表切换页面及操作菜单的重复渲染，首页低库存计数读取更轻量。
- 优化桌面登录页与订单履约面板，完善销售草稿中的交期提示和操作状态。

## 快递账号
- 承运商资料与快递账号页面联动，切换账号时保护未保存资料，移除绑定页的删除入口。
- 顺丰提供常用服务选项，完善顺丰、德邦正式配置传递和专用测试环境校验。

## 说明
- 网页、桌面端与 PDA 同步更新。正式快递下单仍需完成平台授权、合同服务及真实订单验收后手动启用。
- 打印软件流程已验证；本次没有连接打印机，纸张效果仍需现场核对。

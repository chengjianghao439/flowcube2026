# v0.4.18

## 新功能
- **新建收货订单改为「弹窗选品」**：选好供应商后，点击「选择商品」在专用弹窗里挑选本次到货明细，弹窗内可看到订单数量、已收数量、未收数量和采购单价；确认后自动填入收货页面，主页面只保留已选商品的精简列表（可继续改数量、移除），不再和候选明细混在一张大表里。

## 修复
- 修复混合采购单收货订单（一张收货单合并多个采购单明细）审核通过后只结算其中一个采购单应付、其余漏结算的问题。
- 修复取消采购单时的联动逻辑：混合收货单场景下，取消采购单会正确移出该采购单在收货单里尚未收货的明细（收货单继续处理其余采购单）；若该采购单已产生实际收货，则会阻止取消并提示先处理收货流程，不再因为查不到关联收货单而被误放行。
- 修复采购单列表/详情页「已收数量」统计和关联收货单列表在混合收货单场景下漏算、漏显示的问题。
- 修复桌面端连接检测在切换页签时误触发重新校验、导致编辑中的表单被卸载丢失的问题。

## 说明
- 桌面端本版无独立功能变化，仅随系统同步版本号。

# v0.4.14

## 新功能
- **采购单支持货号/型号/颜色**：选择商品弹窗、新建/编辑采购单、采购单详情页统一展示编码、货号、型号、商品、颜色、单位，选品时一眼看全信息，不用再切到商品管理页核对。
- **采购单详情页新增收货进度**：已提交的采购单可直接看到「已收/应收」数量，并能点击关联的收货入库单单号直接跳转查看，不用再去另一个列表页手动查找。
- **采购单查询「经办人」改为精确下拉选择**：原来靠输入姓名模糊匹配，容易漏筛；现在从下拉列表选人，当前登录用户置顶显示。
- **仓库选择统一改为下拉快选**：采购单、销售单、库存出库、塑料箱管理等多处的「仓库」字段从弹窗选择改成下拉框，减少一次点击。
- **日期输入统一支持手动输入**：采购单、销售单、报表、对账单、付款记录等日期字段，现在既可以点日历选择，也可以直接手打日期，不用逐页翻月份。

## 优化
- 新建/编辑采购单：供应商、仓库、商品明细未填完整时，直接在对应字段标红提示，不用再对着一条模糊提示自己去找漏填在哪。
- 新建采购单的保存按钮改名为「保存草稿」，跟详情页里真正的「提交」动作区分开，避免误以为保存草稿等于已提交给供应商。
- 工作区标签之间来回切换、点顶部菜单换页，都不会再误弹「未保存确认」——只有真正关闭标签时才会提示，编辑中的内容切走了也不会丢。

## 修复
- 修复采购单详情页「预计到货」显示原始时间戳（如 `2026-04-25T16:00:00.000Z`）的问题，现在正确显示为日期。
- 修复采购单商品明细表格因新增列导致的列宽分配问题，不再有大片异常空白。
- 修复新建采购单表单里输入框未正确关联标签、删除行按钮缺少无障碍标注的问题。

## 说明
- 桌面端与网页端同步升级，桌面端本版无独立功能变化，仅随系统同步版本号。

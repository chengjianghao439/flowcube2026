# v0.13.4

## 安装验收说明

- 本版继续仅供安装验收。仓库范围受限账号查看部分异常历史关联记录的权限问题仍未完成验证与修复；验收期间只使用合成测试数据，不用于真实业务。
- Windows 安装与更新、PDA 安装与扫码、打印机实际出纸仍待现场验收；软件检查通过不代表现场验收通过。

## 查询与返回

- 采购、采购申请、调拨、退货等列表打开详情并返回时，保留已应用的日期、关键词、仓库及其他查询条件。
- 已打开的采购和销售退货页各自保留查询与单据类型；批次详情保留原筛选，承运商账号返回后保留手选账号和搜索。
- 保留查询草稿取消、确认重置、浏览历史及未保存输入的原有保护。

## 库存与收货

- 收货单可按需查看保存、标签、实收、上架与库存生效说明，沿用现有办理步骤。
- 现货、已预占、现货可用按单位解释，避免把不同单位的数量相加。预占明细连续读取并保留读取时点，异常或过期时须重新核对完整范围。
- 销售关联任务取消的提示与服务端规则一致；取消任务仍不自动释放预占。运费仍仅记录，不进入库存成本或财务金额。

## 成本与打印

- 当前成本对账保留单位成本精度，并按需说明移动均价、当前进价估值或缺失来源；超出当前显示范围时明确提示。
- 补打入口按现有单份规则处理，不接受额外份数参数；通用打印队列沿原规则。结果未知时先核对原请求和现场纸张。
- 三端同步为0.13.4，PDA versionCode为155；请同时更新前端与服务端。没有重算历史成本或修改账务口径。

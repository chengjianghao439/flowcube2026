# v0.13.7

低权限账号登录后进入自己有权限的页面；月结账款须通过对账单核销，不能按单直接付款。

## 登录与权限

- 登录后按当前账号能打开的页面落地。没有待办或仪表盘权限时，不再进入无权页面；完全没有可用页面时，提示联系管理员分配权限。
- 没有打印机查看权限时，不再请求打印机绑定接口。

## 账款

- 月结账款不能按单直接付款，须通过对账单核销；直接付款会被拒绝。
- 供应商往来默认页单独展示月结未结清应付，包括尚未出对账单的欠款，与现结分开，月结区域只读。

- 本版不新增SQL迁移文件。

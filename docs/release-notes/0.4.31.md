# v0.4.31

本版新增 PDA 设备绑定，并把仓库之间的数据隔离补齐。系统现在不只知道「谁在操作」，还知道「用的是哪台机器、这台机器属于哪个仓」。

## 新功能

- **PDA 设备绑定**：新增「系统 → PDA 设备」页面。每台 PDA 在这里登记后会生成一个绑定二维码，用 PDA 扫一下即可完成绑定，一台机器只需做一次。绑定后：
  - 绑了仓库的机器扫其他仓库的单据会被直接拒绝，杜绝跨仓误操作
  - 机器丢了在后台点「停用」，它手上的凭证立刻失效，捡到的人用不了，也不影响操作员本人
  - 怀疑凭证外泄可以「重置密钥」，旧凭证立即作废
  - 列表能看到每台机器最后一次在线时间，谁的机器没在用一目了然
  - 绑定二维码里的密钥只显示一次，关掉就查不回来了，请当场扫完
- **仓库数据隔离扩展到全部单据**：以前只有销售单和库存做了仓库隔离，采购单、收货订单、调拨单、退货单、盘点单都没有——只管上海仓的人能翻到北京仓的采购价、供应商、成本，知道单号还能直接改别人仓的单据。现在这五类单据都做了隔离：看不到、查不了、也改不动。给用户配置了仓库范围后立即生效；没配范围的用户（如管理员）不受影响。

## 修复

- **断网后「上次到底成没成」问不出来**：PDA 在网络中断时会回来向服务器确认上一次提交的结果，据此决定要不要重扫。这个查询接口后端一直没有注册，请求必然失败。销售退货收货/质检两个页面因此会直接显示红色失败，员工照着重扫就是重复入账。现已修复，并给这两个页面补上了确认兜底。
- **打包可以从电脑端完成**：建箱、装箱、移出、作废、完成打包这几个动作以前在电脑上也能操作，绕过了现场实物核对——而出库确认扫的是箱码，箱里到底装没装货就没人验过了。现在这些动作只允许 PDA 扫码完成（补打箱贴不受影响）。
- **有三个权限在角色配置里勾不到**：「在途调拨异常了结」等三个功能后端有校验、界面有按钮，但权限列表里没有对应条目，非管理员账号等于永远用不了。已补齐。

## 改进

- **超收确认改成独立弹窗**：以前超收要「再点一次同一个按钮」确认，戴着手套赶工连点两下是本能，这道闸门形同虚设。现在会弹出独立确认框，列清楚应到多少、本次多少、超收多少、大约多付多少钱，并要求选择超收原因（供应商多发 / 前次少收补发 / 扫码录错 / 其他），选了才能确认。原因会记在收货单上，财务对账时能直接区分「真多送」和「扫错了」。

## 说明

- 本版包含数据库结构调整，服务器部署时会自动执行，无需手工操作。
- PDA 设备绑定默认为「观察模式」：未绑定的机器仍可照常作业，绑定后的机器才享有跨仓保护。等所有设备都登记绑定完成后，可由管理员开启强制模式，届时未绑定的机器将无法作业。

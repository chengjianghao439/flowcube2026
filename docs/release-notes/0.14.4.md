# v0.14.4

## 订单、仓库与库存

- 修复整单取消和 PDA 同时首次拣货时的并发冲突。销售列表、总数和状态统计使用同一组筛选。
- 库存导入中断后可查原批次并继续处理失败行。旧失败行无法覆盖后来已提交的库存目标。
- 循环盘点保留已完成的类别进度，重启后可补做未完成的类别。历史库存周转依据不足时显示暂不可用，仓库看板区分真实零与查询失败。

## 财务、草稿和会话

- 凭证按业务归属账套生成，有记账记录的资金账户保留原分类。账款与对账导出采用一致的查询快照。
- 修复关闭工作区标签、固定资产处置切换和登录续期时的草稿保护。PDA 分别提示设备换绑、安装授权与实际升级状态。
- 小满的历史任务支持按操作者分页，并保留原任务和操作回执，降低历史记录增长对响应的影响。

## 服务与更新

- 网页切换时保留上一版所需的静态资源。Windows 安装包、下载清单和 GitHub 附件核对原构建摘要。
- 正式部署独立触发，使用同一提交完成网页、PDA 和 Windows 发布检查。改进数据库迁移检查、备份恢复和后台任务收尾。

# v0.9.21

本版主要让「编辑」这件事看得见：编辑时页面会明确提示正在编辑哪条记录、有没有未保存的改动，配置页改为「先查看、点编辑再修改，保存后回到查看状态」；同时把收付款与对账的几个大弹窗改成可拖拽、可记尺寸的工作区，并修掉弹窗里日期选择被裁切的问题。

## 改进

- **编辑时一眼能看出「在编辑」**：客户、供应商、仓库、库位、货架、分拣格、承运商、费用类别、部门、分类、用户、审批流、财务账户、报销单、发票、PDA 设备等编辑弹窗，以及销售单、采购单、调拨单、商品表单，编辑状态都会显示「编辑中」标识并在标题旁标出正在编辑的单号 / 编码 / 名称；有改动未保存时显示「未保存」。
- **主操作按钮统一为「保存修改」**：编辑已有记录时按钮叫「保存修改」，与新建时的「创建 / 保存 / 保存草稿」区分开，不再出现「分不清是在新建还是在编辑」。
- **配置页改成「查看 → 编辑」两步**：系统设置、权限管理、快递账号绑定、盘点 ABC 规则打开时是只读查看状态，点右上角「编辑 / 编辑规则」后才可修改；**保存成功后自动回到查看状态**并提示已保存，取消则丢弃改动。此前这几页打开就能改，点保存也只弹一句提示、页面毫无变化。
- **收付款与对账弹窗可以拖拽调整、记住尺寸**：登记付款 / 登记收款、应付结算确认、登记收付款并核销（含继续核销）、核销明细、新建对账单、对账单详情六个弹窗统一为可拖拽的工作区外观，表头与底部按钮固定、明细区自身滚动，宽表格不再把整个弹窗撑开。

## 修复

- **弹窗里的日期选择不再被裁切**：在查询条件等弹窗中点开日期时，月份表头与星期行正常显示，日历也不会再盖住其它条件；窗口高度不足时只滚动日历本体，「清除 / 今天」始终可见。
- **编辑单据不再误报「未保存」**：编辑销售单、采购单时，商品的多计量单位是后台异步带出的展示数据，不再被算成未保存改动，也不会再误弹「当前内容尚未保存，确定离开吗」。
- **保存期间继续编辑不会被当成已保存**：保存回执到达时若发现又有新的输入，页面会留在编辑状态并保留离开保护，避免后续内容被当成已保存。
- **采购单、调拨单新建保存后有明确提示**：此前保存后直接跳转，没有任何成功提示。

## 说明

- 权限管理在编辑状态切换角色时会先确认是否放弃未保存的勾选改动；只有查看权限的账号看不到「编辑」入口。
- 桌面端界面与上一版一致，仅随系统同步版本号。

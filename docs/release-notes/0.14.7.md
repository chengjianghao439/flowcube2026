# v0.14.7

## 订单与仓库

- 销售、采购、收货、退货、退款、调拨、报废和盘点统一在出错字段旁说明原因。提交时定位到第一处，保留已填内容。采购数量须为正整数，输入小数时可在原行修改。
- 销售详情集中展示订单和作业进度，旧发货安排链接回到订单信息。仓库任务链接仍可定位原作业。部分出库时切换勾选会保留已填写的出库数量。
- 库存、成套配件、补货、改价和仓龄表集中展示商品信息与关键数值。仓库结构的子页切换后保留原生效筛选，商品分类支持搜索和批量展开收起。
- PDA 盘点手输条码失败时保留条码和焦点，便于纠正后再扫。

## 财务与报表

- 余额调整会复核确认时的余额。其他经办人先改动余额时，页面显示新差额并等待再次确认。重复提交可核对原流水。
- 销售和库位的 Excel 导出与列表采用同样的生效筛选。库存价值图按原始金额显示到分。
- 资金看板提前展示账龄明细，窄屏下分栏改为单列。会计科目可按编码或名称搜索。优化固定资产录入、凭证弹窗日期焦点和报表查询日期提示。

## 电脑端体验

- 窄窗顶栏更紧凑，菜单支持键盘操作和退出回焦。小满首次打开时显示欢迎区顶部及四项快捷操作。
- 待办中心优先展示当前岗位事项和财务提醒。商品选择器可用键盘到达长列表末尾。打印模板编辑时可折叠两侧面板，条码查询与运费对账的常用操作移至页头。
- 资金账户删除、固定资产管理和 PDA 设备管理入口按岗位权限显示。

## 升级说明

- Windows 旧版用户需升级到 v0.14.7 后提交资金账户余额调整。升级前可使用已更新的网页版办理。

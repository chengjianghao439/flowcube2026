# v0.4.64

## 优化
- **列表页真分页**：销售/采购/退货/调拨/收货/账款/费用/操作日志/库存/商品 10 个列表页改为按页加载（每页 20 条），数据量大时页面不再一次性拉全部，打开更快、更流畅
- **数据库补索引**：打印机轮询、库存流水、仓库任务、销售明细四类高频查询补了 5 个索引，列表和扫码出库提速
- **接口参数加固**：后端对所有列表接口的分页参数做上限控制，防止异常请求拉取超大结果集

## 修复
- 清理了 30+ 个无人使用的接口函数和 2 个废弃组件，代码更干净

## 说明
- 本版为性能优化与代码清理，功能与上版一致；桌面端/PDA 端与上版一致，仅随系统同步版本号

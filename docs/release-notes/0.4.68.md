# v0.4.68

## 新功能
- **呆滞库存处置单**：新增「呆滞库存处置」功能——系统自动识别 90 天无出库的呆滞商品，运营圈选生成处置单，经审批后执行降价促销 / 退货供应商 / 报废（报废另留台账）。处置自动扣减库存，全程走 ERP 端
- **销售折扣**：销售单支持录入整单折扣金额（抹零、促销减让），应收按「原值 − 折扣」净额计算
- **采购价格管控**：建单/修改采购单时，单价与最近 3 次成交价偏差超过 20% 会提示预警，避免采买价异常偏离行情

## 说明
- 呆滞处置的「审批」权限由管理员在角色权限中手动授予（不默认开放）
- 桌面端/PDA 端与上版一致，仅随系统同步版本号

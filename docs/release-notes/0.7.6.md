# v0.7.6

## 修复
- 修复工资发放：有社保/公积金的账套下，工资单可正常发放（此前会因凭证借贷不平而失败）。
- 修复多账套建账：新建账套的会计科目树、试算平衡显示正确（此前子科目无法归到上级科目）。
- 修复销售列表「继续发货」按钮误显示：已全部发货的订单不再错误提示可继续发货。
- 修复跨仓库同时上架同一商品时，移动加权成本可能算错的问题。
- 修复调拨出库可整箱超量搬出、导致跨仓多搬货的问题。
- 修复呆滞处置建议数量虚高（未扣除已被销售占用的部分），避免执行时失败。
- 修复固定资产折旧最后一期漏提，累计折旧与账面净值更准确。
- 修复 2/4/6/9/11 月报税数据为空的问题（此前月末日期计算有误）。

## 安全
- 修复仓库数据权限漏洞：限仓用户不再能越权查看/修改他仓的库位、货架、分拣格、打印机、仓库任务详情与库存初始化导入。
- 修复库存初始化导入可越权调整他仓库存的问题。
- 修复手动出库重复提交导致重复扣库存的问题。
- 修复价格表导入错误提示泄露数据库内部信息的问题。

## 说明
- 登录会话安全性增强：refresh token 改为一次性轮换，泄露后无法反复续期。
- 后端运行时升级至 Node 22（Node 20 已停止安全维护）。
- 桌面端与上版一致，仅随系统同步版本号。

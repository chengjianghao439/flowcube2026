# v0.7.0

## 新功能

- **PDA 绑定页新增「相机扫码」**：PDA 的红外/激光扫码枪只能扫一维条码，扫不了绑定二维码——现在绑定页可以直接调用相机扫码，对准 ERP 屏幕上的绑定码即可完成设备绑定（仅 PDA 安装包生效，需更新 APK）
- **系统品牌与公司 Logo 明确分区**：登录页、PDA 登录页与首页固定显示「极序 Flow」系统品牌，不再被公司 Logo 顶掉；公司 Logo 只用于 ERP 顶栏与打印单据模板（上传入口在「系统设置 → 品牌标识」）

## 修复

- **桌面端显示不了公司 Logo**：桌面版是本地文件加载，浏览器里正常显示的 Logo 在桌面端一直不显示——已修复，上传 Logo 后桌面端顶栏与打印单据都会正常显示
- **PDA 未绑定设备时点作业报错**：之前未绑定的 PDA 点进作业页会直接报错，现在统一显示「受限模式」引导页，引导去绑定设备，不再弹错误

## 优化

- **界面专业名词通俗化**：波次拣货→批次拣货、呆滞→滞销、请购→采购申请、库龄→存放时长、ABC 分类→商品分档、覆盖率→按期盘点率等，仓库现场一眼看懂

## 说明

- PDA 版本已同步递增（versionCode 99），需推送到 PDA 端才会弹出更新提示
- 桌面端与上版一致，仅随系统同步版本号

# v0.4.58

## 改进
- **收货更快**：所有商品收货只需「扫商品 + 填逐箱数量」。填每箱 1 件即自动一件一码（系统逐件生成库存条码并打印标签），不再要求逐台扫厂家序列号
- **出库更快**：出库扫箱码即可，原「逐台扫序列号核销」环节整体移除（拣货扫的库存条码已唯一确定每一件）
- **盘点统一**：盘点恢复为一套流程（填实盘数量），原独立的「序列号盘点」PDA 页面移除
- **拆分/改单简化**：拆分不再要求逐台扫序列号；已拣货减量的归还确认扫容器码 + 库位码即可
- 商品档案的「序列号管理」开关移除：一物一码由系统按收货数量自动判定（每箱 1 件即个体），无需手工开关
- PDA 拆分页新增拦截：扫到「单件库存条码」会提示该条码不可拆分（一件一码，整件操作）

## 修复
- 调拨时批次商品的生产日期/效期会错前一天的问题已修复（同 v0.4.56 拆分继承效期的时区问题同源）

## 说明
- 本次为「条码与序列号融合」的第三阶段（链路改造）。系统内不再采集厂家机身码，唯一身份统一为系统打印的库存条码；历史序列号数据未在生产使用过，不受影响

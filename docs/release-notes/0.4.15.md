# v0.4.15

## 新功能
- **调拨改为「扫码收发货」两阶段流程**：调拨单确认后不再由 ERP 直接改库存，而是先在 PDA 端扫码出库（源仓库存变为「在途」），再到目标仓库扫码收货（自动上架入库）。库存变动全程有真实扫码记录，避免账实不符。
- **调拨单改为独立新建/详情页**：不再是列表页里的弹窗，新建、编辑、查看都在单独页面完成，操作更清晰，支持货号/型号/颜色两行式展示。
- **调拨、销售单明细支持货号/型号/颜色**：选品弹窗、表单明细行、详情页明细表三处统一展示货号、型号、颜色信息，跟采购单体验一致。
- **销售单查询体验对齐采购单**：新增「查询」弹窗，支持按单号、状态、客户、仓库、产品、经办人、日期区间、备注筛选，当前生效的筛选会以标签形式展示在列表上方，可逐项移除或一键清空。

## 优化
- 新建/编辑调拨单、销售单：字段未填完整时直接在对应输入框标红提示。
- 新建调拨单、销售单标题旁会显示「未保存」提示，保存按钮统一为「保存草稿」，跟真正的提交/派发动作区分开。
- 销售单号列表展示样式统一，与采购单、调拨单风格一致。
- 销售单「备注」「数量」的填写规则统一为跟采购单一样的标准：备注不再限制字数上限，数量必须填写正整数。

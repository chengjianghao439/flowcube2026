# v0.7.5

## 新功能
- 销售订单支持「按产品/按数量」占库：可只占部分产品或部分数量，未占部分留待补占。
- 新增「部分占库」订单状态：只占了一部分库存的订单会单独显示，一眼可见。
- 支持补占：已占库/部分占库订单可反复打开占库弹窗补足剩余数量。
- 取消占库支持按产品/按数量释放，也可一键整单释放。
- 已占库/部分占库订单支持修改明细（占库期改单），已占数量自动按新明细对齐。

## 修复
- 销售列表「回款状态」独立显示：未付、部分付、已付清、月结、逾期区分更清晰。
- 统一逾期判定口径：到期当天不再误判为逾期（与对账单页一致）。

## 说明
- 桌面端与上版一致，仅随系统同步版本号。

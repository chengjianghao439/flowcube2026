# v0.4.40

## 新功能
- **来料质检**：采购收货支持「先检后入」——需质检的商品收货后先进「待质检」，PDA 新增「来料质检」作业逐批判定合格 / 拒收，合格量才可扫码上架、拒收量转不合格区（不入库、不计入应付）；质检开关按商品 / 供应商配置，默认关闭，不影响未开启的商品。
- **采购计划·单据化**：需求预测的采购计划从只读报表升级为可编辑单据，可逐行调整采购量、补选供应商，再按供应商一键转成采购单草稿（仍需人工确认，绝不自动下单）。
- **商品多计量单位**：商品可维护「基本单位 + 辅助单位及换算率」（如 1 箱 = 12 件），商品列表按「件 · 箱×12」展示；库存与账款始终按基本单位记账，口径不变。
- **循环盘点·ABC 管理页**：新增「ABC 分类与循环盘规则」页，可查看 / 重算各仓库商品的 ABC 分档，并按 A/B/C 类维护盘点周期与单次抽盘上限。

## 说明
- 来料质检与多计量单位均为灰度上线（默认关闭）；未开启的商品，收发货流程与上一版完全一致。
- 桌面端与上版功能一致，随系统同步版本号。

# v0.4.78

## 新功能
- **PDA 工作台新增「作业待办通知」**：顶部显示待办任务汇总条（如「收货订单 12 · 拣货 5 · 复核 2」），各作业图标右上角带红色数字角标，一眼看清仓库里有哪些活要干，点击可直接进入对应作业；待办按本机绑定的仓库统计
- **「取消清理」更名「拣货退回」**：名称更准确，与「销售退货」区分开，避免混淆

## 优化
- **全站文案规范化**：统一了「产品 / 商品」的用词口径、省略号写法，修正了多处口语化、不通顺的提示语（如「点这里」→「点击此处」、「未清」→「未结清」、「手工录号」→「手工录入快递单号」等），并清理了页面里遗留的开发期说明文字
- **通知中心改进**：分类徽章配色统一，不再按严重程度显示红/黄误导；逾期账款等通知文案更规范
- **PDA 界面细节**：取消清理列表、改单确认列表等页面的任务卡片宽度对齐；拣货商品列表改为两列网格，一屏可看更多
- **PDA 设备绑定页**：票据状态显示更清晰（「有效 / 需重新登录以获取」）

## 修复
- 修复 403 页面文字样式失效的问题（拼写错误导致字重丢失）
- 修复部分状态文字颜色写法不统一的问题（复核、打包、设备绑定等页面的状态展示）

## 说明
- PDA 端随本版更新

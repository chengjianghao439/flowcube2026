# v0.4.54

## 新功能
- **序列号商品已拣货后也能改单减量（物理归还逐台扫码）**：序列号管控的商品在已拣货之后需要减少数量时，不再提示「取消后重新下单」——改单提交后进入仓库「改单确认」，PDA 逐台扫描「要放回货架的那几台」序列号，系统按扫到的名单把这些台从拣货容器拆出、归还到原库位，其余台继续留在任务里正常出库。台账与物理严格一致，避免序列号张冠李戴。此前这种场景被整体拦截（v0.4.53）。
  - 若归还的恰好是整只容器，直接扫容器条码 + 原库位即可，无需逐台扫。
  - 改单请求时不会立刻拆容器，只有 PDA 现场扫到具体序列号时才真正拆分归还，全程账实一致。

## 说明
- 非序列号商品的改单减量归还行为完全不变。
- 序列号管控为灰度功能、默认关闭；未开启序列号的商品不受影响。
- 序列号级盘点（逐台核对盘盈亏）仍作为后续专项。

## 日常启动及回退

电脑重启后在仓库根目录运行：

```bash
npm run dev:mysql8
npm run dev:backend
```

已有后端运行时直接复用；需要前端时另开终端运行 `npm run dev:erp`。开发网址仍为 http://localhost:5173，现有账号及密码保持不变。`npm run dev:mysql8:stop` 只停容器，保留数据卷，但停止后当前开发后端将无法访问数据库；不要在正在操作系统时执行。

旧 MySQL 9.6 保留用于回退，不再作为日常开发写入目标。需要回退时，先停止当前本地后端、另行备份切换后产生的新数据，再从私有备份恢复原 backend/.env 并启动原连接。没有新写入时可直接恢复配置；有新写入时必须先确定数据合并方案，不能丢弃新数据直接回退。不要删除 Colima 数据卷或原 MySQL 数据目录。

仓库文档和脚本仍在 `codex/local-codex-setup` 分支，未提交或推送；本机数据库及连接切换已经生效。

# 销售订单关联界面覆盖清单

范围：桌面销售订单直接打开的页面、弹窗及共用选择器。销售退货、窄屏专项、独立客户/价格/财务/仓库管理不在本轮。沿用 Impeccable，使用本地开发浏览器验收；不执行库存、订单或审批写入。

| 界面 | 处理内容 | 验证状态 |
| --- | --- | --- |
| 主列表、状态筛选、快捷搜索 | 恢复旧版独立列布局，顶部仅增加无数量分类，详见 sale-classic-layout-2026-09-05.md | 本地已复验 |
| 高级查询 | 更宽双列、紧凑排列、状态用语与列表一致 | 已打开核对 |
| 订单侧栏预览 | 保留完整商品、任务、上一单/下一单 | 本地已复验 |
| 新建、草稿编辑、占库期编辑、执行期改单 | 共用商品表，价格来源文字、数量标签、按单位汇总 | 新建、草稿编辑、执行期改单已打开；共用样式已重构 |
| 客户选择 | 窗口加宽、选择摘要截断提示、操作区固定 | 搜索/选择已验 |
| 商品选择 | 供应商型号名称统一，保留分类、搜索和价格获取 | 搜索/选择已验 |

共用 FinderModal 的宽度和页脚布局也影响其他使用它的选择器；OrderPrintOverlay 工具栏主题也供其他订单打印预览复用。未修改其他独立管理页或打印纸张格式。

最新纯样式轮：新建/编辑商品区抽为共享组件，商品身份独立列展示（按后续商品列展开规范修订），底部汇总横排；查询分区、商品查找加宽。计算、API和状态判断未在本轮更改。

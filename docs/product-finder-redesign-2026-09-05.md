# 全局商品查找重构（2026-09-05）

## 范围与显示契约

用户批准重构全局商品选择弹窗。所有调用继续共用 `ProductFinderModal`，`components/finder/ProductFinder.tsx` 仅负责统一导出；不新建各业务专用副本。销售新建、编辑、改单使用 sale 模式，采购订单和采购申请使用 purchase 模式；其他既有入口使用默认 lookup。退单页面与窄屏布局不另行重构。

| 区域 | 内容 |
| --- | --- |
| 搜索 | 名称、编码、条码、供应商型号、型号、颜色，300ms 防抖 |
| 分类 | 全部分类、可展开树；名称筛选父分类及子孙，箭头只展开 |
| 商品行 | 编码、供应商型号、型号、名称、颜色各自独立列，随后为基本单位、分类；采购显示供应商。按 `product-columns-2026-09-05.md` 展开，不合并身份单元格 |
| 场景辅助 | 销售基础参考售价；指定仓库时显示该仓可用库存，未传仓库不显示假零库存 |
| 选中摘要 | 名称、编码、完整分类路径、供应商、条码；销售说明成交价以订单为准 |
| 底部 | 真实匹配总数、完整商品列表、确认和取消；不显示分页控件 |

保留单击选择、双击确认；键盘 Space 选择，Enter 选中后确认。筛选或翻页清空选择，关闭后卸载草稿，仓库/模式变化重新挂载；防抖及查询过渡期间不可确认旧结果。空结果、分类失败、商品失败与重试分别处理。沿用主题颜色、AppDialog 拖动/缩放和默认焦点返回；新 dialogId 避免历史小尺寸覆盖新版布局。

## 数据实现

`GET /products/finder` 保留鉴权、启用商品过滤、分类后代展开与库存展示投影。扩大 keyword 匹配至 article_number/spec/color，响应增加可空 barcode；列表按 name/id 稳定排序。供应商 JOIN 改用 sup 别名，消除带仓查询与库存 s 别名冲突。库存是原有缓存投影的 quantity-reserved 下限 0，不包含采购预计供应；不用于占库或出库决策。销售参考价沿用现有基础 A 价回退，不改变客户价格等级、改单、库存或保存规则。

# 界面设计、一致性与交互体验复查计划

目标：以销售订单列表、查询、新建及详情为视觉和交互基准，在上轮修复代码的隔离预览上用正常电脑窗口和鼠标键盘比较其他模块，形成系统 UI 规范建议与优先级清单。

1. 核对工作树、服务、容器、数据库身份、资源和合成账号，复用已有专属隔离库；记录代码和环境。
2. 从登录、工作台、导航和全局搜索开始，检查信息层级、名称、页面切换、状态反馈和键盘操作。
3. 逐组检查采购、销售、库存、仓储、财务、会计、报表、系统，以及可在浏览器模拟的 PDA：列表、空态、查询弹窗、详情、返回、创建草稿、校验和错误恢复；只记录实际走到的步骤。
4. 对照页面布局、表格、日期与金额、按钮和文案，检查窄窗口和弹窗遮挡、可读性、操作焦点；跨窗口交接和角色限制以实际条件记录。
5. 记录页面、步骤、截图、现象、影响、建议和优先级，区分新发现、原问题复验、未覆盖与受阻；不将 API、组件测试、模拟 PDA 或打印回执称为真机与出纸。
6. 完成后关闭本次拥有的浏览器标签和预览进程，保留数据库与已有数据，提交可点击的报告与证据。

不自动修改业务规则，不推送、合并或部署。仅使用合成数据。

# 客户管理完整分页组件

客户管理列表页脚使用共用 `Pagination` 的 `variant="full"`，沿用 Button、Input、Radix Select 和 PaginationArrow。分页作为客户列表 section 的 footer，与表格连续排列；完整模式移除独立卡片外框、背景和圆角，跳页使用普通行内控件，不嵌套 form。其他调用不传 variant 时保留原紧凑模式。

- 左侧展示服务端总数与当前记录范围；空结果显示共 0 条、第 0–0 条。
- 右侧提供 20/50/100 条每页选择、上一页/下一页、首末页和邻近页码、省略号、页码输入及确定按钮。页码项数量有界，不随总页数分配大数组。
- 切换条数回到第一页；搜索与重置仍回到第一页。跳页只接受有效范围内的整数，支持输入框回车跳转；当前页带 `aria-current`，控件具备中文标签和键盘焦点。
- 加载期间禁用分页控件。客户列表通过 `useCustomers` 可选的保留前次数据参数稳定总数，表格在请求期间显示加载状态，避免将前一页内容误认为新页数据；其他消费者保持原查询行为。
- 删除等操作导致页码大于最新总页数时，列表在请求完成后回到有效末页。
- 仍使用原服务端分页接口与搜索参数，无数据库、权限或导出规则变更。

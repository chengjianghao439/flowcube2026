# 极序 Flow 前端 UI 标准

检查基线。依据主线 `44ccb1ffc675ce563b0fa4a280a1d49fd014e7b0` 的界面实现和现有项目约定整理，适用于 ERP 网页与 Windows 桌面端。PDA 采用本文的 PDA 条款和原作业规范。独立官网、对外查询和打印模板画布沿各自的呈现规范，ERP 内的查询、编辑和预览界面仍纳入检查。

## 通用原则

- **围绕岗位任务组织。** 销售开单、仓库执行、财务核对、系统配置各按经办人需要安排层级。首屏先呈现当前位置、关键业务事实和当前可执行的动作。标签和提示只保留有助于识别、判断或操作的信息。
- **视觉语言保持一致。** ERP 沿用灰白工作面、深蓝主操作和紧凑浅色布局。正文、辅助文字、边框、主操作、危险、警告和成功使用语义令牌。状态同时用文字传达。沿用当前字体栈、Lucide 图标和工作区与门户样式。 [颜色令牌](../frontend/src/index.css) · [ERP 样式](../frontend/src/styles/desktop-page-samples.css)
- **界面呈现业务事实。** 字段名称、单位、币种、状态、仓库、账套、日期及汇总口径来自真实数据和业务规则。区分零值、缺值、暂不可用和读取失败，历史记录按原口径展示。 [业务语义](business-semantics.md) · [数量规则](sale-shipping-quantity-policy.md) · [金额规则](cash-cents-policy.md)

## 视觉对照与退役入口验收（2026-11-24 第二版）

| 对象 | 应看到的结果 | 取证方式 |
| --- | --- | --- |
| 浮层与底图 | 打开动画结束后，菜单内每个像素由当前面板及其内容覆盖，菜单项的整行可点。表头把手、粘性列、滚动条和标签页工具不可抢到其交叠区域。 | 在有数据的列表展开菜单，保留普通、滚动、窄窗画面。在竖线与菜单项实际交汇处记录最上层 DOM、指针命中及底图。分组横线应可对应到菜单内的分隔元素。 |
| 普通录入弹窗 | 同类表单的标题、正文和底部动作有一致的边缘。采用灰底页脚时，色块连续延伸至容器内边，下方不另留一圈白边。较强的遮罩或外阴影应有相同语义的对照。 | 同视口并排比较共用表单样板与业务表单，分别量面板 box-shadow、遮罩背景、页脚边线和左、右、下内缩。打开二级选择器后另行取证。 |
| 待办与提醒 | 同级岗位使用一致的标题和分组方式。数量注明是在数事项、单据还是类别；用户可先找到最需要处理的业务。按钮明确将打开某单、列表或全部事项。 | 用非零和零任务同屏取景，记录首个可处理事项相对视口的位置、同一记录的重复入口、刷新作用域及是否显示内部排序编号。 |
| 功能退出 | 退役能力从首页组件、待办分区、设置、搜索、通知、帮助文字和详情入口同步收敛。保存的旧链接按明确的兼容规则处理。 | 以用户确认的退役范围做清单，对照当前工作树、实施提交和仍在用的业务动作；查找调用、权限、网络请求，并实际打开相关入口。 |

## 表格样式标准

同一类型、同一状态的表格按同一视觉基线核对。至少区分普通业务列表、只读明细与报表、录入明细、选择器、紧凑内嵌表、分组或树形报表。审计记录浏览器计算样式和对应源码。类型存在差异时，记录适用的组件和业务场景。

| 条款 | 验收要求 |
| --- | --- |
| 表格样式 1 · 表头 | 普通 ERP 表头沿用共用浅灰背景、细下分隔线、12 CSS px 字号和 18 CSS px 行高。标题、排序、列宽把手和选择框位于同一行基线。分组表头另保留层级。 |
| 表格样式 2 · 行与单元格 | 普通列表使用现有表体字号、左右留白和分隔线。对照当前组件的密度类型核对行高。录入、合计、跨列空态和长文本行按自身结构留出空间。 |
| 表格样式 3 · 数据对齐 | 同类名称、编号、数量、金额、日期和状态按一致的基线呈现。需纵向比较的金额、数量右对齐并使用等宽数字。日期、数量和金额可完整辨认，长名称有换行或可操作的完整值入口。 |
| 表格样式 4 · 行状态与操作列 | 有悬停、选中的表格由整行共享背景。操作列沿普通列的底色、行边框和滚动规则。危险操作仍保留对应语义色，合计行与普通数据行可区分。 |
| 表格样式 5 · 内嵌与宽表 | 明细、选择器和弹窗表格沿同一套表头、文字、分隔线和焦点视觉。需要横滚时由表格所在区域承接，表头与数据列对齐，窄窗下操作可达。 |
| 表格样式 6 · 样式来源 | 现有表格优先复用共同样式与令牌。默认密度以 `DataTable` 或同类组件为基准。已有分组、虚拟行、深嵌明细和紧凑变体可保持合乎用途的结构与密度。 |

## 表格设计标准

审核时用一条岗位任务解释这张表的用途，例如销售经办人按原单找到需跟进的订单，财务按凭证和期间核对金额。

| 条款 | 验收要求 |
| --- | --- |
| 表格设计 1 · 呈现方式 | 多行需比较、查找或连续处理时用表格。单记录的固定事实可用详情区，窄屏仓库作业按 PDA 的扫码和触控流程安排。 |
| 表格设计 2 · 默认列与主标识 | 首屏优先给出稳定的单号、编码或其他主标识和岗位关键字段。身份、时间、状态、数量及金额按任务轻重排序。每个默认列都能解释其决策用途，低频字段可从详情或已有列设置查阅。 |
| 表格设计 3 · 字段口径 | 列名说清业务口径与必要单位，例如可用量、实发量、待退金额。涉及跨仓、跨账套、时间区间或汇总范围时，使用户能够辨认生效范围。展示零值、负值及未核实值的实际含义。 |
| 表格设计 4 · 主次与操作 | 每行主入口可预期，查看、编辑、确认或作废按业务重要性和当前状态呈现。只有存在真实、可执行的批量操作时才显示勾选列，选择状态与实际对象一致。 |
| 表格设计 5 · 分组和合计 | 报表保留必要的分组表头、层级、合计与原单跳转。商品身份可在录入场景组合展示，主数据维护和需要独立比较的分析字段按岗位需要保留。 |
| 表格设计 6 · 业务覆盖 | 用代表性真实形态的合成行走过查找、比较、定位差异或进入单据的路径。以现有业务规则核对拟调整的默认列和操作入口，业务口径有疑问时记录依据和待核点。 |

## 列表、页面和输入

| 主题 | 验收要求 |
| --- | --- |
| 列交互 | 只有接口或原组件支持的列才显示排序。排序标记对应实际字段与方向。选择、列宽、重排及持久化只在支持的表格验证，按对象身份核对换页、刷新和切换条件后的选择范围。 |
| 查询和筛选 | 清楚区分正在输入的条件和本次实际应用的条件，显示生效日期、类别或仓库。清除及重置回本页约定的默认口径。权限范围和查询范围沿用现有契约。 |
| 工作区 | 菜单、标签和页标题清楚指向当前页面或组合页子视图。列表进详情再返回时恢复原列表、已应用条件、可保留的滚动和筛选草稿。切换、关闭及隐藏页刷新按工作区规则处理，未保存输入保留到用户明确处置。 |
| 表单 | 标签关联输入，必填、只读、默认值、单位、格式与错误原因清楚。错误就近显示，保留输入及可核对的上下文。数量和金额沿业务精度规则处理，已有历史事实按原口径读取。 |
| 动作与授权 | 同义动作使用一致名称。主操作与危险动作易区分。入口根据当前岗位、权限、仓库及单据状态出现。对结果有实际影响的确认应说明对象与后果，保留明确取消入口。 |
| 操作与读取反馈 | 首读、刷新、空数据、筛选无匹配、读取失败、离线、提交中、成功、明确拒绝和结果未知能区分。已确认显示可定位的结果。结果未知先查原任务或回执，避免重复办理。 |
| 页面与浮层 | 页头、业务说明、工具栏和内容区按信息层级排列。长表单和窄窗口有可访问滚动区，固定工具栏与页脚避开内容及焦点。弹窗、侧栏、选择器、菜单和提示的遮罩、焦点域与返回遵循共用组件约定。 |

## 可访问性、图表和运行端

| 主题 | 验收要求 |
| --- | --- |
| 可访问性 | 关键任务可用键盘完成。核对焦点可见、顺序、浮层关闭回焦、同页状态宣告和可读名称。表头、行、分组、交互控件按对应语义呈现。普通文字对比度至少 4.5:1，符合 WCAG 大字号定义的文字至少 3:1，状态另有文字、形状或图标。 [WCAG 2.2 对比度](https://www.w3.org/TR/WCAG22/#contrast-minimum) |
| 窗口与内容变化 | ERP 窄窗、常用窗和放大时保持主标识、关键数值、提交入口和错误信息可达。表格仅在自身区域横滚。长客户名、连续商品编码、多行备注和空内容按实际宽度呈现。 |
| 图表和汇总 | 图例、单位、周期、聚合范围与数值可读。颜色之外有明确的系列和状态说明。归零、负值、缺值和未完整加载有真实表达，图表与表格/汇总按相同已应用条件核对。以 `ChartPresentation` 和现有图表主题为基线。 |
| 大数据 | 沿现有有界读取、按需续读或虚拟化模式呈现。显示已加载量与总量的真实含义，保留最后一条记录的可达性及行内编辑焦点。隐藏、轮询和恢复保留有效条件及输入。用户可见列表沿用项目的连续浏览设计。 |
| PDA | 以仓库扫码和触控作业为中心，沿用原头栏与作业页规范。必要操作和手工数量输入至少 44 CSS px 高。始终能识别当前作业对象、扫码状态、失败/重试和结果待核对状态。扫码头、震动、系统返回与安装按真机能力另取证。 |
| Web 与 Windows | 两端共用 ERP 基线。保留平台明确提供的本机打印、安装和更新入口，条件变化时解释可用动作。用对应客户端核对平台入口和桥接反馈。 |

# PC 商品字段展开规范（2026-09-05）

用户以销售商品明细截图为准，要求其他商品显示不要合并拥挤。本规范取代此前 UI 重构记录中的商品复合单元格设计。

## 当前显示规则

商品明细按编码、供应商型号、型号、名称、颜色独立成列，单位、数量、价格及业务进度保持各自语义。名称及规格允许换行，宽表在所在区域横向滚动，不压缩成“商品 / 规格”一格。单商品抽屉和预览摘要用带标签的分格布局。查询框中的已选条件仍是简短提示，不把筛选控件变成明细表。

复用 `productIdentityColumns.tsx`（DataTable）及 `ProductIdentityCells.tsx`（手写表格、网格、摘要）。只读取当前行已有字段；缺失显示 —，不查询当前主档补历史快照，不改变字段回填、单位折算、数量、价格、权限或请求行为。

## 本次调整范围

- 全局商品查找：五项身份字段独立表头，选择、分页、键盘和回填沿用原逻辑。
- 销售：新建/编辑共用商品录入表、占库、释放占库、发货及预览摘要；原本独立列的销售详情继续保留。
- 采购、采购退货、销售退货、调拨：编辑录入表与只读明细；采购申请与转采购弹窗、采购计划明细。
- 收货：新建已选明细、采购明细选择弹窗、任务详情。
- 商品管理、库存总览和流水、容器抽屉、塑料盒绑定商品列表、改价列表。
- 盘点明细、ABC 分析、处置建议/录入/详情、拣货批次商品汇总。
- 商品报表、库存库龄、利润分析、成本对账、补货建议及生成申请确认表。

未重写已有独立字段展示。PDA、打印模板、业务规则及生产环境不在这次样式修改范围。

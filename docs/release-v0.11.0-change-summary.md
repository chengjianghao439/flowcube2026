# v0.11.0 改动总览

本版纳入两个有未提交改动的工作树：主工作区提交 `8e8421f`，审计修复工作树提交 `cf6b3bd`。其余工作树没有未提交改动。本文件按业务影响汇总具体内容；发布是否成功以单独的本版结果记录和线上同提交验证为准。

## 用户、角色与部门

- 用户管理过滤明确用于开发验收的账号，用户下拉和导出保持相同口径；后端缺省接口保留完整记录供测试和运维使用。开发身份登录时，顶栏和 PDA 问候语显示中性名称。
- 角色列表和用户、审批流的角色选择按稳定角色编码隐藏开发角色。迁移 `257_seed_job_role_presets.sql` 增加七个常用岗位，授予最小可用初始权限，不改派现有账号，不重写管理员后续调整。
- 新增/编辑用户弹窗分区、字段校验和提交反馈改进；仓库范围必须在当前授权与仓库列表均加载后才能保存。普通用户可经自助接口查看自己的资料与仓库权限。
- 部门树支持行内新增子部门、展开与收起、完整路径搜索；负责人状态、直属成员与审批流引用口径更清楚。部门删除受子部门、成员和审批流引用保护；新增、修改后刷新用户页面的部门选项。

## 操作记录与前端展示

- 操作记录列表与导出隐藏开发账号记录，以及成功的打印客户端心跳和领取轮询；错误与真正的打印操作仍保留，打印状态以打印记录页为准。
- 页面错误、更新提示与承运商历史配置不向业务用户暴露开发标记或技术细节；官网版本摘要更新为本版用户可读内容。

## PDA 作业与设备

- 上架偏离建议库位时允许明确的第二次同码实扫，仍拦截短时硬件抖动和广播/键盘双通道回放。
- 工作台四类作业入口补齐目标路由所需的查看权限；任务列表、拣货商品视图和部分详情请求失败时显示重试，不再显示空任务或无限加载。
- PDA 岗位徽标使用实际角色名称；密码显示按钮可读且可聚焦，页面可缩放；小按钮触控区域和网络待确认提示对比度调整。
- 设备作业票据绑定当前用户。待确认请求跨页面共享状态并防止同一操作重复提交；旧的无用户归属记录隔离处理，存储异常不再使流程白屏。原生相机关闭/卸载等待监听器及扫描停止后才释放所有权。

## 库存、销售、财务与采购

- 盘点落账前整单校验现货预占，拣货锁定的库存条码不被错误扣为盘亏；容器扣减拒绝非正数量。手动出库请求身份绑定商品、仓库、数量和载荷，仓库范围在条码详情及写入时校验。
- 销售部分发货结案逐行按两位金额精度汇总，草稿更新采用稳定请求键，避免重试重复写明细与操作事件。
- 收付款核销和资金账户余额累计改用四位固定点，避免浮点累计误差。采购建议预览使用有界短期快照，翻页绑定用户、范围和筛选；失效时要求刷新，事务中的计划生成仍实时计算。

## 权限与发布链路

- 角色权限仅请求内复用，仓库范围每次请求读取，避免跨进程延迟撤权。导入不支持的文件类型返回明确的业务错误；生产 CORS 禁止来源反射和通配符。
- 浏览器、PDA、桌面和诊断工作流改为固定可信 SSH 主机键；部署验收口令经标准输入传递，不放入 SSH 命令参数。发布准备已核对主机键、设置 Actions 变量，并备份及调整生产 CORS 配置。
- 新增静态、前端、MySQL 和脚本行为回归，覆盖上述权限、库存、金额、采购分页、设备生命周期和部署门禁。构建与自动测试不能替代 Windows 安装、PDA 真机扫码及相机验收。

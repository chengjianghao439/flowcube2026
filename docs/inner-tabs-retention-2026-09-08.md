# ERP 功能页内 Tab 状态保留

## 当前规则

已访问的功能子页首次打开才挂载；切换子页或工作区标签后保留实例、查询草稿、输入、选中/展开状态及滚动位置，关闭整个工作区页面后卸载并重置。不使用 localStorage 保存此次操作草稿，不承诺刷新浏览器后恢复。列宽等原有个人布局持久化沿用原规则。

查询缓存仍按 React Query 失效/刷新规则更新业务数据，保留操作状态不代表冻结金额或单据状态。已开始提交继续处理回执；隐藏子页暂停自身查询/轮询与弹层展示，不替用户取消已提交业务操作。

单据身份变化、切换会计账套、退出或权限隔离仍按原有安全边界处理，不能用缓存把其他单据或账套草稿带入。共用顶部日期/期间筛选保持既有共用语义；税务调整草稿分别归属增值税与所得税。

## 实现与覆盖

- `KeepAliveSection`：按需保留 DOM 与状态，传播 `SectionVisibilityContext`；记录所属工作区滚动容器位置。
- `KeepAliveOutlet` 和 `MergedPage`：工作区、合并中心、页内子页可见性逐层合成；会计内容仍置于 companyId 重建边界内。
- `useActiveWorkspaceTab`：同时识别子页可见性。Dialog/Sheet/Select/DropdownMenu/Popover/旧 AppDialog 使用可见性限制弹层；不调用业务关闭回调清除隐藏页草稿。打印预览同样保留 DOM、模板与缩放，隐藏时移除自身全局打印样式/监听；隐藏、关闭或卸载后不执行此前等待图片解码的打印请求。
- 财务：现结按单登记与收付款核销、月结汇总对账/核销/单据明细；核销和对账面板筛选各自保留。
- 单据：销售详情五个子页；共享订单详情的信息、进度、扫码/条码、打印、操作记录按独立视图保留。后台记录刷新失败继续保留已挂载内容。
- 库存与报表：库存总览/流水，基础统计三类，利润分析三类，库龄/效期，ABC/规则/覆盖率，会计三张报表，税务两类。
- 仓库/库位/货架/分拣格原有四个独立路由与工作区身份本来就保留各自实例，本次不合并为一个大页；PDA 扫码作业步骤与显示模式不套用 ERP 内页缓存。

## 草稿保护

- ABC 分批盘点规则切换子页后仍触发大页面未保存保护；后台刷新不得覆盖已编辑草稿。切仓先确认放弃；保存回执仅更新已提交基线，保存期间的新编辑继续保留。
- 税务各税种独立草稿，提交回执只能作用于对应税种，不能清掉另一税种或提交后的新输入。
- 库存从自身 TabPathContext 解析 URL，避免其他工作区页面参数污染本页筛选。

## 验证与发布边界

- 前端全量单测：42 个文件、211 项通过，包含公共缓存/弹层、现结与月结核销切换、税务异步回执、ABC 草稿以及打印预览隔离。
- `tsc -p frontend/tsconfig.app.json --noEmit`、受影响文件 ESLint、ERP build 通过；`npm run test:print` 的打印策略 18 项、打印状态 15 项通过。
- 本地开发浏览器（5173，真实登录）：现结收款核销查询 `RC-KEEP`，切换按单登记后返回仍保留；关闭现结客户账款大页重开，默认进入按单登记，核销查询恢复默认。
- 本地税务页：增值税调整项与金额输入后切到所得税，所得税保有独立空草稿；切回增值税以及切换其他工作区后返回均保留原输入。关闭报税数据大页重开后输入为空；未提交任何财务业务数据。
- 开发过程中旧运行实例曾显示切换重置，完整刷新加载当前代码后按上述步骤复验通过；正常使用时刷新仍按本节规则重置内存草稿。
- 浏览器会话 `flowcube-tab-retention` 验收后关闭并核验退出。测试不包含真实设备物理出纸。

本项只修改前端与说明，不修改数据库；实现纳入 v0.9.10，生产验收以同 SHA 发布结果为准。

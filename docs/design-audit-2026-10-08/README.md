## 本轮实质改动

- 列表读取失败、真实空结果、刷新和汇总分别呈现；客户、采购、退款、财务会计、打印模板和PDA不再把错误伪装为零或空表。写入口使用准确权限，来源未重新核对时暂停写入。
- 八个基础资料共用表单及客户、用户、发票、审批流独立表单保留脏输入，覆盖取消、Escape、选择器回调、提交锁、隐藏页迟到响应；没有改原409复制后刷新规则或原操作恢复资格。
- DataTable辅助备注可原位展开；四个比例列表按列权重保留可读宽度和表内滚动，固定操作列悬浮底色不透字；商品编码、供应商型号、型号、颜色与名称仍完整保留。
- 标签、Finder键盘、工作区标签键盘、弹窗返回焦点和嵌套日历Escape统一；真实浏览器反例促成Radix交互基础依赖单例，保留自然失败记录。
- 状态文字使用浅深主题的语义ink，保持业务阶段、异常提示和实际操作结果的区别；PDA普通输入不被扫码夺走，浮层暂停扫码，触控目标和错误反馈清晰可达。
- 供应商退款沿用公共列表/详情体系，明确原单身份、分配与四位金额；后端仅扩充原来源展示DTO，以及修复客户退款限仓SQL连接的既有语法错误，未修改库存或资金业务规则。

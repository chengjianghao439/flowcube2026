# 小满大页面与 Agent 缺陷修复计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 将 Agent 变为“小满”工作区大页面，替换顶部待办中心入口；仪表盘组件进入原待办中心，并修复本轮实测缺陷。

**Architecture:** 复用 HashRouter、工作区标签与 KeepAlive。新增 `/assistant` 页面及类型明确的业务预览，左侧列出当前用户最近任务；Agent 服务继续只调用正式 Flow API，保留当前鉴权、范围、幂等与确认闸门。服务端持久化可恢复的安全任务视图，前端不保存凭据或跨用户对话。

**Tech Stack:** React/TypeScript、现有组件与设计变量、Node ESM Agent 服务、node:test、Vitest。

- 用户已明确授权大页面、重命名、导航调整及修复；按该要求直接执行，不追加设计审批。

- 不提交、推送或发布；验证用既有本批专属合成测试实例。
- 主页面标题、工作区标签和导航均为“小满”。原待办中心 `/reports/role-workbench`、旧别名及 REPORT_VIEW 保留，仅移除其顶部导航。

### 正式接入补充授权

用户在发布任务明确选择“也纳入小满，等它完成验收后一起发布”，并授权通知本任务补齐正式版接入。本工作树负责代码与隔离验收，版本号、合并、推送、tag、生产配置与服务启动仍由发布任务统一处理，不提前连接或修改生产。

- 复用既有后端进程与 `/api/assistant`，将独立服务的任务运行时提取复用；模型执行仍只经原 Flow API，不增加数据库直写。
- 正式请求走当前 ERP API 与登录续期，兼容 Electron `file://` 与运行时服务器地址；禁止将当前凭据发往单独编译的 Agent URL，网络失败不自动换服务器重放。

## 最新用户设定

- 名称统一为“小满”，导航、页面、对话不显示“助手”或“Agent”。
- 小满是自然、聪明、细心、可靠的数字伙伴；工作严谨，交流仅限极序相关业务、流程、使用、排错和产品设计，禁止闲聊。简洁、温和、不卖萌、不客服腔、不反复解释人设，不假装真实人类经历。
- 人设接入实际回复入口；极序讨论仅使用本用户有限同范围上下文，不能调用工具或生成业务事实。原未支持的审批、付款、取消、发货等能力保持边界。

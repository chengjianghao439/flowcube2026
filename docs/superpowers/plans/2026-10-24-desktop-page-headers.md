# 全系统电脑端页头与说明收敛

> 历史方案：后续用户要求所有页面均保留一行小字，当前规则与实施结果见 [统一一行说明计划](2026-10-24-desktop-uniform-subtitles.md)。本文件仅记录上一轮。

目标：沿销售列表和原应用模板，常规页头只保留标题、标题旁状态、右侧操作。功能介绍删除；业务规则、读取口径和请求恢复说明保持可见且与状态区分。不改业务函数、权限、配置或 PDA。

- [x] 核对当前分支与既有修改，保存本批前快照到仓库外 header-baseline。
- [x] 盘点 PageHeader、BaseCrudPage、ActionBar 和自写仪表盘页头；ReportPanel 的区块说明不属于页面副标题。
- [x] 新增页头语义回归，先确认新状态/业务说明槽位缺失导致失败；覆盖默认紧凑页头、合并页导航、状态与重要说明保留、原按钮动作。
- [x] PageHeader 使用 status / notice 两种显式语义；状态随标题排列，notice 使用独立业务说明区；BaseCrudPage 同步接口。ActionBar 保留原状态调用与吸顶行为，统一排版。
- [x] 逐项迁移页面：删除功能介绍；编辑/未保存/运单状态移入 status；科目/分类数量及报告更新时间等元信息移入对应内容区；结账、退款、数量库存、分账、操作恢复提示完整保留为 notice。
- [x] 仪表盘自写页头接入同一组件，保留全部原控件与编辑状态；不操作原浏览器标签中的未完成编辑。
- [x] 核对所有生产入口无旧 description 页头调用，所有重要说明原文字保留，渲染前业务实现与原 onClick/onChange/disabled 不变。未知用途不批量丢弃。
- [x] 统一桌面作用域页头/状态/说明/正文间距；长标题、宽按钮组和窄窗口可换行，不裁切、不隐藏说明。
- [x] 一次运行受影响组件回归、前端约定和文档守卫；按仓库约定，lint、类型检查、构建和全量业务测试留发版前统一验证。
- [x] 本地合成预览实际核对：无副标题列表、设置编辑、重要财务规则、退款恢复、合并页、动态元信息与仪表盘；核对 1470/1024/800 宽，保留真实后台/生产/PDA 未验证边界。
- [x] 同步主题文档与逐项清单、截图和实测结果，清除临时标签及夹具，保留既有用户预览和仪表盘草稿。不提交、推送或发布。

执行结果：所有 98 处原页头 title 保持；仪表盘接入后共 99 个调用。93 页面源码与交互属性对照通过。相关 38 文件 / 306 例及最终页头/打印编辑器 2 文件 / 26 例通过；前端约定与文档守卫通过。GUI 取可见节点核对，客户/设置/采购申请常规页头为 36px、正文间距 20px。未执行 lint、类型检查、构建、全量业务回归或部署。记录与分类清单见 docs/desktop-ui-review-2026-10-24.md。

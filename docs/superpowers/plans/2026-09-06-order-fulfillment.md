# 订单异常、交期与采购建议实施计划

> 执行：使用 subagent-driven-development 分职责实现，根代理集成并执行需求及代码复核。用户已授权实现；不提交、不推送、不发布，保留前序改动。

**目标：** 将销售、采购、收货、调拨异常融入原订单进度和待办；记录承诺发货日、采购交期变更及销售影响；深化现有采购建议。

**架构：** 独立履约模块负责受原单权限约束的异常与交期 API、持久事件和提醒。采购建议复用共同供需计算并保留计划/申请原转单路径。新数据通过增量迁移加入，不修改库存事实及原状态机。

**技术：** Express/CommonJS、MySQL、React/TypeScript、React Query、现有公共表格与订单组件。

## 已确认规则

- 承诺交期以仓库实际出库为准；订单默认日期可由明细覆盖；未知供应日期显示待确认。
- 异常按来源默认负责人，无法确定则待认领，支持认领和转派；关闭必须记录结果，系统条件仍存在时不能关闭。
- 调拨展示可调仓库、数量和时间条件，进入原建单人工确认，未落实不扣采购缺口。
- 保留采购建议两个视图、首页摘要/完整待办、现结/月结分离、业务无分页、公共进度/操作记录、独立列宽。

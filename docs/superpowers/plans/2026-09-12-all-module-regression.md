# 全模块本地回归

用户要求每个模块测试一遍。以当前路由注册表和后端挂载模块为清单，区分页面/接口读取、隔离数据库回归、离线规则/构建以及暂缓的生产和设备证明。

1. 主任务通过电脑控制浏览器遍历 ERP 静态入口，每个模块检查加载、错误、主要筛选/页签和典型详情；保持本地业务数据不变。
2. 数据库专项在独立测试库串行运行，逐项保存退出码/断言/失败原因，禁止开发或生产业务库造数。
3. 独立离线任务运行各业务规则、权限、打印、运行时及 ERP/PDA 构建；另做挂载模块覆盖映射，查出遗漏和不适用项。
4. 发现实际问题后定位根因、修复、针对性复测；同步 AGENTS 和影响文档。最终提供逐模块状态，明确未验证的外部/设备/角色边界，不能以页面成功等同业务全流程成功。

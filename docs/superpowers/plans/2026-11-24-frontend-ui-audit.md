## 30 轮新增的实景验收卡

以下各行加在同编号操作卡上。每次发现新实例回填所有适用轮；共用代码相同而父容器、数据或权限不同的实例分别登记。每条记录含视口、角色、步骤、预期、实际、证据文件和未覆盖条件。

| --- | --- | --- |
| 01 | 表格样式 | 并排比对同类列表、录入、只读、内嵌、选择器及分组表；人工看表头与行、长号末字和列边界，记录滚动与浮层相交位置。 |
| 02 | 表格设计 | 按岗位完成查找一单、比较两行、辨别状态与下一动作；复核用户需要的字段、空值与单号识别，注明实际业务对象。 |

| 05 | 批量选择 | 比较选中前后整行、固定操作列及半选视觉；取消、改筛选及重选时核对对象和输入数量。 |

| 14 | 动作与权限 | 同一路径有记录/零记录/只读逐一对照；重点检查空任务大按钮、重复首单入口、历史模板中的入口。 |

## 复核交付

每轮单独列“适用对象 / 实际检查 / 缺口”。留存多张同类界面的实际画面、用户图对应位置和冲突元素，不以路径打开数量抵算交互覆盖。功能退役记录产品要求、当前分支、历史提交及调用源；用户已报告项与扩查新发现分别计数。实际穿透须用截图、命中元素或实际操作取证，孤立的 z-index 数值只登记为候选。同类表面比较保留相同视口的对照，记录独立原因，避免把所有可见灰色都记作阴影异常。

## 第一轮 · 所有表格的样式一致性

**覆盖范围**　全部在用表格实例及本轮相关的正常、悬停、选中、编辑、加载、空态和只读变体。

- [ ] 为六类表格建立样板截图及计算样式对照。至少取普通销售列表、单据只读明细或单层报表、销售/采购录入明细、商品选择器、弹窗/侧栏内嵌表和会计分组报表。另加库存虚拟宽表，对照虚拟与非虚拟呈现。记录表头颜色、字号、字重、行高、上下左右 padding、边框、对齐和滚动容器。把各类型的合法差异写入台账，PDA 中的表格按 PDA 类型另取基准。
- [ ] 逐表核对正常数据行至少一行。核对表头与表体对齐、合计和分组层级、数字与日期、长名称处理、操作列与相邻列的边界。对有选择或悬停能力的表格，另外取整行悬停、选中、禁用控件和操作列的证据。
- [ ] 逐表核对适用的空态、加载、带跨列单元格、录入长商品名、长编号与横向滚动。常用视口取 1470×900，窄 ERP 视口取 1024×768，均按 CSS 像素记录。使用图片和计算值定位不一致；同一根因影响多表时保留每个受影响实例。
- [ ] 交付表格视觉覆盖矩阵、同类基线截图、逐项差异与例外依据。仅出现空态的表仍缺正常行证据。字段该不该展示归第二轮。

**通过条件**　每个表格实例的适用状态都有截图与计算样式。同类样式一致，例外有组件或业务依据。

## 第二轮 · 所有表格的设计与业务用途

**覆盖范围**　第一轮同一批表格，按每种实际改变字段、用途、操作或汇总口径的岗位与状态核对。

- [ ] 对第一轮同一个表格对象逐个填写「谁在看、为完成什么、主要判断或操作是什么」，并写出用户最先需要看到的字段。找出无法解释用途的默认列、关键标识后置、重复信息、重要内容被藏入详情的情况。
- [ ] 逐表核对默认列、列顺序、列名、金额/数量/日期口径、零值和缺值、分组、合计及源单入口。重点用合成例比较销售状态和实发、库存可用与预占、财务应收与已核销、退货待退与已退、日志对象与发生时间。
- [ ] 用业务步骤检查主次入口和信息层级。普通业务列表验证找一张单和处理一条记录，评估录入表能否在行内核对商品与数量，选择器能否区分同名对象，报表能否追到来源和解释汇总。按真实权限和业务能力判定选择列、批量动作和原单入口。
- [ ] 交付逐表设计判定、岗位任务、实际障碍和建议的列或入口调整。依照业务说明保留分组、可比较字段和有理由的例外；字段或计算定义仍需核对的标「待验证」。字体、底色和间距归第一轮。

**通过条件**　每张表都有明确的岗位任务，用户能定位、辨认、比较和操作所需对象，关键字段和汇总口径有依据。

### 前两轮逐表执行卡

台账按「销售与客户 → 采购与供应商 → 库存、仓库作业与物流 → 财务与会计 → 报表与仪表盘 → 设置、日志和小满」分批。每批里的列表、详情、录入、弹窗、侧栏、选择器分别登记。页面只有一个表格时仍保留其路由和区域编号。共享组件对多页的影响沿受影响实例回填。

| 步骤 | 第一轮 · 样式一致性 | 第二轮 · 设计符合标准 |
| --- | --- | --- |
| 进场 | 通过记录的业务入口打开表格。对照同类样板，并用同一浏览器、视口及干净列设置取图。 | 以对应岗位打开同一入口。写下这张表用来查找、比较、录入或决策的具体任务。 |
| 检查表头 | 读背景、字号、字重、行高、内边距、边框及对齐。对照列宽、排序标记和分组表头。 | 逐列判断名词、默认顺序、主标识、读数单位、口径与必要性，并核对分组和排序依据。 |
| 检查表体 | 检查普通行、长文本行、数值行、合计或编辑行的间距、数据对齐及溢出。实际轮转悬停、选中和横滚。 | 执行一次岗位任务，记录首屏缺字段、相似记录分辨、原单跳转、合计范围，以及是否要多绕一步才能做出判断。 |
| 检查操作 | 悬停与选中时测普通列、操作列和边框。内嵌表同时核对所在面板的滚动范围。 | 核对主要操作可发现、低频操作有归处、选择列有真实用途。记录要求选择仓库、状态或对象的依据。 |
| 记录结果 | 逐条登记实际计算值、预期值或基准实例、状态、截图。只出空态或出现数据失败时留下待验证记录。 | 逐条登记岗位任务、实际操作路径、判断依据、预期行为和截图。涉及业务口径的差异关联业务文档或实际接口字段。 |

同一张库存表可同时出现两类问题。操作列独有底色归第一轮，可用量和在库量的含义难以区分归第二轮。两条记录使用同一个表格编号，各自注明受影响岗位和证据。

# 全系统取消页面分页 Implementation Plan

**Goal:** ERP、PDA 与查找弹窗展示筛选范围内的完整列表，取消用户翻页与加载更多操作。

**Architecture:** 共用 GET 数据层识别标准列表分页信封，自动以有界批次取齐后一次交给页面；保留后端单次查询上限、鉴权、仓库及账套过滤。首批及续批使用相同登录会话与账套，批次失败或数据总量变化不能伪装成完整结果。搜索游标在 API 层自动取齐。列表展示保留筛选、总数与业务操作。

**Tech Stack:** React、TypeScript、React Query、Axios、Express/MySQL 现有接口。

- [x] 编写并验证共用完整列表读取测试：超过后端批量上限、查询参数、汇总信息、失败、重复响应、取消和会话/账套绑定。
- [x] 实现完整列表读取与搜索游标自动读取；检查非标准列表信封与摘要接口，保留摘要卡片既定范围。
- [x] 移除所有页码、页大小、跳页、加载更多 UI，清理页面分页状态及纯前端切片；保留真实总数。
- [x] 核对 ERP、PDA、会计独立列表、风险与商品查找弹窗；检查限条数文案和错误状态，避免只显示首批。
- [x] 同步 AGENTS.md 与现行文档；完成定向/全量前端测试、类型检查、双端构建及本地只读验证。浏览器验收按实际可用登录条件记录。

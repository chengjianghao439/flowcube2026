# 电脑端页面样板实施计划

**目标**：按用户提供的 `00-应用合集.html` 的浅色、蓝色强调、紧凑表格与圆角面板风格，交付销售列表、真实销售表单和系统设置三个可操作样板。

**范围**：本批只改三个页面及访问它们时的 ERP 外壳呈现。官网属于后续批次；PDA、后端、配置键和值、权限、请求、数量与金额规则不改。全部交互继续使用现有组件、hooks 与 API。

**架构**：使用局部 `desktop-page-sample` / `desktop-shell-sample` 样式作用域，不覆盖全局主题。销售新建与编辑继续由现有统一编辑器承载。设置仅按已有键整理展示分组，未知键仍可见、可按原权限编辑，图片和时间戳维持原独立链路。

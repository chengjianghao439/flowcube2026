# 仪表盘与销售订单第二版实施计划

**目标：** 将用户确认的项目外第二版接入真实数据，不提交或部署。
**架构：** 保留页面路由、鉴权、React Query、业务操作及个性化布局。销售列表增加当前页批量只读投影，预览按需读取详情；应收到期分布扩展既有账龄接口。
**技术：** React / TypeScript / Tailwind / Radix Dialog，Express / MySQL。

- [x] 销售只读投影：按基本单位汇总已占、派发、出库；汇总所有任务待归还标记和授信待审批；状态计数沿用筛选与仓库范围。
- [x] 展示逻辑测试：混合单位、小数、取消和待归还优先级、未占量不冒充缺货。
- [x] 销售列表与可访问侧栏：真实商品快照、真实任务、完整详情和已有操作入口；密度可持久化；加载失败不伪装空数据。
- [x] 应收到期分布：逾期、今天、未来七天、更晚、未设置到期日；金额合计与未清应收一致，北京时间边界。
- [x] 仪表盘按确认稿调整首屏布局、待办、风险、趋势和到期分布，保持组件编辑和权限。
- [x] 类型检查、单测、隔离数据库回归、lint、构建、本地登录验收与截图。
- [x] 更新 AGENTS.md 和相关说明，复核改动范围。

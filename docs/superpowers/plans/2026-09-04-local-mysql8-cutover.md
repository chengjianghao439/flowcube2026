# 本地开发库迁移至 MySQL 8

目标：按用户授权，保留现有开发数据与账号，将本地后端从 MySQL 9.6 的 flowcube 切换到独立 MySQL 8 的 flowcube_dev8。生产连接不在本次范围内。

方式：逻辑 SQL 导出/恢复，不移动或降级原 MySQL 数据目录。旧库、原 backend/.env 和目标初始化库均保留备份；目标恢复后先验证数据，再修改本地连接。所有备份和口令仅存本机私有目录。

- [x] 显式检查迁移状态和表完整性；保留原 JWT 及其他业务配置，只切换 DB_HOST/PORT/NAME/USER/PASSWORD。

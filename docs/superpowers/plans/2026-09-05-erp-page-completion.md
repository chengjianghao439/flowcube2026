# ERP 剩余页面专项重构 Implementation Plan

**Goal:** 完成 PC 业务页面剩余专项样式重构，包含列表、详情、新建编辑和关联弹窗，并逐模块实页验证。

**Architecture:** 延续已批准的紧凑 ERP 设计；逐页处理独立结构，复用商品身份、查询栏、分区和表单结构，不改业务处理器或 API。现有销售分组保留并复核；PDA 与窄屏不做专项设计。当前任务顺序执行，不另开任务。

**Tech Stack:** React、TypeScript、Tailwind、Radix、CUA 浏览器工具。

- [x] 应收应付/对账/账户/流水/报销/退款：金额对齐，明细与录入区分，查询布局。
- [x] 会计科目/凭证/总账/报表/期间/固定资产/账套/报税：工作区层次、表格阅读、表单和操作区。
- [x] 报表中心及其分析页：指标、图表、筛选和表格分层，原始商品字段统一。
- [x] 系统设置/权限/部门/审批流/打印模板/设备/日志：独立配置布局、分区与表单。

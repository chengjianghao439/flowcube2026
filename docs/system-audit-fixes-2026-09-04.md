## 关联修复与依赖

- 测试公共入口不加载真实 `backend/.env`，要求显式本机测试库。可选择 `.env.test`，调用者变量优先；环境不合法/迁移失败立即终止。
- Node 22 使用项目 TypeScript 加载前端标签镜像，原有 5 个快照实际执行，不再跳过。
- npm audit 网络、安装或 JSON 错误必须失败；直接高危以上阻断发布，传递风险仍报告。
- 修复低磁盘门禁清理掉回退镜像、MySQL 尚未健康即迁移、手动桌面检出 ref 借用另一 SHA 绿灯，以及 CI 缺少桌面更新运行依赖等问题。
- PDA 发布先落不可变 APK，再原子切换不入 Git 的 `published-version.json`；保留旧下载 URL 对应原包。同号不同包拒绝，同包重试幂等。首次切换部署链在 Git 更新前迁移旧清单；失败恢复旧镜像前，原子还原旧 API 可读的 version.json，使其 filename 指向实际已发布包。
- 后端 mysql2 升至 **3.24.3**，qs override **6.16.0**，更新有漏洞的 brace-expansion；前端 react-router-dom 升至 **7.18.3**、xmldom 升至 **0.8.15**。React Router 保留 HashRouter 架构，新增 12 个实际 AppRouter 路由回归。
- 新增开发依赖 jsdom **26.1.0**，支持真实 DOM 回归。临时验证 venv 使用 PyYAML **6.0.3**。

升级依据包括维护者的 [React Router 安全公告](https://github.com/remix-run/react-router/security/advisories/GHSA-wrjc-x8rr-h8h6) 和 [mysql2 安全公告](https://github.com/sidorares/node-mysql2/security/advisories/GHSA-rgwj-5xj2-c3m3)。最终漏洞数来自本次 npm registry 实际审计，不以版本号推测。

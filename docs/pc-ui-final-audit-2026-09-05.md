# PC 前端样式重构收口报告

本记录接续仪表盘、销售分组、全导航页面及六组关联弹窗的重构，处理用户要求的 PC 全前端样式收口。结果位于本地工作区，未提交、推送或发布。

## 覆盖依据

不能用“菜单都打开过”推导所有弹窗都已重构。本次补充 [源码覆盖索引](pc-ui-source-inventory.md)：扫描非 PDA 专属 TSX，保留所有候选文件，并单列路由注册表、Dialog、AppDialog、Sheet、Popover、CRUD 和独立 Portal 覆盖层。当前为 226 个候选 TSX 文件、163 个弹层/CRUD/覆盖层节点及 83 个注册路由定义；后两个数字均不是独立页面或弹窗数量。注册表实际为 71 个静态入口和 12 个动态规则；登录、403、官网入口还在主路由中单独登记。与旧验收表逐项比对，唯一漏记的静态入口为 `/returns/purchase`，本轮补验其列表及新建表单；原 70 入口证据不改写成当时已经覆盖 71 个。

索引是静态定位依据，不自动证明视觉验收。共用组件、原语和不输出 UI 的桥接器不应通过无意义改写来充当“重构数量”。新增页面后可执行 `node scripts/pc-ui-inventory.cjs > docs/pc-ui-source-inventory.md` 更新候选清单。

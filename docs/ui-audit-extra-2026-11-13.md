# 极序 Flow UI 样式与交互补测

以销售订单的页面标题、状态徽标、主次按钮、筛选摘要、列表和详情页签为参照。使用正常 Chrome 窗口，在本机“隔离测试 · 非正式”预览里操作合成数据。业务流程只推进到能观察实际界面状态的位置。

| 页面 | 实际操作与看到的结果 | UI 样式与交互观察 |
| --- | --- | --- |
| 采购计划 | 在无库存的合成调入仓保存 7 件销售草稿 `SL20261113002`。生成 `PLAN000001`，展开需求与覆盖，核对净需求、建议量均为 7，另有 7 件调拨候选且未抵扣。勾选行、尝试转单、补选供应商，生成 `PC20261113002`。计划回读已转采购并可打开关联草稿，草稿为 7 件、¥0.00，保留草稿状态。 | 未选供应商时转单按钮仍可点击，随后才提示必填。可在行内直接解释并标出需补选项。选定后单击即生成草稿，按钮文案可明确说“生成采购草稿”。选定供应商后，可见文本显示供应商，但当时控件的无障碍值仍读作“待选供应商”，需要在真实读屏环境复核。零金额是本例观察，是否必须在转单前填写价格需按业务规则确认。 |
| 采购计划详情 | 在 Chrome 放大到 150% 查看计划信息，切换作业进度后恢复 100%，再查看操作记录。 | 标题、状态和页签仍在首屏。表格右侧的净需求、采购量与关联采购单超出首屏，且供应商型号、型号和颜色等次要列占用了首屏宽度。建议先露出商品、净需求、采购量和关联单据，把型号和颜色等信息移入行明细或次要列。 |
| 销售列表 | 按 `SL20261113002` 查询到 1 单，点击导出，在系统保存窗口实际保存。检查下载的工作簿，销售单号集合仅含这一单，合成备注也匹配。将已出库筛选扩大到 2025-01-01 至 2026-11-13，仍显示 0 单。 | 条件标签、结果总数与下载内容一致。100% 的销售列表仍可见右侧操作菜单被裁切，复现此前宽表问题。 |
| 仓库运营 | 从作业概况点“查看批次效率”，再切到 PDA 异常。两页均显示空态，前轮的页面停留未复现。 | 批次查询日期为 11-07 至 11-13，卡片依然写“近 30 天”，复现前轮问题。 |
| PDA 未绑定与绑定 | 浏览器逐页打开库存查询、收货、扫码上架、拣货、复核、打包、出库、分拣、盘点、调拨、销售退货、改单、拣货退回、塑料盒作业、塑料盒放货和拆分结果核对。各页有对应标题和“去绑定设备”。点击进入绑定页，手工输入无效二维码得到错误说明。经用户确认，在合成仓 `C4-8a071494` 登记“UI审查专用模拟设备”，从设备码与密钥表单绑定成功，工作台显示可执行入口与待办计数。 | 错误提示给出 ERP 设置路径。绑定页的“手动输入”有两种含义，一处输入二维码原文，另一处输入设备码和密钥。可以把按钮分别命名为“输入二维码内容”和“输入设备码与密钥”。 |
| PDA 收货与上架 | `IN20261113001` 应收 1 件，填 2 件后打开超收确认，未选原因时确认禁用。取消后仍已收 0。改收 1 件，完成页引导去上架。ERP 回读库存条码 `I000015`。创建合成货架 `UIAUDIT-R1`，ERP 分配货架条码 `H000001`。PDA 手输该货架条码报“库位编码 H000001 不存在”。同一流程录入推荐库位编码 `C4-8a071494` 后，PDA 显示上架完成，ERP 回读待上架 0、已上架 1。 | **优先**。上架步骤要求“扫描货架条码”，但本例成功值是库位编码，ERP 货架条码会被拒绝。应该先明确当前支持的标识，让页面和仓储标签用同一个术语。超收时摘要显示“提交后剩余 -1”，建议直接显示“超收 1 件”，并保留原因确认。 |
| PDA 拣货与分拣 | 拣货页按同款商品展开两个任务，明确选中 `WT20261113001`。手工输入 `I000015` 拣取 1 件，页面显示待分拣并提供“去分拣”。分拣页输入同款商品编码时，提示另一张 `WT20261112001` 尚未分配分拣格。输入保留，可以取消或重试。 | 拣货能在同款多任务时主动选择订单，分拣只展示另一张任务的错误。建议在“去分拣”交接时保留刚完成的任务号、取货码提示或明确的任务选择。浏览器宽屏下错误条横跨窗口，流程卡片和底部输入居中，两者相距较远。建议提示与当前扫码区域对齐。 |
| PDA 调拨 | 从已绑定工作台进调拨列表，`TF20261113001` 显示待出库和两仓方向，打开“调出仓扫码出库”看到整条码与剩余量限制。 | 状态、仓库方向和下一步集中在卡片上，操作用词清楚。实际调拨扫码尚待验收。 |
| 条码打印查询 | 筛选 `I000015` 后打开打印记录，显示打印任务已生成、等待客户端领取，详细记录包含请求时间和打印机。 | 展开记录只撑高“打印机 / 最近任务”单元格，导致同一行的条码、单号及操作按钮落到很低的位置，大面积留白。建议像销售订单详情一样，保留紧凑摘要行，把打印历史放到全宽展开区或侧栏。主表的“条码状态”显示“待派发”，应明确这是打印状态，便于与 ERP 的“已上架”区分。 |

界面证据由电脑操作中的截图和控件读数记录。实际导出的合成文件保存在 [销售单 Excel 样本](../output/ui-audit-extra-20261113/flowcube-ui-audit-sale-SL20261113002.xlsx)。

本轮保留了合成销售和采购草稿、采购计划、模拟设备与浏览器绑定、合成货架、收货与上架结果和待分拣任务。PDA 操作用浏览器手动录码。实体扫码、实际出纸、Windows 客户端、批次有数据时的操作、已出库销售退货、已绑定后的分拣确认及后续履约仍待验收。测试标签和预览服务已关闭。专属数据库容器正常停止，具名数据卷与合成记录保留。

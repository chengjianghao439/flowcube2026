# 系统 UI 检查续记（2026-11-12）

本记录使用 Safari 和 Chrome 正常窗口、鼠标和键盘操作本地隔离测试实例；以销售订单界面为参照。这里只记录实际观察，不把访问页面当作全部功能通过。原审查见 `docs/ui-design-audit-2026-11-12.md`。

为了补岗位检查，本轮使用准备脚本在经容器、卷、回环端口、数据库名和服务 UUID 核验的专属隔离库中新增 5 个合成账号：`ui_audit_purchaser`、`ui_audit_sales`、`ui_audit_finance`、`ui_audit_accountant`、`ui_audit_warehouse`，分别使用已有系统角色；只复用合成测试账号的加密密码值，不修改原有角色权限。账号准备不是 GUI 功能测试；账号保留供复测，不涉及正式库。

## 本轮已操作

- 采购建议：从采购菜单进入；打开生成计划，切换预测方式 SMA→WMA、选择测试仓库，再取消；后以采购员填写合成计划名称并点击生成，提示当前需求已被覆盖、无需重复生成，列表仍为 0；有缺口时生成与转单未验证。
- 采购订单：新建空单点保存，列出供应商、仓库、商品三项缺失；添加商品后取消选择仍为“暂无商品明细”。取消新建后查看合成采购单详情并切换收货进度、操作记录；未创建或更改单据。
- 补货建议：从采购建议页切换；打开查询，打开空分类选择器并关闭；输入不存在的关键字并查询、清空筛选。查询条件生效并显示筛选标签。
- 收货订单：打开查询；选择合成供应商、选择商品并确认，重置清除这两项；切换“待收货”；新建表单空提交得到“请选择供应商”；选择供应商、从原采购明细输入数量并确认，取消新建触发未保存确认，确认离开后保留原列表状态。未创建收货单。
- 收货订单详情：以管理员打开合成收货单的“结束本次收货”和“撤回收货”确认弹窗，查看说明后分别取消；没有执行结束或撤回。
- 采购退货：打开查询并取消；进入新建页，空提交显示供应商和仓库必填提示；点添加商品后取消选择，再关闭页签并确认离开。未创建退货单。

- 供应商管理：打开新增表单；将结算方式由月结切换为现结，账期字段随之隐藏；取消时出现未保存确认，选择放弃。未创建供应商。
- 供应商批量导入：展开、收起导入说明；未下载模板或上传文件。
- 销售退货：新建页添加商品后取消选择，出现与采购退货相同的空白明细；关闭页签并确认放弃，未创建退货单。
- 销售订单：打开合成拣货中订单的取消确认并选择返回，未取消；切换发货安排、拣货明细、装箱进度和操作记录。这张合成单的明细为空，不能借此验证有商品的明细展示。
- 超额放行申请：打开发起弹窗，点击搜索显示合成销售单；选中一单并输入原因，创建按钮启用；取消后立即关闭，再打开确认输入与选择已清空。未创建申请。

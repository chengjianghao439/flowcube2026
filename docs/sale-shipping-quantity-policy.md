# 全数量规则与固定销售单位

用户于 2026-10-13 10:47 UTC 确认：有些商品是不可拆的整体，商品数量开关须覆盖所有数量。本文替代本分支此前仅出货草稿；代码仍未提交、未发布。

## 商品规则

复用 `product_items.allow_decimal_qty`，界面为“允许小数数量”，新建默认关闭，编辑保留原值，不批量改存量商品。关闭时数量必须是整数；开启时最多两位小数。原量先校验，不通过则拒绝，不先取整。零、正数、负数方向及上限继续由各业务约束；价格、成本、金额、百分比及统计比率保留各自精度。

采购/退货录入量与未经取整的基本量分别校验，不能用 0.5 箱乘 2 得到 1 件来绕过整数规则，不能把无效基础量静默舍入。保留采购直接建单接口的整数约束、完整整数套数、一件一码保护、PDA 拆分原限制及授权/仓库/事务/业务额度校验，不因勾选小数而放开独立限制。

覆盖数量写入口：采购、请购、采购计划和包装/MOQ、收货/上架、销售、预占/释放、仓库及退货任务生成、拣货/复核/分拣/装箱/出库、销售及采购退货、调拨、库存调整/盘点、库存导入、容器创建/扣减/拆分/批量创建/取货及库存同步。数量规则以当前商品为准，旧策略快照和客户端选项不能豁免。

平均销量 ADU 等统计比率不是实物数量，不自动改其统计方法；计划实际建议/调整数量在生成或写入前额外校验，整件商品不存不合法的执行数量。不会为通过校验擅自把比例建议取整成一件。

## 安全切换和锁

从允许小数切换为关闭时，服务端检查逐个非空库存条码、库存/预占余额、在途绑定、未完成单据/任务、盘点条码、有效数量配置和当前套件组成，以及仍可退的原销售/采购/成交批次数量。发现小数即 409 `PRODUCT_QTY_POLICY_CONFLICT`，保留原开关与全部业务事实，不自动改账。两个条码分别 0.3 和 0.7，即使合计 1 仍构成冲突。

已完成历史输入、已发生流水和打印保持原事实；取消且无后续数量义务的单据不阻止切换。已发 0.3、已退 0.1、剩余可退 0.2 时，即使库存为 0 也拒绝关闭，避免未来退货无路可走。旧系统已经存在“标志关闭但事实有小数”的商品不自动修正；数量执行会拒绝不合法值，需显式开启并按原业务核对处理。

默认仓库存策略可在同一修改请求中明确替换成整数后关闭；其他仓小数策略、包装或在途业务仍须先处理。开关的请求键重放只返回原结果，不多改一次版本。

数量事务对商品行作当前共享读，批量 ID 升序；策略锁先于库存维度与条码锁。关闭持商品排他锁；关闭事务使用 READ COMMITTED，只读检查业务依赖，不反向锁单头/库存。若数量写入先持锁并提交小数，关闭读到最新事实并拒绝；若关闭先提交，写入读取关闭后的规则并拒绝。

采购上架还要更新平均成本，因此在任何商品共享锁、库存维度和条码锁之前取得商品排他锁，避免两仓同时上架发生共享锁升级死锁。只调整本次新增锁所需顺序，不改成本算法。销售出库任务由原单事务连接生成，策略锁与任务写入一起提交；不再接受无事务连接的生成调用。所有现有正式调用均提供事务连接。

盘点建单采用两阶段账面读取：首次仅发现有货候选商品，按 ID 升序共享锁定其当前策略，再在 READ COMMITTED 下只重读这些已锁商品的 ACTIVE 账面量，逐项校验后落明细。等锁期间耗尽的商品不会写入陈旧小数账面；候选发现后新出现的 SKU 由后续盘点覆盖。该读路径不锁库存维度或容器，不形成“容器→商品”的逆序；关闭排他锁等待建单提交后会读到新盘点依赖。

## 固定销售单位及历史边界

新销售只用当前商品唯一 `unit`，没有辅助单位选择或 `product_units` 折算分支；再买/复制也是新业务，使用当前单位与数量规则，不能把原箱数当件数。采购辅助单位及必要旧退货处理保留。

未变历史行保留原 `unit`、`entry_unit`、`entry_qty`、`conversion_rate`、单价、金额和身份；旧包装字段只供事实回显/只读预览，不重新读取主档换算率。旧换算行改数量须显式以当前固定单位重录，不自动转换或重新定价；未变原行的基本数量仍按当前规则校验。

`allow_decimal_qty_snapshot` 和商业组原策略记录仅是历史创建时的审计事实，NULL 不代表当前放行。历史事实不被当前开关追溯改写；未来操作必须满足当前规则。因此此前“关闭后原 0.3 仍可履约/退货”的演示不作为本轮正确行为：现在关闭动作被拒绝，保留开启后按原事实履约/退货。

商业销售物理行按商品和仓库复用 ID 时，无履约历史的重新录入行同时保存当前 `unit`/`entry_unit`，避免新组件与物理行单位不一致；未变的保留行保持原录入量、换算率、价格及空审计值。有已占/已派/已发量、非草稿状态、仓库任务、退货、预占或预计绑定历史的物理行不得替换单位，409 `SALE_FIXED_UNIT_CHANGED`，必须保留原行或另建销售单；旧组件的单位快照不覆写。历史退货来源仍读原确认批次的单位/售价；新建退货库存容器沿原流程使用当前主档单位，该行为没有在本轮更改。

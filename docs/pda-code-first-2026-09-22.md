## 实现

- `PdaProductIdentity` 统一以编码为首行、加粗等宽字体，不截短编码；名称作为第二行。调用方必须指定 `overview` 或 `detail`。
- 商品总览：拣货汇总、收货选货、盘点选货、销售退货选货使用 overview，名称单行省略；原始名称保留，进入原作业入口后可查看全名。拣货汇总仍是单列，卡片补充待拣数量、进度、已有的型号/颜色/供应商型号与关联单数；同一商品关联多任务时先选任务，避免误入第一张任务。
- 商品/任务详情：拣货、收货编辑、复核、打包、出库、调入/调出、盘点作业、分拣结果、退货收货与取消退回使用 detail，名称完整换行。取消退回优先显示实际库存条码；其余有商品编码的入口显示商品编码。规格、颜色等详细资料保持完整。
- 任务总览：单号保留为主要标识，客户、供应商、调拨仓库组合、分拣格辅助名称可用 `PdaOverviewText` 单行显示。不会把全目录的业务详情统一改回省略号。
- 盘点具体商品的全名移到正文，导航标题优先编码，避免长名称撑高顶部。
- 截断守卫只有一个精确例外：`PdaOverviewText` 的指定样式字面量。ERP 与 PDA 详情仍受守卫检查；组件测试明确验证 overview/detail 的不同语义以及编码始终不截断。

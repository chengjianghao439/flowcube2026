# 打印模板默认真实数据预览

本文保留实现时的验证记录；相关代码已纳入 v0.9.12 发布准备，实际发布结果以 `docs/release-v0.9.12-result.md` 为准。

新建及编辑打印模板时，自动以当前账号能查看的对应业务记录显示字段、条码与明细。真实数据只用来查看排版效果，不会写进模板，也不会创建打印任务。

- 已有布局直接套入数据；初始空画布有记录时提供默认字段布局，可撤销，适配当前纸张尺寸。手工改动或清空后不会因接口重试再次插入元素。
- 无记录时保留现有空白画布/字段占位；无查看权限给出简短说明。加载失败保留布局，提供重试。真实记录缺少字段或明细时保持为空，不拼入虚构示例。
- 后端 GET `/api/print-templates/preview-data?type=1..10`：先模板查看权限，再原业务查看权限及仓库范围。只读查询一条最新可访问记录；返回 null 或 `{ type, sourceLabel, kind, record/data }`，无列表全量拉取、无打印入队。
- 类型1销售、2采购、3沿用现有退货打印消费者、4仓库任务；5货架、6库存容器、7物流箱、8商品、9塑料盒、10库位。单据复用既有打印映射，标签字段遵循真实标签命令口径。
- 前端按类型与登录会话代次隔离请求，使用取消信号，隐藏页面不发起新取数；迟到响应不能替换其他类型或账号的当前数据。默认30秒查询缓存，仅驻留内存，离开后回收。

## 验证

- 新回归先观察缺功能失败：后端新增路由被旧 `/:id` 捕获导致500；前端6组中5组因缺真实数据功能失败。后续新增刷新失败、撤权后失败重试回归也先失败再修复。
- 后端独立回环随机 `flowcube_printfix_*_test` 数据库：真实预览17组、既有打印队列8组通过；测试库已清理，不连接生产或开发业务库运行清理测试。
- 隔离修复工作树前端全部47个测试文件、251项通过，其中模板编辑器13项、适配与纸张边界6项；类型检查、定向ESLint和ERP构建通过。构建保留既有queryClient静态/动态导入提示。
- 主工作区同步14个本次专属路径，AGENTS.md定向更新；同步前核对旧文件及新增路径无冲突，保留前轮打印修复和其他任务改动。主目录完整类型检查和diff检查通过。
- 规格及代码质量独立复审通过。401/403会清除当前类型/会话的查询缓存；后续失败不能恢复旧数据，重新取数成功后才恢复真实预览。已有数据的普通网络刷新失败保留当前预览并独立显示错误/重试。
- 本地 `http://localhost:5173` 使用已有真实测试账号验收：产品标签自动显示库内商品条码/名称，销售模板已有14元素布局显示真实单据及明细；十类API均返回对应真实来源。未点击保存，未修改业务数据或创建打印任务；空数据和权限回退由独立数据库与组件测试验证。
- 本地截图：`output/print-template-real-preview-2026-09-09/product-real-data.png` 与 `sale-real-data.png`。本任务浏览器会话结束后关闭并核验，保留其他会话和开发服务。
- 专项 `npm run smoke:print-template-preview` 已加入 Tests CI。v0.9.11 首次 CI 发现管理员空库断言依赖前序测试数据；改用新建仓库范围验证空数据，不删除共享测试库记录。完整软件验证与发布结果见版本记录；未真机打印。
